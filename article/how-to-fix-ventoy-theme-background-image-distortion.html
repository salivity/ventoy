How to Fix Ventoy Theme Background Image Distortion

Ventoy allows you to customize its boot interface using GRUB2 themes, but varying screen resolutions and aspect ratios (such as 16:9, 16:10, and 4:3) frequently stretch and distort full-screen background graphics. This guide explains how to prevent background distortion in Ventoy by enforcing specific display resolutions, replacing full-canvas scaling with centered image components in your theme configuration, and utilizing aspect-ratio-safe graphic design techniques.

Method 1: Lock Display Resolution in ventoy.json

By default, Ventoy attempts to match the native display resolution of the host machine's UEFI or BIOS environment. If a 16:9 image is loaded on a 4:3 or 16:10 screen, GRUB stretches the image to fit. You can force Ventoy to run at a fixed aspect ratio using the ventoy.json configuration file located in the ventoy folder of your USB drive.

Add or edit the gfxmode property within the theme object:

{
    "theme": {
        "file": "/ventoy/theme/mytheme/theme.txt",
        "gfxmode": "1920x1080"
    }
}

If the display hardware does not support the forced resolution, GRUB falls back to the nearest compatible mode. You can specify a prioritized list separated by commas or semicolons (e.g., "1920x1080;1366x768;1024x768").

Method 2: Center the Image via theme.txt

The standard GRUB2 directive desktop-image automatically stretches any graphic across the entire screen. To prevent stretching while maintaining proper aspect ratio across arbitrary resolutions, use a solid background color combined with a centered image component instead of desktop-image.

  1. Open your custom theme's theme.txt file.
  2. Remove or comment out the desktop-image line.
  3. Define a fallback background color using desktop-color.
  4. Add a centered image component that holds your graphic at fixed dimensions.

Example configuration in theme.txt:

desktop-color: "#000000"

+ image {
    top = 50%-270
    left = 50%-480
    width = 960
    height = 540
    file = "background_centered.png"
}

In this configuration, an image measuring 960x540 pixels remains centered without stretching, surrounded by black letterboxing on wider or taller displays.

Method 3: Implement Safe Zones for Stretched Graphics

If your design requires the artwork to cover the entire canvas without letterboxing, design the asset around "safe zones":

  1. Create the graphic at a base resolution of 1920x1080 (16:9).
  2. Keep critical UI elements, logos, and focal art within a central 1440x1080 (4:3) bounding box.
  3. Use textures, gradients, or abstract graphics toward the left and right outer edges.

When the image scales horizontally or vertically on non-standard displays, the peripheral details absorb the compression or stretching, leaving the core artwork visually intact.
