How to Install Ventoy on a Fixed External Hard Drive

Ventoy can be installed on a fixed external hard drive that does not report as a removable media device. By default, Ventoy filters out fixed drives as a safety precaution to prevent users from accidentally overwriting internal system drives. However, this restriction can be disabled directly within the Ventoy interface or via command-line options, allowing you to turn any external HDD or SSD into a multi-boot drive.

Why Fixed Drives Are Hidden by Default

Windows and other operating systems classify storage devices as either "removable" (standard USB flash drives) or "fixed" (internal drives and certain external enclosures). Ventoy defaults to displaying only removable media so that primary operating system installations are not wiped by mistake. Because many high-capacity external hard drives and NVMe/SATA USB enclosures report to the OS as fixed disks, they will not appear in Ventoy's target list until you manually enable the option to view them.

Enabling Fixed Drives in Windows (Ventoy2Disk.exe)

To install Ventoy onto a fixed external drive using Windows:

  1. Connect your external hard drive to the computer.
  2. Launch Ventoy2Disk.exe.
  3. Click on the Option menu located in the top toolbar.
  4. Check the option labeled Show all devices.
  5. Return to the device dropdown list; your fixed external drive will now be visible.
  6. Verify the drive capacity and model carefully to ensure you do not select an internal disk.
  7. Click Install to format the drive and apply the Ventoy bootloader.

Enabling Fixed Drives in Linux

On Linux systems, Ventoy interacts directly with block devices (such as /dev/sdb or /dev/sdc). The installation script does not restrict device types by default, but caution is required:

  1. Identify the correct disk path using lsblk or fdisk -l.
  2. Run the Ventoy installation script targeting the drive: 
    sudo sh Ventoy2Disk.sh -i /dev/sdX
    (Replace /dev/sdX with your external drive's actual identifier).
  3. Confirm the prompts twice to proceed with formatting.

Configuration Tips for Large External Hard Drives

  • Partition Scheme: For modern systems and drives larger than 2 TB, use the GPT partition style. You can set this under Option > Partition Style in the Ventoy menu before installation.
  • Preserving Space for General Storage: Ventoy creates two partitions: a hidden boot partition (VTOYBOOT) and a main storage partition formatted as exFAT. You can use the main partition to store ISO files as well as regular files, folders, and backups without interfering with boot functionality.
  • Non-Destructive Workarounds: If your drive already contains critical data that cannot be erased, Ventoy also supports non-destructive installation options under the Option menu, provided there is enough unallocated space to create the required boot structures. However, a full backup is strongly recommended prior to proceeding.
