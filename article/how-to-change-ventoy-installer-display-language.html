How to Change Ventoy Installer Display Language

The Ventoy installer utility defaults to the operating system's native language, but users can easily switch to an alternate display language or create custom translations. This guide covers how to change the interface language within the Ventoy graphical tools on Windows and Linux, use the Web GUI selector, and add a completely custom language file for unlisted localizations.

Changing the Language in the Windows and Linux GUI

  1. Open the Ventoy folder and launch the installer executable (Ventoy2Disk.exe on Windows or VentoyGUI on Linux).
  2. Locate the menu bar at the top of the application window.
  3. Click on the Language tab.
  4. Scroll through the alphabetical list and click your preferred language. The interface text updates immediately without requiring an application restart.

Changing the Language in the Web GUI (Linux)

If you are using the browser-based interface via VentoyWeb.sh:

  1. Launch the web server using terminal: sudo bash VentoyWeb.sh.
  2. Open the displayed local address (usually http://127.0.0.1:24601) in your web browser.
  3. Locate the language dropdown menu located in the top-right corner of the interface.
  4. Select your preferred display language from the list.

Adding a Custom Display Language

If your required language is not present in the default installation, you can create a custom translation using Ventoy's localization structure:

  1. Open the extracted Ventoy folder and navigate to the languages subfolder.
  2. Locate en_US.json or another language file to use as a template.
  3. Make a copy of the file in the same directory and rename it using your target locale name (for example, custom_LANG.json).
  4. Open your new file in any text editor.
  5. Translate the string values corresponding to each key. Do not modify the JSON keys, only the translated text on the right side of the colon.
  6. Save the file.
  7. Launch the Ventoy installer, click Language on the top menu, and select your newly added custom language from the list.
