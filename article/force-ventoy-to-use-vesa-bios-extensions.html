Force Ventoy to Use VESA BIOS Extensions

Ventoy can be forced to use standard VESA BIOS Extensions (VBE) video modes when booting systems in Legacy BIOS mode to resolve display glitches, black screens, and resolution mismatch issues. Because Ventoy relies on standard GRUB2 display drivers, users can manually select standard VESA resolutions via runtime hotkeys, enforce specific resolutions in the configuration file, or drop back to legacy text mode if graphic modes fail.

VESA Support in Ventoy (Legacy BIOS vs. UEFI)

VESA BIOS Extensions (VBE) are strictly a feature of Legacy BIOS environments. If you boot Ventoy in modern UEFI mode, the firmware relies on the Graphics Output Protocol (GOP) instead. To use VESA video modes, your computer must boot the Ventoy USB drive in Legacy BIOS mode (often labeled as CSM or Legacy Boot in motherboard firmware settings).

Method 1: Change Resolution via the Ventoy Menu

The quickest way to switch to a standard VESA mode is through Ventoy’s built-in resolution menu:

  1. Boot your computer from the Ventoy USB drive in Legacy BIOS mode.
  2. At the main Ventoy boot menu, press F5 (Tools).
  3. Select Resolution Configuration.
  4. Choose a standard VESA-compliant resolution from the list, such as 1024x768x32, 1024x768x16, or 800x600x16.
  5. Return to the main menu. Ventoy will reset the display adapter to the selected VESA mode.

Method 2: Force Resolution Using ventoy.json

To make standard VESA mode settings permanent across reboots, define the resolution in the ventoy.json configuration file.

  1. Open the primary data partition of your Ventoy USB drive.
  2. Navigate to the ventoy folder (create it if it does not exist).
  3. Create or edit the ventoy.json file.
  4. Add the theme configuration block specifying a fallback VESA resolution:
{
    "theme": {
        "display_mode": "gui",
        "gfxmode": "1024x768"
    }
}

Setting gfxmode to 1024x768 or 800x600 instructs the underlying bootloader to request a standard VESA resolution from the system BIOS.

Method 3: Use the GRUB Command Line

If the interface fails to load properly, you can inspect and set VESA video modes directly through GRUB commands:

  1. Press c at the Ventoy boot screen to open the command-line interface.
  2. Type videoinfo (or vbeinfo) and press Enter to display all VESA modes supported by your video BIOS.
  3. Note a standard mode (for example, 1024x768x32).
  4. Type set gfxmode=1024x768 and press Enter.
  5. Type terminal_output gfxterm to reinitialize the display with the selected mode.
  6. Press Esc to return to the main menu.

Method 4: Fallback to Text Mode

If your graphics hardware refuses to initialize any graphical VESA buffer correctly, force Ventoy to bypass graphical modes entirely and use standard VGA text mode. In ventoy.json, configure:

{
    "control": [
        { "display_mode": "cli" }
    ]
}

This disables all graphical output drivers and relies on standard 80x25 BIOS text output, ensuring universal compatibility across legacy hardware.
