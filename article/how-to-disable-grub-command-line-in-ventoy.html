How to Disable GRUB Command Line in Ventoy

This guide explains how to completely restrict and disable access to the GRUB command-line interface (CLI) in Ventoy. By default, users can press the c key at the boot menu to enter the GRUB shell or e to edit boot parameters. Securing your Ventoy drive against unauthorized command-line access is achieved by configuring the Ventoy Password Plugin within the ventoy.json configuration file, which effectively locks the terminal and configuration editor behind an administrator credential.

Step 1: Create the Ventoy Configuration Directory

  1. Insert your Ventoy USB drive into your computer.
  2. Open the main partition (the partition where you place ISO files).
  3. Create a folder named ventoy in the root of this partition (all lowercase).

Step 2: Generate the Admin Password Hash

Ventoy allows you to lock down administrative features using either plain text or hashed passwords (SHA-256 or SHA-512). A SHA-512 hash is recommended for maximum security.

You can generate a password hash using a standard terminal command or Ventoy's provided tool:

  • Linux: Run the following command in a terminal (replace YourPassword with your desired password):

    grub-mkpasswd-pbkdf2

    Enter your password when prompted and copy the output string beginning with grub.pbkdf2.sha512....

  • Windows: Use the VentoyPlugson GUI tool included with the Ventoy download package, or use plain text temporarily (though plain text is less secure).

Step 3: Create and Configure ventoy.json

Inside the ventoy directory created in Step 1, create a file named ventoy.json. Open it in any text editor and define the "password" plugin with the "admin" parameter:

{
    "password": {
        "admin": "grub.pbkdf2.sha512.10000.YOUR_GENERATED_HASH_HERE"
    }
}

If you prefer to use a plain text password instead of a hash:

{
    "password": {
        "admin": "YourSecurePassword"
    }
}

Step 4: Verify the CLI Lockout

  1. Safely eject and restart your computer to boot from the Ventoy USB drive.
  2. In the Ventoy main menu, press c to invoke the command-line interface, or e to edit an entry.
  3. Ventoy will now display an authentication prompt requiring the administrator username and password.
  4. Without the administrative credentials, access to the GRUB CLI terminal is completely blocked, preventing any arbitrary command execution or modification of kernel parameters.
