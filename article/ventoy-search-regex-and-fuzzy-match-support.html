Ventoy Search: Regex and Fuzzy Match Support

Ventoy includes a convenient search mode to help users quickly locate specific ISO and image files within large storage drives, but its filtering mechanism is limited. Ventoy does not support regular expressions (regex) or fuzzy matching algorithms. Instead, the search function relies on standard, case-insensitive substring matching, requiring users to input exact sequences of characters found within file names or file paths.

How the Ventoy Search Filter Operates

When accessing Ventoy's boot menu, pressing the F3 key opens the search interface. As you type into the search box, Ventoy immediately filters the list of bootable images displayed on the screen.

The filter checks whether the entered string exists as a contiguous block of text inside the file name or its directory path. The evaluation is strictly case-insensitive, meaning searching for "ubuntu", "Ubuntu", or "UBUNTU" will yield identical results.

Regular Expression (Regex) Support

Ventoy does not support regular expressions. Metacharacters commonly used in regex syntax—such as .*, ^, $, [a-z], or ?—are not parsed as pattern modifiers or wildcards.

If you type any of these symbols into the Ventoy search prompt, the system treats them as literal characters. Consequently, an expression like win.*iso will fail to match a file named windows11.iso, as it will explicitly search for the literal string .* in the filename.

Fuzzy Matching Support

Fuzzy matching—an algorithm that tolerates typos, misspellings, or non-consecutive character inputs (such as matching "ubntu" to "ubuntu")—is not supported in Ventoy.

Because the search uses strict substring evaluation, the query string must precisely match a continuous sequence of characters in the target file. If a single letter is omitted, transposed, or misspelled, the matching file will not appear in the filtered results.

Tips for Efficient Searching in Ventoy

Because Ventoy lacks advanced matching patterns, optimizing your storage layout and naming conventions ensures the best search experience:

  • Use Consistent Naming: Rename your ISO files systematically (e.g., distro_version_arch.iso such as ubuntu-22.04-x64.iso) to make searching predictable.
  • Keep Search Queries Short: Instead of typing full names, type unique short identifiers like 22.04, win11, or arch to instantly narrow down your list.
  • Leverage Directory Paths: Ventoy's search scans the entire relative path. If you organize files into folders such as /Linux/ or /Rescue/, searching for the folder name will filter files residing in that specific directory.
