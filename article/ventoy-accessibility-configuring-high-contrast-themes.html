Ventoy Accessibility: Configuring High-Contrast Themes

Ventoy can be fully configured for accessibility, allowing users to implement high-contrast color schemes, enlarge menu fonts, and switch to simplified text modes. Because Ventoy uses GRUB2 as its underlying interface engine, the boot menu can be styled via custom theme.txt files and managed through the ventoy.json configuration file. This guide explains how to optimize Ventoy's boot environment for users with visual impairments or specific readability needs.

Understanding Ventoy's Theming Engine

Ventoy relies on GRUB2 graphical themes to render its menu interface. By default, Ventoy displays a standard graphical menu, but this interface can be altered by overriding theme components. Accessibility modifications primarily involve:

  1. Modifying the theme.txt file to define high-contrast colors (such as bright yellow or white on a pure black background).
  2. Supplying larger bitmap fonts (.pf2 format) to enhance text readability.
  3. Enabling Text Mode (CLI mode) to strip away graphical elements entirely.

Creating a High-Contrast GRUB Theme

To apply a high-contrast theme, create a custom theme directory inside the ventoy folder on your Ventoy USB drive (e.g., ventoy/themes/high-contrast/).

Inside this directory, create a theme.txt file containing high-contrast properties:

# General settings
title-text: ""
desktop-image: ""
desktop-color: "#000000"

# Boot menu properties
+ boot_menu {
    left = 15%
    top = 20%
    width = 70%
    height = 60%
    item_font = "DejaVuSans-Bold-24"
    item_color = "#FFFFFF"
    selected_item_color = "#000000"
    item_height = 40
    item_spacing = 15
    selected_item_pixmap_style = "select_*.png"
}

Key accessibility settings in this configuration include:

  • desktop-color: "#000000": Enforces a solid, glare-free black background without distracting background graphics.
  • item_color: "#FFFFFF": Ensures non-selected items display in pure white for maximum contrast against the black background.
  • item_spacing and item_height: Expanded values make distinct menu items easier to differentiate.

Using Larger Fonts for Readability

GRUB2 cannot render standard TrueType (.ttf) fonts directly; it requires .pf2 font files. To generate a large, readable font:

  1. On a Linux system, use the grub-mkfont utility: 
    grub-mkfont -s 32 -o DejaVuSans-32.pf2 /usr/share/fonts/truetype/dejavu/DejaVuSans-Bold.ttf
  2. Copy the resulting DejaVuSans-32.pf2 file into your theme directory.
  3. Reference the font in your theme.txt: 
    item_font = "DejaVuSans-32"

Activating the Theme in ventoy.json

To make Ventoy load your custom theme, create or edit the ventoy.json file in the ventoy directory on your USB drive:

{
    "theme": {
        "file": "/ventoy/themes/high-contrast/theme.txt",
        "gfxmode": "1920x1080"
    }
}

The gfxmode parameter can be lowered (for example, to 1024x768 or 800x600) to naturally scale up all visual elements on high-DPI displays.

Switching to CLI (Text Only) Mode

For environments where graphical themes remain difficult to read or fail to scale properly, Ventoy includes a native text-mode interface.

Text mode can be engaged in two ways:

  • On demand: Press the F7 key at the main Ventoy menu to toggle between graphical mode and text mode.
  • By default: Add the display_mode directive to ventoy.json:
{
    "control": [
        { "display_mode": "cli" }
    ]
}

CLI mode eliminates custom styling, background images, and scaling issues, rendering standard BIOS/UEFI monochrome terminal text for optimal clarity and high contrast.
