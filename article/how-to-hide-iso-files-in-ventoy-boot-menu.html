How to Hide ISO Files in Ventoy Boot Menu

Ventoy automatically scans your drive and lists every compatible image it detects, which can quickly clutter your screen if you store backup images, secondary tools, or installation files you do not need at boot. This guide explains how to hide specific ISO files from the Ventoy boot menu using three practical methods: the .ventoyignore directive, the ventoy.json display list, and file extension modifications.

Method 1: Use the .ventoyignore File

Ventoy allows you to exclude entire folders and their contents from the boot scan by placing a special marker file inside them.

  1. Open your Ventoy USB drive in your file manager.
  2. Create a new directory to store the images you wish to hide (for example, /Hidden or /Storage/ISOs).
  3. Move the ISO files you want to hide into this directory.
  4. Inside this same directory, create an empty text file and name it exactly .ventoyignore (ensure your operating system does not append a .txt extension).

During boot, Ventoy detects the .ventoyignore file and skips scanning that directory and all of its subdirectories, preventing any ISOs inside from appearing on the menu.

Method 2: Define an Image Whitelist in ventoy.json

If you want to keep your file structure unchanged, you can use Ventoy's Control Plugin to explicitly define which ISO files are allowed to appear on the menu. Any file not listed in this configuration will remain hidden.

  1. Navigate to the root directory of your Ventoy USB drive.
  2. Locate or create a folder named ventoy.
  3. Inside the ventoy folder, create or edit a file named ventoy.json.
  4. Add the image_list array inside the control block to specify only the ISO files you want visible:
{
    "control": [
        {
            "image_list": [
                "/ISOs/Ubuntu-22.04.iso",
                "/ISOs/Windows-11.iso"
            ]
        }
    ]
}

Make sure file paths start from the root of the USB drive and use forward slashes (/). Any ISO located on the drive that is omitted from image_list will be hidden from the boot screen.

Method 3: Change the File Extension

Ventoy only displays files that match supported image extensions such as .iso, .wim, .img, and .vhd. Renaming the file extension prevents Ventoy from parsing it as a bootable image while keeping the file accessible for storage.

  1. Locate the ISO you want to hide on the drive.
  2. Rename the file and append an arbitrary suffix to the extension, such as changing debian.iso to debian.iso.hidden or debian.iso.bak.

When you need to boot the file again, simply rename it back to its original .iso extension.
