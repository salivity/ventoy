Restrict Ventoy to Scan a Specific Directory

By default, Ventoy scans the entire partition of your USB drive to locate bootable ISO, WIM, and IMG files. When a drive contains numerous unrelated files and folders, this broad scan can slow down the initial boot menu loading time. You can easily restrict Ventoy to scan only a single designated directory by configuring the VTOY_DEFAULT_SEARCH_ROOT option within the ventoy.json configuration file.

Step 1: Create the Configuration Folder

  1. Plug your Ventoy USB drive into your computer.
  2. Open the main partition where your ISO files are stored (typically labeled Ventoy).
  3. Create a new directory named ventoy (all lowercase) in the root of the partition if it does not already exist.

Step 2: Create the ventoy.json File

Inside the newly created ventoy folder, create a plain text file and name it ventoy.json. Make sure your operating system does not append a .txt extension to the file name.

Step 3: Define the Search Directory

Open ventoy.json in any standard text editor (such as Notepad, VS Code, or nano) and enter the following JSON configuration:

{
    "control": [
        { "VTOY_DEFAULT_SEARCH_ROOT": "/ISO" }
    ]
}

Replace /ISO with the exact path of the directory you want Ventoy to scan.

Important Configuration Rules

  • Leading Slash: The directory path must start with a forward slash (/), representing the root of the Ventoy partition (e.g., /ISO, /Images, or /BootFiles).
  • Case Sensitivity: Directory paths in Ventoy are case-sensitive. Ensure that the casing in your JSON file matches the folder name on the drive precisely.
  • Subdirectories: Setting VTOY_DEFAULT_SEARCH_ROOT restricts the search so that Ventoy only scans the designated folder and any subdirectories nested directly inside it. The rest of the partition will be completely ignored during boot.
