Custom Boot Arguments for ISOs in Ventoy

Ventoy does not offer a direct, single-line "kernel argument" parameter inside the standard ventoy.json file. However, you can configure persistent, per-ISO custom boot arguments using the boot_conf_replace plugin defined within ventoy.json, or by defining custom GRUB entries through a ventoy_grub.cfg file. This guide explains how to apply custom boot options to specific ISO images using both approaches.

Method 1: Using the boot_conf_replace Plugin in ventoy.json

The native way to supply custom kernel arguments via ventoy.json is through the Boot Conf Replace plugin. This plugin instructs Ventoy to swap the ISO's internal bootloader configuration file (such as grub.cfg or isolinux.cfg) with an external, modified configuration file located on your USB drive.

1. Extract and Modify the Configuration File

Open your ISO file using an archive manager (such as 7-Zip) and extract the boot configuration file.

  • For UEFI/GRUB-based ISOs, this is typically located at /boot/grub/grub.cfg.
  • For Syslinux/Isolinux-based ISOs, look for /isolinux/isolinux.cfg or /boot/syslinux/syslinux.cfg.

Open the extracted file in a text editor, locate the kernel command line (usually lines starting with linux, linuxefi, or append), and add your desired boot arguments (e.g., nomodeset, quiet, console=ttyS0). Save this file on your Ventoy drive under a directory such as /ventoy/conf/custom_ubuntu.cfg.

2. Configure ventoy.json

Open or create /ventoy/ventoy.json on your Ventoy partition and configure the boot_conf_replace section:

{
    "boot_conf_replace": [
        {
            "iso": "/ISO/ubuntu-22.04-desktop-amd64.iso",
            "dst": "/boot/grub/grub.cfg",
            "src": "/ventoy/conf/custom_ubuntu.cfg"
        }
    ]
}
  • iso: The path to your target ISO on the Ventoy drive.
  • dst: The path of the original configuration file inside the ISO image.
  • src: The path to your modified configuration file containing your custom parameters.

When you boot the specified ISO, Ventoy automatically swaps in your modified configuration file containing the custom parameters.

Method 2: Using ventoy_grub.cfg (Alternative Approach)

If you prefer not to unpack and replace internal configuration files, Ventoy supports adding native GRUB2 menu entries with custom boot arguments using an external ventoy_grub.cfg file.

  1. Create a file named ventoy_grub.cfg inside the /ventoy/ directory.
  2. Add a custom GRUB menu entry targeting your ISO and appending the necessary parameters:
menuentry "Ubuntu 22.04 (Custom Arguments)" {
    set iso_path="/ISO/ubuntu-22.04-desktop-amd64.iso"
    loopback loop $iso_path
    linux (loop)/casper/vmlinuz boot=casper iso-scan/filename=$iso_path nomodeset fsck.mode=skip ---
    initrd (loop)/casper/initrd
}
  1. Boot your Ventoy drive and press F6 to load the custom GRUB menu, where your entry and arguments will be available.

Temporary Boot Arguments (Runtime)

If you only need custom parameters for a single boot session, you do not need to edit ventoy.json:

  1. Highlight your ISO in the Ventoy boot menu.
  2. Press e or select the boot menu option that allows parameter editing (depending on the bootloader style).
  3. Append your parameters to the command line and boot by pressing Ctrl+X or F10.
