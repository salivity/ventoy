Enable Serial Terminal Output in Ventoy

This guide provides a straightforward walkthrough on how to enable serial terminal output in Ventoy. By modifying the GRUB configuration located on Ventoy's reserved EFI system partition, you can redirect the boot menu and console output through a serial port, allowing you to manage headless servers, appliances, and systems over an RS-232, IPMI SOL (Serial-over-LAN), or USB-to-serial interface.

Step 1: Mount the Ventoy EFI System Partition

Ventoy partitions a drive into two sections: Partition 1 (formatted as exFAT, NTFS, or ext4 for storing ISO files) and Partition 2 (the hidden VTOYEFI FAT partition holding the bootloader files). You must mount Partition 2 to edit the core GRUB configuration.

  • On Linux:

    1. Identify the partition using lsblk (typically /dev/sdX2, where sdX is your USB drive).
    2. Mount the partition to a temporary directory: 
      sudo mkdir -p /mnt/ventoy_efi
sudo mount /dev/sdX2 /mnt/ventoy_efi

  • On Windows:

    1. Open Command Prompt as Administrator and run diskpart.
    2. Enter list volume and identify the hidden FAT volume labeled VTOYEFI.
    3. Select it using select volume X (replace X with the volume number).
    4. Assign a temporary drive letter: assign letter=V.

Step 2: Edit the GRUB Configuration File

Navigate to the grub directory located within the mounted EFI partition:

  • Path: /mnt/ventoy_efi/grub/grub.cfg (Linux) or V:\grub\grub.cfg (Windows).
  • Open grub.cfg in a plain text editor with administrative privileges.

Step 3: Insert Serial Console Directives

Add the GRUB serial terminal commands at the very top of grub.cfg before any menu entries or environment initializations:

serial --unit=0 --speed=115200 --word=8 --parity=no --stop=1
terminal_input --append serial
terminal_output --append serial
  • --unit=0: Corresponds to COM1 (ttyS0). Change this value if using a different port (1 for COM2/ttyS1).
  • --speed=115200: Sets the baud rate. Match this with your client terminal emulator settings.
  • --append: Ensures that the serial terminal is activated alongside the standard display console rather than replacing it entirely.

Save the changes and unmount or safely remove the assigned drive letter:

  • On Linux: sudo umount /mnt/ventoy_efi
  • On Windows diskpart: remove letter=V

Step 4: Pass Serial Parameters to Guest Operating Systems

Enabling serial output in Ventoy's GRUB configuration displays the Ventoy bootloader menu over serial, but the launched payload (such as a Linux installer) will drop back to standard video unless configured otherwise.

To pass serial console parameters to the booted kernel:

  1. Connect your serial client and boot into the Ventoy menu.
  2. Highlight your target ISO image and press e to edit the boot parameters.
  3. Locate the linux or linuxefi kernel command line and append the console parameter: 
    console=tty0 console=ttyS0,115200n8
  4. Press Ctrl+X or F10 to boot the payload with serial console redirection enabled.

Note on Upgrades

Ventoy rewrites Partition 2 during full updates. If you update the Ventoy installation via the Ventoy installer utility, your changes to grub.cfg will be overwritten and must be reapplied.
