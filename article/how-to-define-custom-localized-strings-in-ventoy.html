How to Define Custom Localized Strings in Ventoy

Yes, you can define and display custom localized strings in your personal Ventoy boot menu. Ventoy relies on standard GRUB2 underpinnings and a flexible JSON configuration architecture, allowing you to override default interface text, rename boot entries into your preferred language, and map customized language files. This guide details how Ventoy handles localization and the exact steps to implement custom strings in your setup.

1. Creating the Configuration Directory

All customizations in Ventoy reside inside a dedicated configuration folder on the first partition (the partition where you store ISO files).

Create a folder named ventoy at the root of the USB drive, and place a file named ventoy.json inside it:

/ventoy/ventoy.json

2. Customizing Menu Titles with menu_alias

If your goal is to present localized names for your ISO and WIM files instead of raw filenames, use the menu_alias plugin. This allows you to define localized, human-readable labels for specific boot images:

{
    "menu_alias": [
        {
            "image": "/ISO/ubuntu-22.04-desktop-amd64.iso",
            "alias": "Ubuntu 22.04 LTS (Système d'exploitation)"
        },
        {
            "image": "/ISO/Win11_English_x64.iso",
            "alias": "Windows 11 (Installation Principale)"
        }
    ]
}

3. Setting a Default Localized Language

Ventoy includes built-in translations for its core interface (such as footer hints, key combinations, and system menus). You can force a specific language string set directly via the control plugin in ventoy.json:

{
    "control": [
        { "VTOY_DEFAULT_SEARCH_ROOT": "/ISO" },
        { "VTOY_MENU_LANGUAGE": "fr_FR" }
    ]
}

Setting VTOY_MENU_LANGUAGE automatically pulls the corresponding localized strings from Ventoy's internal translation table.

4. Overriding Core System Strings via Custom Themes

For deeper interface customization—such as custom prompt strings, labels, and status messages—Ventoy relies on GRUB2 themes. You can supply a custom theme package that includes its own localized font sets and theme.txt configurations:

{
    "theme": {
        "file": "/ventoy/theme/mytheme/theme.txt",
        "ventoy_left": "5%",
        "ventoy_top": "80%",
        "ventoy_color": "#ffffff"
    }
}

Within your custom theme.txt, you can replace default English UI text with hardcoded strings in your chosen language or target specific text components.

5. Advanced Dynamic Strings with ventoy_grub.cfg

For completely custom, script-driven localized strings, create a file named ventoy_grub.cfg inside the /ventoy/ directory. Ventoy will execute this file, allowing standard GRUB2 scripting:

  • You can define environment variables containing your localized strings.
  • You can read the current $lang variable set by Ventoy.
  • You can write conditional logic (if/then/else) to display different text options depending on the selected interface language.
