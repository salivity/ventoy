Ventoy Hotkeys: Fast One-Key Booting Rescue Tools

This article evaluates whether Ventoy natively supports hotkey navigation profiles for fast, one-key booting of primary rescue tools and explains how to implement direct-boot shortcuts. While Ventoy lacks a dedicated feature named "hotkey navigation profiles," it offers robust built-in shortcut keys and full integration with GRUB2 scripting, allowing users to configure rapid, single-keystroke launch mechanisms for essential diagnostic and recovery environments.

Native Hotkey Capabilities in Ventoy

Out of the box, Ventoy utilizes a core set of pre-mapped function keys across its primary user interface:

  • F1 (Memdisk Mode): Boots an ISO entirely into RAM.
  • F2 (File Browser): Allows browsing non-standard directories on the drive.
  • F3 (Tree View): Toggles tree-style folder views.
  • F4 (Local Boot): Searches and boots operating systems installed on internal drives.
  • F5 (Debug/Tools): Accesses internal diagnostic utilities and resolution switchers.
  • F6 (Custom Menu): Loads a user-defined custom GRUB menu directly.

Ventoy also features a real-time key filter. Typing any character while on the main menu immediately filters the list of ISO files, functioning as a fast navigation mechanism to narrow down large collections to a specific tool.

Creating One-Key Boot Profiles with ventoy_grub.cfg

To achieve true one-key booting for specific recovery systems, you must leverage Ventoy's custom menu integration via GRUB2. Because Ventoy is built on a GRUB2 base, it can parse standard GRUB commands, including the --hotkey flag.

  1. Create a folder named ventoy at the root of your Ventoy USB drive.
  2. Inside this directory, create a file named ventoy_grub.cfg.
  3. Add custom menu entries utilizing the GRUB --hotkey parameter.

For example, to bind the key r directly to an automated rescue image:

menuentry "Boot SystemRescue (One-Key)" --hotkey="r" {
    set iso_path="/ISO/systemrescue.iso"
    search --no-floppy --fs-uuid --set=root $vtoy_iso_part_uuid
    loopback loop $iso_path
    linux (loop)/sysresccd/boot/x86_64/vmlinuz archisobasedir=sysresccd img_loop=$iso_path earlymodules=loop
    initrd (loop)/sysresccd/boot/x86_64/initramfs.img
}

When you press F6 from the Ventoy home screen to enter your custom menu, pressing the assigned key (such as r) will instantly execute that tool without manual scrolling or selecting secondary options.

Rapid Booting via Default Configuration

If you prefer to bypass secondary menus entirely, you can configure your primary rescue environment as the default boot target using the ventoy.json configuration file located in the /ventoy/ directory.

By applying the control plugin settings:

{
    "control": [
        { "vtoy_default_search_root": "/ISO" },
        { "vtoy_default_image": "/ISO/systemrescue.iso" },
        { "vtoy_timeout": 5 }
    ]
}

This configuration highlights your primary rescue utility immediately on startup. Combined with a short countdown timer, it enables automatic or instant single-press (Enter) execution of your primary utility while retaining access to the rest of your diagnostic library.
