Show Fixed Disks in Ventoy Windows Installer

When booting a Windows installation ISO through a Ventoy USB drive, the setup wizard may fail to detect your internal, non-removable fixed disks (NVMe SSDs or SATA drives) on the partition selection screen. This issue typically stems from missing storage controller drivers, active Intel VMD/RST configurations in your firmware, or virtual drive emulation conflicts. The following steps provide direct solutions to force the Windows installer to recognize and display your internal drives.

1. Disable Intel VMD or RAID in BIOS/UEFI

Most modern laptops and desktops (especially Intel 11th Gen and newer) have Intel Volume Management Device (VMD) or Intel RST (RAID) enabled by default. The standard Windows installer lacks these drivers, causing internal fixed disks to disappear.

  1. Restart your computer and press the BIOS/UEFI key (typically F2, F12, or Delete).
  2. Navigate to System Configuration, Storage, or Advanced Settings.
  3. Locate Intel VMD Technology, Intel RST, or SATA Operation.
  4. Change the setting from RAID/VMD to AHCI or Disabled.
  5. Save changes, exit BIOS, and reboot into your Ventoy drive.

2. Manually Load Storage Drivers During Setup

If you cannot or do not want to disable Intel VMD/RST, you must supply the storage controller drivers during the installation process.

  1. Download the appropriate Intel Rapid Storage Technology (IRST) or motherboard storage driver package from your hardware manufacturer's support page.
  2. Extract the driver archive so the raw driver files (.inf, .sys, .cat) are accessible.
  3. Copy the extracted driver folder directly onto the storage partition of your Ventoy USB drive.
  4. Boot the Windows installer via Ventoy and proceed to the disk selection screen ("Where do you want to install Windows?").
  5. Click Load driver in the lower-left corner.
  6. Click Browse, navigate to the driver folder on your Ventoy drive, select the compatible controller driver, and click Next. The internal disks will appear once the driver loads.

3. Launch the ISO Using Ventoy WIMboot Mode

Standard ISO loopback mounting can sometimes conflict with Windows Setup disk discovery routines. Ventoy includes a dedicated WIMboot mode that bypasses traditional virtual disk mounting.

  1. Boot your computer into the Ventoy boot menu.
  2. Highlight your Windows ISO file.
  3. Press Ctrl + W on your keyboard (or press Enter and select Boot in wimboot mode if prompted).
  4. Proceed through the Windows Setup wizard normally to check if your fixed disks appear.

4. Bring Disks Online Using Diskpart

A non-removable disk might be detected by Windows Setup hardware detection but hidden from the installer interface because it is marked offline or has an incompatible partition table.

  1. On the Windows Setup screen, press Shift + F10 to open the Command Prompt.
  2. Type diskpart and press Enter.
  3. Type list disk and press Enter.
  4. If your internal disk is visible in the list:
    • Type select disk X (replace X with the number of your internal disk) and press Enter.
    • Type online disk and press Enter to ensure the disk is active.
    • If the drive is entirely blank or can be wiped, type clean followed by convert gpt to create a fresh partition structure.
  5. Type exit, press Enter, and close the Command Prompt.
  6. Click Refresh on the Windows installation drive selection screen.
