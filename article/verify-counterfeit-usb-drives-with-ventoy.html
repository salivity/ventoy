Verify Counterfeit USB Drives with Ventoy

Counterfeit USB flash drives often feature modified firmware that reports a large storage capacity while only possessing a fraction of that physical memory, causing severe data loss once the true limit is exceeded. This guide explains how to detect fake flash drives using Ventoy's verification capabilities to confirm whether your drive has genuine storage capacity and intact flash memory.

The Risk of Counterfeit USB Drives

A counterfeit drive typically alters the controller chip to report an inflated capacity (such as 512 GB or 1 TB) when the actual NAND flash chip inside is only 16 GB or 32 GB. When writing files past the physical limit, the drive either quietly overwrites older data or crashes, resulting in unrecoverable data corruption.

Preparing for the Verification

Before testing your drive, be aware that thoroughly testing for fake storage requires writing data patterns across the entire storage space.

  1. Back Up Data: The testing process will overwrite existing blocks. Ensure any important files on the drive are backed up elsewhere.
  2. Download Ventoy: Obtain the latest official release package of Ventoy from its official repository and extract the files to your computer.

Step-by-Step Verification Using Ventoy

  1. Launch the Utility: Open the extracted folder and run Ventoy2Disk.exe as an administrator on Windows, or run the corresponding Ventoy GUI/terminal script on Linux.
  2. Select the Device: In the "Device" drop-down menu, choose your USB drive. Double-check the drive letter and device label to avoid selecting the wrong storage unit.
  3. Access the Testing Feature:
    • In the top menu bar, click on Option.
    • Locate and select the drive verification/testing feature (labeled as fake capacity check or disk integrity verification depending on the version).
  4. Initiate the Check: Confirm the operation when prompted. Ventoy will write predetermined data patterns to specific sectors across the full reported range of the USB drive, specifically focusing on boundary areas where counterfeit loops occur.
  5. Read and Compare: After the write phase, the tool reads back the written sectors to verify whether the stored data matches the original pattern.

Interpreting the Results

  • Genuine Drive: If the drive is authentic, all test sectors will return matching data patterns without read errors. Ventoy will report that the capacity is verified and matches the physical controller specifications.
  • Counterfeit Drive: If the read phase fails, returns corrupt data, or throws I/O errors past a certain capacity threshold, the drive is counterfeit. This indicates that the storage wrapped around and overwrote earlier blocks or attempted to write to non-existent memory addresses.

If the drive fails the test, stop using it immediately for any important data, as reliable file storage is impossible on a modified controller. Contact the seller or retailer to arrange a return and refund.
