How to Non-Destructively Upgrade Ventoy on Linux

This guide explains how to safely update an existing Ventoy installation on a USB drive using the Linux command line without erasing your stored ISO files and data. By utilizing the official Ventoy installer script with the appropriate upgrade argument, you can update the bootloader files on the reserved partition while keeping your main data partition completely intact.

The Non-Destructive Upgrade Command

To upgrade an existing Ventoy drive without formatting it, use the -u command-line argument with the Ventoy2Disk.sh script.

The basic syntax is:

sudo ./Ventoy2Disk.sh -u /dev/sdX

Replace /dev/sdX with the actual device node of your USB drive (for example, /dev/sdb).

  • -u: Specifies the non-destructive upgrade operation. Unlike the standard install command (-i), which reformats the entire drive, -u only updates the EFI and boot partitions, preserving the storage partition where your ISO files reside.

Step-by-Step Upgrade Process

  1. Download the Latest Release
    Download the latest ventoy-x.x.xx-linux.tar.gz archive from the official Ventoy repository and extract it:

    tar -xzvf ventoy-*-linux.tar.gz
cd ventoy-*/

  2. Identify Your USB Drive
    Confirm the correct block device identifier for your USB drive to avoid targeting the wrong disk:

    lsblk

    Locate your drive in the list (e.g., sdb, sdc). Ensure you target the whole device (such as /dev/sdb), not a specific partition (such as /dev/sdb1).

  3. Run the Upgrade
    Execute the upgrade script with root privileges using the -u flag:

    sudo ./Ventoy2Disk.sh -u /dev/sdX

  4. Confirm the Upgrade
    The script will compare the currently installed Ventoy version with the new package version and prompt for confirmation. Type y and press Enter to complete the update. Once finished, the tool will report that the upgrade was successful and your ISO images will remain untouched.
