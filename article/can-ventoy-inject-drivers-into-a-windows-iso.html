Can Ventoy Inject Drivers into a Windows ISO?

Ventoy can inject hardware drivers into a Windows installation ISO on the fly without requiring any permanent modifications to the original ISO file. By leveraging Ventoy's built-in Windows Injection Plugin, users can dynamically supply necessary storage controllers, network drivers, or missing chipset drivers directly to the Windows Preinstallation Environment (WinPE) and the setup process during boot.

How On-the-Fly Injection Works

Ventoy bypasses the traditional requirement of repackaging or slipstreaming drivers into an ISO via tools like DISM. Instead, Ventoy mounts the untouched ISO into memory alongside a separate archive (typically a .zip or .7z file) containing the required driver files and deployment scripts.

During the boot phase, Ventoy executes a hook that unpacks these files directly into the virtual environment's memory. When Windows Setup initializes, it can immediately access and utilize the injected drivers to detect NVMe drives, RAID arrays, or specific network interfaces that the default Windows installer lacks native support for.

Requirements for Driver Injection

To successfully deploy drivers on the fly, you must prepare the drivers and Ventoy configuration properly:

  1. Unpacked Driver Files: Executable installers (.exe) will not automatically load during Windows Setup. The drivers must be in raw format, consisting of .inf, .sys, and .cat files.
  2. The Injection Archive: Drivers are placed inside an archive along with a batch script or auto-install instructions (such as a command calling pnputil /add-driver) to tell WinPE to load them into the running system.
  3. The Ventoy Configuration File: An entry must be added to the ventoy.json configuration file located in the ventoy folder on the USB drive.

Configuring the Injection Plugin

To configure dynamic driver injection, define the injection object inside the ventoy.json file. The configuration maps a specific Windows ISO to the corresponding driver archive:

{
    "injection": [
        {
            "image": "/ISO/Windows11_Install.iso",
            "archive": "/ventoy/drivers_storage.zip"
        }
    ]
}

When Windows11_Install.iso is selected from the Ventoy boot menu, Ventoy detects the mapped archive, loads the contents into the WinPE memory space, and allows the installation to proceed with the appropriate hardware access from start to finish.
