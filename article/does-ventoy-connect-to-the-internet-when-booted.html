Does Ventoy Connect to the Internet When Booted?

Ventoy does not make any outgoing internet connections when booted locally on a computer from a USB drive. As an offline, open-source bootloader, its primary function is to read ISO, WIM, IMG, and VHD files directly from local storage without communicating with remote servers. While the utility operates entirely offline during standard use, network activity can only occur if you specifically utilize Ventoy’s network-booting features or once the guest operating system loaded via Ventoy initializes its own network stack.

How Ventoy Operates During Boot

When a computer boots from a Ventoy USB drive, the system executes a customized GRUB bootloader environment stored locally on the drive's EFI System Partition. This bootloader accesses the hardware at the firmware level (BIOS or UEFI) and directly reads the file system of the storage device.

In a standard boot scenario:

  • No Network Initialization: Ventoy does not initialize UEFI or BIOS network drivers to query remote endpoints.
  • No Telemetry or Tracking: The open-source codebase contains no background telemetry, phone-home features, or usage reporting mechanisms during the boot phase.
  • Local Image Resolution: Ventoy hooks directly into memory to simulate a virtual optical drive or hard disk, presenting the selected ISO to the hardware entirely via local memory and bus interfaces.

Common Sources of Confusion Regarding Network Activity

Users observing network traffic during or immediately after the boot process often attribute this activity to Ventoy, but it typically stems from other sources:

  1. The Booted Operating System: The moment you select an ISO from the Ventoy menu and the OS kernel loads, control of the machine transfers entirely to that operating system. Most modern live distributions (such as Ubuntu, Fedora, or Windows PE/Installer environments) automatically initialize network adapters, request local IP addresses via DHCP, and contact network time protocol (NTP) servers or software repositories immediately upon startup.

  2. Ventoy's PXE / iPXE Features: Ventoy includes optional network-booting tools, such as Ventoy Server (iPXE). If an administrator intentionally configures Ventoy to boot over a local area network or retrieve remote boot files, network connections will occur. However, this is an opt-in network architecture, not the default USB boot behavior.

  3. Desktop Installation Tools: The Ventoy installation utility that runs inside Windows or Linux to format and prepare the USB drive may check the internet to verify the latest release version. This is separate from the boot environment itself.

When booting a computer directly from a standard Ventoy USB drive, the bootloader remains completely offline and transmits no outbound data.
