Ventoy VTOY_DEFAULT_SEARCH_ROOT Options Explained

This article provides an overview of the VTOY_DEFAULT_SEARCH_ROOT configuration option in Ventoy, explaining its purpose, syntax, and available settings. By utilizing this parameter within the global control plugin, users can define exactly where Ventoy searches for bootable image files, improving boot menu loading times and organizing storage layouts on the USB drive.

Purpose of VTOY_DEFAULT_SEARCH_ROOT

By default, Ventoy recursively scans the entire primary partition of the USB drive for bootable image files (such as .iso, .wim, .vhd, and .img). The VTOY_DEFAULT_SEARCH_ROOT setting overrides this behavior by restricting the file search to a designated folder and its subdirectories. This configuration is defined within the ventoy.json file inside the ventoy directory on the drive's first partition.

Available Options and Values

The VTOY_DEFAULT_SEARCH_ROOT setting accepts a string representing a path on the Ventoy partition. The available options include:

  • Default Root Search (Unset or "/"): If the setting is omitted from ventoy.json, or if the value is set to "/", Ventoy maintains its standard behavior. It scans the root of the partition and all child directories across the entire drive.
  • Single Custom Directory Path (e.g., "/ISO"): Specifying a single folder path forces Ventoy to search only within that specific directory and any subdirectories inside it. Any bootable images stored outside this directory will be ignored.
  • Nested Directory Path (e.g., "/boot/images"): The setting supports deeper folder structures. Ventoy will begin its scan at the deepest specified directory, ignoring higher-level folders.

Syntax Requirements and Rules

When configuring VTOY_DEFAULT_SEARCH_ROOT, several structural rules must be followed:

  • Leading Slash: The path must begin with a forward slash (/), which represents the root directory of the Ventoy partition.
  • Path Separators: Always use forward slashes (/) as path separators, even when configuring the drive on Windows systems.
  • Trailing Slash: Trailing slashes are optional; "/ISO" and "/ISO/" are treated identically by the bootloader.
  • Case Sensitivity: While file systems like exFAT and NTFS are case-insensitive, matching the exact casing of the folder name is recommended to avoid parsing issues across different UEFI and BIOS implementations.

Configuration Example

Below is a standard implementation of the option inside the ventoy.json file:

{
    "control": [
        { "VTOY_DEFAULT_SEARCH_ROOT": "/ISO" }
    ]
}

In this setup, Ventoy only lists images located within /ISO and any directories inside it, preventing non-bootable ISOs or backup files stored elsewhere on the drive from appearing in the boot menu.
