Ventoy Multi Windows Unattended XML Injection

This article explains how Ventoy supports injecting unattended XML files across multiple Windows versions simultaneously on a single bootable drive. Through its built-in Auto Installation plugin, Ventoy allows users to link distinct autounattend.xml configuration files to specific Windows ISO images, ensuring hands-free, version-tailored installations without modifying the original installation media.

Multi-Version XML Support in Ventoy

Ventoy fully supports handling separate unattended answer files across multiple Windows versions simultaneously. Rather than enforcing a single global answer file, Ventoy uses image-path matching. This means a single USB drive can store installation media for Windows 10, Windows 11, and Windows Server editions, with each image triggering its own unique unattended XML file upon boot.

How It Works: The ventoy.json Configuration

Ventoy handles unattended deployments via the auto_install plugin defined inside the /ventoy/ventoy.json file. Within this file, you create an array that pairs the exact file path of a Windows ISO with the path to its corresponding XML answer file.

Here is a standard configuration example:

{
    "auto_install": [
        {
            "image": "/ISO/Windows_10_Pro.iso",
            "template": "/ventoy/script/win10_unattend.xml"
        },
        {
            "image": "/ISO/Windows_11_Enterprise.iso",
            "template": "/ventoy/script/win11_unattend.xml"
        },
        {
            "image": "/ISO/Windows_Server_2022.iso",
            "template": "/ventoy/script/winserver_unattend.xml"
        }
    ]
}

Steps to Set Up Simultaneous Unattended Installations

  1. Prepare Answer Files: Create your version-specific autounattend.xml files. Account for version-specific requirements, such as bypassing Windows 11 hardware checks or specifying distinct product keys.
  2. Directory Structure: Create a directory named ventoy in the root of the Ventoy partition. Within this folder, create a subfolder (such as script) to store your XML templates.
  3. Configure ventoy.json: Create or edit ventoy.json inside the ventoy folder. Define the auto_install block to map each Windows ISO located on your drive to its respective XML file.
  4. Boot and Install: When booting from the Ventoy USB drive, select the target Windows ISO. Ventoy will intercept the boot process, read the assigned XML file, and inject it as a virtual floppy drive or ramdisk into the Windows PE environment. Windows Setup automatically detects the injected file and proceeds with the automated installation.

Handling Multiple Configurations for a Single ISO

Ventoy also allows you to link an array of multiple XML templates to a single ISO. If multiple templates are defined for one image, Ventoy displays a menu at boot, prompting you to choose which XML file to inject (for example, selecting between an "Express Domain Join" or a "Standalone Local Admin" setup for the exact same Windows 11 ISO).
