How to Create a Ventoy Persistence Image

This guide explains how to create and configure a persistent storage image file for use with a Ventoy multi-boot USB drive. By adding a persistence image to supported Linux distributions, you can save system settings, installed packages, and personal files between reboots instead of resetting to a fresh live environment every time. The process involves generating a formatted .dat image file, placing it on your Ventoy partition, and configuring the ventoy.json file to map the image to your specific ISO.

1. Obtain or Generate the Persistence Image

Ventoy requires a pre-allocated .dat virtual disk image file with a specific filesystem and volume label (such as casper-rw for Ubuntu/Mint or persistence for Debian).

Option A: Using the Ventoy Script (Linux)

Ventoy provides an official shell script to generate customized persistence files.

  1. Download the latest Ventoy Linux installation package and extract it.
  2. Open a terminal and navigate to the extracted directory containing the CreatePersistentImg.sh script.
  3. Run the script with root privileges using the following syntax: 
    sudo bash CreatePersistentImg.sh -s <SIZE_IN_MB> -t <FS_TYPE> -l <LABEL>
    Example for Ubuntu (creates a 4GB ext4 image named persistence.dat labeled casper-rw): 
    sudo bash CreatePersistentImg.sh -s 4096 -t ext4 -l casper-rw
    Example for Debian/Kali (uses label persistence): 
    sudo bash CreatePersistentImg.sh -s 4096 -t ext4 -l persistence
  4. The output file persistence.dat will be created in the current working directory.

Option B: Using Pre-Configured Images (Windows or Linux)

If you are on Windows or prefer not to use the script, download pre-made empty persistence images directly from the Ventoy release assets.

  1. Download a pre-made persistence zip file corresponding to your distribution (for example, casper-rw.7z for Ubuntu-based distros).
  2. Extract the archive to retrieve the .dat file (e.g., casper-rw.dat).

2. Place the Image on Your Ventoy Drive

  1. Connect your Ventoy USB drive to your computer.
  2. In the root directory of the main data partition, create a dedicated folder to organize your images, such as persistence.
  3. Copy your .dat file into this folder (e.g., /persistence/ubuntu-persistence.dat).
  4. Ensure your Linux ISO is also present on the USB drive (e.g., /ISO/ubuntu-22.04-desktop-amd64.iso).

3. Configure the ventoy.json Configuration File

Ventoy maps persistence files to ISO images through a JSON configuration file.

  1. In the root directory of the Ventoy partition, create a folder named ventoy (must be lowercase).
  2. Inside the ventoy folder, create a new text file named ventoy.json.
  3. Add the persistence plugin configuration using exact file paths relative to the root of the USB drive:
{
    "persistence": [
        {
            "image": "/ISO/ubuntu-22.04-desktop-amd64.iso",
            "backend": "/persistence/ubuntu-persistence.dat"
        }
    ]
}

Note: Ensure all forward slashes are used for paths, and match the case-sensitive names of your files and directories.

4. Boot and Verify

  1. Reboot your computer and boot into the Ventoy USB drive.
  2. Select your Linux ISO from the menu.
  3. When prompted, select the persistence configuration option.
  4. Once booted into the live desktop, test persistence by creating a sample file or changing your wallpaper, then reboot to verify the changes remain intact.
