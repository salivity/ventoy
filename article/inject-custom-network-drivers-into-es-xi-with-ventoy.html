Inject Custom Network Drivers into ESXi with Ventoy

Installing VMware ESXi on hardware with consumer or unsupported network interface cards (NICs), such as Realtek or newer Intel chipsets, typically halts with a "No Network Adapters" error. Because Ventoy operates as an ISO-booting framework rather than an OS-level driver injection tool, you cannot pass raw driver files dynamically during boot. Instead, the solution requires slipstreaming the custom Community Networking Driver bundles into a modified ESXi installer ISO using VMware PowerCLI, and then deploying that customized ISO directly onto your Ventoy USB drive.

Step 1: Prepare the Driver and Tools

  1. Install VMware PowerCLI: Open PowerShell as Administrator on a Windows machine and install the PowerCLI module: 
    Install-Module -Name VMware.PowerCLI -Scope CurrentUser
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
  2. Download ESXi-Customizer-PS: Download the latest script from the official GitHub repository for ESXi-Customizer-PS. This script automates the VMware Image Builder process.
  3. Download the Custom Network Drivers: Download the required network driver offline bundle (a .zip file, not a .vib file). For consumer NICs (such as Realtek or Intel I219/I225), obtain the official VMware Community Networking Driver Offline Bundle from the VMware Flings repository. Place the downloaded .zip file into a local folder, such as C:\drivers.

Step 2: Generate the Custom ESXi ISO

Use ESXi-Customizer-PS to pull the base ESXi image from the VMware Online Depot and inject your custom driver bundle.

  1. Open PowerShell and navigate to the directory containing ESXi-Customizer-PS.ps1.

  2. Run the following command (replace the ESXi version and local path as necessary):

    .\ESXi-Customizer-PS.ps1 -esxiVersion 8.0U2 -pkgDir C:\drivers

    Note: If you have an existing official ESXi base ISO rather than pulling from the online repository, use -baseIso <path-to-iso> instead of -esxiVersion.

  3. The script will fetch the base depot, integrate the drivers located in C:\drivers, and generate a bootable ISO file (e.g., ESXi-8.0U2-custom.iso).

Step 3: Add the ISO to Ventoy

  1. Insert your prepared Ventoy USB drive into your system.
  2. Copy the newly generated custom ESXi ISO directly into the Ventoy partition.
  3. If you have an automated installation script (KS.CFG), you can also save it to the drive and configure Ventoy's ventoy.json plugin to auto-supply Kickstart parameters if required.

Step 4: Boot and Install

  1. Plug the Ventoy drive into the target host machine and enter the BIOS/UEFI boot menu.
  2. Select your Ventoy USB drive in UEFI mode (ESXi 7.x and 8.x strongly favor or require UEFI).
  3. Select your custom ESXi ISO from the Ventoy menu.
  4. When the ESXi boot menu appears, proceed with the standard installation. The installer will load the integrated VIBs during initial boot, detect your network adapter, and allow you to proceed with disk configuration and setup.
