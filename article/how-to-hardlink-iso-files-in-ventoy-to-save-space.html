How to Hardlink ISO Files in Ventoy to Save Space

You can hardlink identical ISO files in Ventoy to save storage space without causing boot errors, provided your Ventoy data partition uses a filesystem that supports hard links. Because a hard link creates an additional directory entry pointing to the exact same data clusters on disk, Ventoy detects and boots the linked file just like any standard ISO. However, because Ventoy formats drives with exFAT by default—a filesystem that lacks hard link support—you must configure the drive with an alternate filesystem such as NTFS or ext4 for this method to work.

Filesystem Compatibility Requirements

Ventoy's default partition format is exFAT, which does not support hard links. If you attempt to create a hard link on the default Ventoy partition, the operating system will return an error.

To use hard links:

  1. Reformat the Ventoy data partition (Partition 1) to NTFS (for Windows/Linux cross-compatibility) or ext4 (primarily for Linux). Ventoy supports custom filesystems natively during installation via its configuration menu.
  2. Ensure you do not modify the hidden VTOYEFI boot partition (Partition 2).

Why Hardlinks Do Not Cause Boot Errors

When Ventoy loads an ISO, it parses the filesystem table, identifies the cluster chain allocated to that file, and passes those raw disk sectors to its virtual disk mapper (or memdisk).

Because a hard link is not an alias or pointer file, but rather an independent directory reference sharing the exact same file attributes and data clusters (inode in Linux, Master File Table record in NTFS):

  • Zero Sector Duplication: The ISO data exists only once on the storage medium, saving full disk capacity for each duplicate reference.
  • Direct Sector Resolution: Ventoy reads the hard-linked file's physical sector locations directly from the partition table, exactly as it does with the original file.
  • Boot Integrity: The bootloader and kernel inside the ISO are unaware that the file is hardlinked, preventing path resolution failures or runtime boot errors.

Creating Hardlinks for Ventoy

Once your Ventoy drive is formatted with NTFS or ext4, you can organize your boot menu using identical ISOs with different filenames or directory structures without using extra space.

  • On Windows (NTFS): Open Command Prompt as Administrator and run: mklink /H "E:\ISO\Duplicate.iso" "E:\ISO\Original.iso"

  • On Linux (NTFS or ext4): Open a terminal and run: ln /media/ventoy/ISO/Original.iso /media/ventoy/ISO/Duplicate.iso

Hardlinks vs. Symlinks in Ventoy

Hard links are superior to symbolic links (symlinks) for this specific use case. While Ventoy has partial support for resolving relative symbolic links, broken targets or absolute system paths can cause boot failures. Hard links bypass filesystem link resolution entirely at runtime, making them completely transparent to Ventoy and entirely safe from boot-time errors.
