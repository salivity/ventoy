How to Auto Boot a Specific ISO in Ventoy

Yes, Ventoy can be configured to automatically boot into a specific ISO image after a designated timeout period. This functionality is handled through Ventoy's Global Control plugin, which allows you to define custom boot behaviors using a simple JSON configuration file. By designating a default image path and a countdown duration in seconds, Ventoy will display the boot menu, count down, and automatically launch your chosen ISO if no manual input is detected.

Creating the Configuration File

To set up an automated boot, you must create a configuration file named ventoy.json inside a folder named ventoy located in the root of your Ventoy USB drive's data partition.

  1. Open your Ventoy USB drive in your file manager.
  2. In the root directory, create a new folder named ventoy (all lowercase).
  3. Inside the ventoy folder, create a text file named ventoy.json.

Configuring the JSON Settings

Open the ventoy.json file in any text editor and add the control configuration block. You must specify the default_file parameter with the exact path to your ISO, along with the timeout parameter set to your desired countdown in seconds.

Here is an example configuration:

{
    "control": [
        {
            "default_file": "/isos/ubuntu-22.04.iso",
            "timeout": 10
        }
    ]
}

Configuration Details

  • default_file: Defines the absolute path to the ISO file on your USB drive. Always use forward slashes (/), start with a leading slash, and ensure the file name and directory names match the exact casing of your files on the drive.
  • timeout: Specifies the countdown duration in seconds. For instance, setting "timeout": 10 gives the user 10 seconds to manually select an alternate entry before the default ISO automatically boots. If set to 0, the menu will boot the designated ISO immediately without waiting.

Save the file after editing. The next time you boot your computer from the Ventoy USB drive, the countdown timer will begin immediately on the menu screen, launching your default file once the timer reaches zero.
