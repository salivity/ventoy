Ventoy MOK Manager Certificate for Secure Boot

To use Ventoy on a system with UEFI Secure Boot enabled, you must enroll Ventoy’s custom Machine Owner Key (MOK) named ENROLL_THIS_KEY_IN_MOKMANAGER.cer. This article explains the purpose of this specific certificate, where it is located, and the exact steps required to register it using the UEFI MOK Manager so you can boot ISO files without disabling Secure Boot in your motherboard's firmware.

The Required Certificate

When booting Ventoy with Secure Boot enabled, the UEFI firmware rejects Ventoy's bootloader because its binary is not signed directly by Microsoft. Instead, Ventoy relies on the open-source shim loader. To authorize Ventoy, you must enroll the ENROLL_THIS_KEY_IN_MOKMANAGER.cer certificate into your system's NVRAM via the MOK Manager.

This certificate is built directly into the hidden VTOYEFI system partition on your Ventoy USB drive and is also accessible via the main Ventoy data partition.

Step-by-Step Enrollment Process

Enrolling the key is a one-time process per machine. Once registered, the motherboard will trust the Ventoy bootloader on future boots.

  1. Trigger the MOK Manager
    Insert your Ventoy USB drive and boot your computer. When Secure Boot detects the untrusted bootloader, it will display a blue or black screen stating a security violation (e.g., Verification failed: (0x1A) Security Violation). Press Enter or any key to launch the Shim UEFI Key Management interface.

  2. Select Enroll Key from Disk
    From the main MOK Management menu, choose Enroll key from disk (or Enroll MOK depending on the shim version).

  3. Locate the Certificate
    Select the Ventoy partition from the list of available storage devices (often labeled with VTOY or VTOYEFI). Navigate through the directory list until you see ENROLL_THIS_KEY_IN_MOKMANAGER.cer, highlight it, and press Enter.

  4. Confirm and Enroll
    Select View Key if you wish to inspect the key details, or proceed directly to Continue. When prompted with Enroll the key(s)?, select Yes.

  5. Reboot the System
    Return to the main MOK menu and select Reboot.

After restarting, your system will recognize the Ventoy signature and load the standard Ventoy boot menu while keeping UEFI Secure Boot fully active and protecting your operating systems.
