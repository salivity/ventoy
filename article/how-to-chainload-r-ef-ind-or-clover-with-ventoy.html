How to Chainload rEFInd or Clover with Ventoy

Ventoy can successfully chainload alternative UEFI bootloaders such as rEFInd and Clover. Because Ventoy operates primarily as an advanced GRUB2-based environment, it provides multiple mechanisms to hand off system control to other EFI executables or bootable disk images. This guide explains whether chainloading is possible, how the process works, and the most effective methods to configure rEFInd or Clover alongside Ventoy.

How Chainloading Works in Ventoy

When your computer starts in UEFI mode, the motherboard firmware executes Ventoy’s primary EFI binary. From this environment, Ventoy can launch other .efi applications directly from the storage drive, pass control via custom GRUB configuration scripts, or boot pre-packaged raw disk images containing rEFInd or Clover.

Method 1: Direct EFI Launching

The simplest way to chainload another bootloader is by running its executable directly:

  1. Download the standalone EFI binary for rEFInd (refind_x64.efi) or Clover (BOOTX64.EFI).
  2. Copy the file into your Ventoy data partition (the partition where you store ISOs). You can place it in a dedicated directory, such as /EFI/refind/.
  3. Boot your machine using the Ventoy USB drive.
  4. Press F6 to enter Ventoy’s file browser mode.
  5. Navigate to the folder containing the .efi file and select it. Ventoy will execute the binary and launch the selected bootloader interface.

Method 2: Bootable ISO or IMG Container

Both rEFInd and Clover distribute pre-built bootable image files (such as .iso or .img files).

  1. Download the official USB image or ISO file for rEFInd or Clover.
  2. Place the image file directly on the Ventoy partition alongside your other operating system ISOs.
  3. Boot the computer using the Ventoy drive and select the rEFInd or Clover image from the main list.
  4. Ventoy will map the virtual drive and boot straight into the target environment.

Method 3: Custom GRUB Menu Integration

To automate the chainloading process without manually browsing files on each boot, use Ventoy's custom menu extension:

  1. Inside the Ventoy partition, create a directory named ventoy.
  2. Inside the ventoy folder, create a plain text file named ventoy_grub.cfg.
  3. Add a GRUB chainloader entry pointing to your bootloader's EFI file:
menuentry "Chainload rEFInd" {
    insmod chain
    search --no-floppy --set=root --file /EFI/refind/refind_x64.efi
    chainloader /EFI/refind/refind_x64.efi
}

When you boot into Ventoy, press F6 to open the custom menu and select your chainloader entry.

Important Configuration Requirements

  • UEFI Mode Only: Both rEFInd and modern Clover builds are designed for UEFI systems. Ensure your machine is set to UEFI boot mode rather than Legacy BIOS.
  • Secure Boot: If Secure Boot is enabled, the secondary bootloader must be signed with a trusted key, or you must enroll its hash using Ventoy's built-in MOK (Machine Owner Key) manager. Alternatively, disable Secure Boot in your motherboard's firmware settings.
