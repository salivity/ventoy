Change Font Size in Ventoy Boot Menu

This guide explains how to adjust the font size displayed in the Ventoy boot menu. Because Ventoy utilizes a GRUB2-based graphical interface, the text size cannot be toggled with a simple switch inside the bootloader itself. Instead, you can change the text size by either modifying the screen resolution in your configuration file or by generating and applying a custom GRUB font file (.pf2) with your desired point size inside a Ventoy theme.

Method 1: Adjusting Screen Resolution (Quickest Method)

Lowering the display resolution automatically scales up the font and menu elements, while increasing the resolution makes the text smaller.

  1. Open your Ventoy USB drive in your file manager.
  2. Navigate to the ventoy folder. If it does not exist, create a folder named ventoy in the root of the partition.
  3. Open or create a file named ventoy.json.
  4. Add or update the resolution property under the theme configuration block:
{
    "theme": {
        "display_mode": "GUI",
        "resolution": "1024x768"
    }
}
  • For larger text on modern high-DPI displays, set the resolution to a lower value such as 1024x768 or 800x600.
  • For smaller text, use higher values like 1920x1080.
  • Save the file and reboot to test the changes.

Method 2: Applying a Custom Font Size via a Theme

To change the absolute font point size without lowering screen resolution, you must generate a .pf2 font file and declare it within a custom theme.

Step 1: Generate a GRUB Font File

GRUB2 themes require fonts in the .pf2 format. You can generate one on Linux using the grub-mkfont utility.

Run the following command in a terminal, adjusting the size (-s) and the font path as needed:

grub-mkfont -s 24 -o custom-font-24.pf2 /usr/share/fonts/truetype/dejavu/DejaVuSans.ttf

This creates a font file with a 24-point size.

Step 2: Add the Font to Your Theme

  1. Place the generated .pf2 file into your Ventoy theme folder (for example, /ventoy/theme/my-theme/custom-font-24.pf2).
  2. Open the theme.txt file located inside your theme's directory.
  3. Add the font declaration near the top of the file:
loadfont custom-font-24.pf2
  1. Locate the + boot_menu section in theme.txt and update the font properties:
+ boot_menu {
    item_font = "DejaVu Sans Regular 24"
    item_color = "#cccccc"
    selected_item_color = "#ffffff"
}

Step 3: Link the Theme in ventoy.json

Ensure Ventoy is instructed to load your modified theme. In /ventoy/ventoy.json, add the path to your theme.txt:

{
    "theme": {
        "file": "/ventoy/theme/my-theme/theme.txt"
    }
}

Once saved, boot from the USB drive to view your updated font size at full resolution.
