How Ventoy Handles Secure Boot Out of the Box

Ventoy provides built-in support for UEFI Secure Boot out of the box, allowing users to boot various ISO, WIM, and IMG files without permanently disabling Secure Boot in their system's BIOS/UEFI settings. By default, the Secure Boot option is enabled during the Ventoy USB creation process. To satisfy UEFI security checks without official Microsoft-signed binaries for its internal payloads, Ventoy utilizes the standard shim bootloader and the Machine Owner Key (MOK) architecture, requiring a simple, one-time key enrollment on the target machine.

The Default Configuration

When you format a flash drive using Ventoy, the "Secure Boot Support" option is toggled on by default. Ventoy configures the drive with two partitions: an exFAT/NTFS data partition for storing ISO images and a hidden FAT16 system partition (VTOYEFI) containing the necessary bootloader binaries and security certificates.

The Shim and MOK Mechanism

Because Ventoy’s custom bootloader is not directly signed by Microsoft's UEFI Certificate Authority, it cannot boot directly on a Secure Boot-enabled system without intervention. To resolve this, Ventoy incorporates:

  1. A Signed Shim: An initial bootloader signed by a trusted authority that the UEFI firmware accepts.
  2. Ventoy’s Custom Certificate: A distinct digital signature used to sign the primary Ventoy core files.
  3. MokManager: An open-source EFI utility used to register user-approved keys into the system’s NVRAM.

The First-Time Boot Process

When booting a Ventoy drive on a Secure Boot system for the first time, the UEFI firmware detects an unrecognized signature and launches the MokManager screen (often displaying a "Verification failed" or "Perform MOK management" prompt). The user must complete a one-time enrollment:

  1. Select Enroll key from disk.
  2. Navigate to the VTOYEFI partition.
  3. Select the file named ENROLL_KEY.DER.
  4. Confirm the enrollment and select Continue or Reboot.

Once this key is registered into the motherboard's Machine Owner Key database, the system permanently trusts Ventoy's boot files.

Subsequent Boots

After the initial enrollment, subsequent boots bypass the MokManager interface entirely. The UEFI firmware recognizes the trusted key stored in its NVRAM, immediately loading the Ventoy menu and any selected operating system images without triggering security warnings. If the USB drive is moved to a different computer with Secure Boot enabled, the enrollment process must be repeated once for that specific machine.
