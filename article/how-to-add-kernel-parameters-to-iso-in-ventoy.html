How to Add Kernel Parameters to ISO in Ventoy

Yes, you can add custom kernel parameters to a Linux ISO before booting it in Ventoy. This can be accomplished either temporarily during the boot process using Ventoy's built-in GRUB interface or permanently by configuring Ventoy's custom configuration files or modifying the ISO itself.

Method 1: Add Parameters Temporarily at Boot

The fastest way to test or apply one-time boot parameters (such as nomodeset, single, or hardware-specific flags) is through the bootloader menu.

  1. Boot your computer from the Ventoy USB drive.
  2. Navigate to the Linux ISO you wish to run and press Enter.
  3. Select Boot in normal mode.
  4. When the Linux distribution's bootloader menu appears (usually GRUB or Syslinux), highlight the desired boot option.
  5. Press e (in GRUB) or Tab (in Syslinux) to edit the boot parameters.
  6. Locate the line starting with linux, linuxefi, or vmlinuz.
  7. Move the cursor to the end of that line, type a space, and append your custom kernel parameters (e.g., nomodeset).
  8. Press Ctrl + X or F10 to boot the system with the modified parameters.

Method 2: Add Parameters Permanently Using ventoy_grub.cfg

If you require persistent custom parameters without re-typing them every time, you can create a custom GRUB menu in Ventoy.

  1. Open your Ventoy USB drive in your operating system's file manager.
  2. Navigate to the ventoy folder in the root of the USB drive (create the folder if it does not exist).
  3. Create a plain text file named ventoy_grub.cfg inside the ventoy directory.
  4. Add a custom boot entry pointing to your ISO with your desired kernel arguments:
menuentry "Ubuntu Live (Custom Parameters)" {
    set iso_path="/ubuntu-22.04-desktop-amd64.iso"
    loopback loop $iso_path
    linux (loop)/casper/vmlinuz boot=casper iso-scan/filename=$iso_path nomodeset quiet splash ---
    initrd (loop)/casper/initrd
}
  1. Save the file.
  2. When booting Ventoy, press F6 to load the custom menu defined in ventoy_grub.cfg and select your custom entry.

Method 3: Modify the ISO Directly

For distributions where automated configuration is necessary across multiple machines:

  1. Extract the ISO contents using a tool like xorriso or 7-Zip.
  2. Locate the bootloader configuration file (commonly /boot/grub/grub.cfg or /isolinux/isolinux.cfg).
  3. Open the file in a text editor, find the default boot entry, and add your parameters to the kernel launch line.
  4. Repack the files into a bootable ISO image using an ISO creation tool (such as xorriso or mkisofs).
  5. Copy the newly modified ISO to your Ventoy USB drive.
