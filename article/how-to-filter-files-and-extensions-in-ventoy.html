How to Filter Files and Extensions in Ventoy

This article explains how to filter out specific file extensions and naming patterns in Ventoy using the ventoy.json configuration file. It details the primary image_blacklist plugin used to match wildcards and extensions, highlights the specialized VTOY_FILE_FLT_EFI global control option, and provides configuration examples to help you customize which bootable files appear in your Ventoy menu.

The image_blacklist Setting

The primary setting in ventoy.json for filtering out specific file extensions, directories, or naming patterns is the image_blacklist plugin.

By default, Ventoy recursively scans your drive and lists every compatible image file it discovers (such as .iso, .wim, .img, .vhd, .vhdx, and .efi). Adding paths or wildcard strings to the image_blacklist array instructs Ventoy to ignore any matching files during boot menu generation.

Syntax and Wildcards

The image_blacklist setting accepts an array of strings. You can use standard wildcard characters:

  • An asterisk (*) matches zero or more characters, allowing you to filter out specific file extensions (e.g., *.wim) or naming patterns (e.g., *backup*).
  • Absolute paths can be used to target specific directories or single files.

Configuration Example

Create or edit the ventoy.json file inside the ventoy directory on your Ventoy drive's first partition (e.g., /ventoy/ventoy.json):

{
    "image_blacklist": [
        "*.wim",
        "*.vhd",
        "*test*",
        "/ISO/Private/*"
    ]
}

In this example:

  • All files ending in .wim or .vhd are hidden from the menu.
  • Any image file containing the word test anywhere in its filename or path is ignored.
  • All image files located in the /ISO/Private/ directory are excluded.

Filtering .efi Files with VTOY_FILE_FLT_EFI

If your goal is specifically to filter out standalone .efi files without writing wildcard patterns, Ventoy provides a dedicated setting in the control section called VTOY_FILE_FLT_EFI.

By default, Ventoy lists valid .efi files found on the partition. Setting VTOY_FILE_FLT_EFI to 1 hides all .efi files automatically.

Configuration Example

{
    "control": [
        {
            "VTOY_FILE_FLT_EFI": 1
        }
    ]
}
  • Value 1: Filter out and hide all .efi boot files.
  • Value 0: Allow .efi files to appear in the menu (default behavior).

Using image_list for Whitelisting

If you prefer to define strictly which files are permitted rather than filtering out unwanted ones, use the image_list setting. When image_list is defined, Ventoy only displays the exact files or matching patterns declared in the list, hiding everything else:

{
    "image_list": [
        "/ISO/Ubuntu-22.04.iso",
        "/ISO/Windows-11.iso"
    ]
}

Configuration Best Practices

  1. JSON Formatting: Ensure ventoy.json uses valid JSON syntax. Trailing commas after the last array item will cause parsing errors.
  2. File Location: The file must reside at /ventoy/ventoy.json on the main data partition (Ventoy partition 1).
  3. Case Sensitivity: Wildcard matches within image_blacklist are generally case-insensitive, but maintaining exact casing matching your actual filesystem names ensures consistent behavior across different hardware platforms.
