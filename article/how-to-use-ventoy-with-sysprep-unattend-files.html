How to Use Ventoy with Sysprep Unattend Files

Ventoy allows you to automate Windows deployments using custom sysprep or autounattend.xml files without modifying the original ISO image. By leveraging Ventoy's native Auto Install Plugin, you can map specific answer files to your Windows installation media through a central configuration file. This guide explains how to structure your USB drive, configure ventoy.json, and deploy an unattended Windows installation.

Step 1: Prepare Your Directory Structure

Navigate to the root of your Ventoy USB drive (the main partition where ISO files are stored). Create a folder named ventoy if it does not already exist, and create a subfolder named script inside it to keep your answer files organized.

The directory layout should look like this:

USB_ROOT/
├── ISO/
│   └── Win11_23H2.iso
└── ventoy/
    ├── ventoy.json
    └── script/
        └── autounattend.xml

Step 2: Add Your Sysprep Unattend File

Place your customized sysprep or answer file into the USB_ROOT/ventoy/script/ directory. Ensure the file is named clearly (e.g., autounattend.xml or win11_unattend.xml). The XML file should contain standard Windows Setup configuration passes, such as windowsPE, specialize, and oobeSystem.

Step 3: Configure ventoy.json

Ventoy reads automated deployment directives from a file named ventoy.json located inside the USB_ROOT/ventoy/ directory.

Create or edit ventoy.json and add the auto_install section to map your Windows ISO path to the corresponding answer file. Use forward slashes (/) for all paths:

{
    "auto_install": [
        {
            "image": "/ISO/Win11_23H2.iso",
            "template": "/ventoy/script/autounattend.xml"
        }
    ]
}

If you have multiple ISOs or want to assign multiple templates to a single ISO, you can pass an array of file paths to the template key:

{
    "auto_install": [
        {
            "image": "/ISO/Win11_23H2.iso",
            "template": [
                "/ventoy/script/autounattend_work.xml",
                "/ventoy/script/autounattend_home.xml"
            ]
        }
    ]
}

Step 4: Boot and Deploy

  1. Insert the configured USB drive into the target computer and boot to Ventoy.
  2. Select the Windows ISO defined in your configuration.
  3. If you configured a single template, Ventoy will automatically inject the unattend.xml into the Windows Preinstallation Environment (WinPE) memory space during the boot phase.
  4. If you configured multiple templates, Ventoy will prompt you to choose which answer file to load before booting the setup.
  5. Windows Setup will launch and execute the automation passes defined in your sysprep file without manual intervention.
