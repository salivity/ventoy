How to Separate Client Files on a Ventoy Drive

Technicians frequently use Ventoy to consolidate multiple operating system installers and utility ISOs onto a single USB drive. However, storing client backups, driver packages, and recovery data alongside bootable installation media can quickly lead to menu clutter and accidental data exposure. This guide outlines the most effective methods to cleanly separate and secure client files from boot media on a Ventoy drive, utilizing partition splitting, directory isolation flags, and custom configuration files.

Method 1: Create a Dedicated Data Partition

The most secure and organized approach is to isolate client data onto its own dedicated partition. By separating the storage environments, you prevent operating system installers from touching client data and keep your backup tools isolated.

  1. Reserve Space During Installation: When initially formatting your USB drive with the Ventoy GUI tool, open the Option menu and select Partition Configuration. Check the box to reserve space at the bottom of the drive and specify the amount of gigabytes you need for client files.
  2. Format the Reserved Space: Once Ventoy finishes installing, open your operating system’s disk manager (such as Windows Disk Management or GParted on Linux). Locate the unallocated reserved space at the end of the drive, create a new partition, and format it with your desired filesystem (NTFS or exFAT).
  3. Label the Partitions: Name the default Ventoy boot partition something clear, such as VENTOY_BOOT, and label the second partition CLIENT_DATA. Ventoy will strictly ignore the secondary partition unless you explicitly configure it otherwise.

Method 2: Use the .ventoyignore Directory Flag

If you prefer to keep all files on a single partition without repartitioning the drive, you can prevent Ventoy from scanning specific folders for bootable media.

  1. Navigate to the root directory of your Ventoy drive in your file manager.
  2. Create a dedicated folder for client files, such as Client_Backups or Technician_Tools.
  3. Open that folder, create a blank text document, and rename it exactly to .ventoyignore (ensuring there is no hidden .txt extension).
  4. Place all client files, diagnostic logs, and temporary storage inside this directory. Ventoy will skip this folder entirely during its boot-time ISO scan, keeping your boot menu clean and responsive.

Method 3: Restrict Ventoy Scanning Paths via ventoy.json

For complete control over where Ventoy looks for bootable images, you can configure the bootloader to scan only one specific folder.

  1. In the root of your Ventoy drive, create a folder named ventoy (all lowercase).
  2. Inside the ventoy folder, create a plain text file named ventoy.json.
  3. Create a separate folder in the root of the drive exclusively for your bootable media, such as /ISOs.
  4. Open ventoy.json in a text editor and add the following configuration:
{
    "control": [
        { "ventoy_search_path": ["/ISOs"] }
    ]
}

By defining the ventoy_search_path, Ventoy will ignore any other folder in the root directory. You can then create standard folders for client files anywhere outside the /ISOs directory without fear of boot menu interference.
