Can Ventoy Boot Antivirus Rescue Disks?

Ventoy fully supports booting live antivirus rescue disks directly from their standard ISO files, including Kaspersky Rescue Disk, ESET SysRescue Live, and many others. This article explains how Ventoy handles these security tools, covers compatibility and configuration details such as Secure Boot and database persistence, and provides instructions for setting up a multi-boot malware removal USB drive.

Compatibility with Major Rescue Disks

Most modern antivirus rescue environments are built on specialized Linux distributions. Because Ventoy operates by directly hooking into the boot process and reading ISO files into memory without unpacking them, it natively boots the vast majority of antivirus rescue environments.

Kaspersky Rescue Disk (KRD)

Kaspersky Rescue Disk is built on Gentoo Linux and runs reliably through Ventoy in both Legacy BIOS and UEFI boot modes.

  • Boot Options: You can select standard graphic mode or limited graphic mode if hardware acceleration issues occur.
  • Database Updates: By default, Kaspersky can use your computer's local hard drive or a separate USB storage location to temporarily save downloaded virus definitions.

ESET SysRescue Live

ESET SysRescue Live is built on an Ubuntu base and functions without modification via Ventoy.

  • Boot Options: It supports standard live booting into a lightweight desktop environment.
  • Database Updates: Once booted and connected to the internet, ESET can download the latest threat signatures directly into memory for scanning.

Other Supported Rescue Disks

Ventoy also supports numerous other emergency disks, including:

  • Bitdefender Rescue CD
  • Avira Rescue System
  • Trend Micro Rescue Disk
  • Dr.Web LiveDisk
  • Comodo Rescue Disk

Key Considerations for Booting Rescue Disks

While booting these tools is straightforward, two specific factors require attention:

Secure Boot Settings

Certain rescue environments use custom Linux kernels or bootloaders that are not signed by Microsoft. If your computer has UEFI Secure Boot enabled, the rescue disk might fail to launch. To resolve this:

  • Disable Secure Boot in your motherboard's UEFI/BIOS settings before scanning.
  • Alternatively, enable Ventoy's built-in Secure Boot support, which uses MokManager to enroll the Ventoy key during the first boot.

Virus Definition Persistence

When an antivirus ISO boots from Ventoy, it runs primarily in a read-only live session in RAM. Any virus definitions downloaded during that session will be erased when the system reboots. To address this:

  • Internet Connection: Connect the target machine via Ethernet or Wi-Fi immediately after booting to download the latest definitions into memory before running a scan.
  • Ventoy Persistence Plugin: For advanced users, Ventoy supports a persistence plugin that links a persistent image file (.dat) to compatible Linux-based ISOs, allowing updates to be preserved across reboots.

How to Set Up an Antivirus Rescue USB with Ventoy

  1. Install Ventoy: Format and prepare your USB drive using the official Ventoy installer.
  2. Download ISOs: Obtain the latest live rescue ISO files directly from official antivirus vendor websites.
  3. Copy Files: Drag and drop the downloaded .iso files onto the main Ventoy USB partition. Do not extract or alter the files.
  4. Boot and Scan: Insert the USB drive into the target computer, select the USB drive from the hardware boot menu, choose your desired antivirus rescue disk from the Ventoy list, and initiate the malware scan.
