Ventoy Multi-ISO Persistence Setup Guide

Ventoy fully supports linking distinct persistence images to multiple ISO files on the exact same USB drive. By utilizing Ventoy's native plugin architecture through a simple JSON configuration file, you can assign dedicated .dat storage images to individual Linux distributions. This allows each operating system to retain files, installed packages, and configuration changes across reboots independently without conflict.

How Multi-ISO Persistence Works in Ventoy

Ventoy separates the read-only boot image (the ISO) from the writable data layer (the persistence image). To make multiple persistent distributions coexist, you create a dedicated persistence container for each distribution and configure Ventoy to match each ISO with its corresponding storage file using a configuration file named ventoy.json.

Step 1: Create the Persistence Image Files

Each operating system requires its own persistence image file. Ventoy provides tools to generate these .dat files with the correct label and file system.

  1. Download the Ventoy persistence plugin files or use the included script (CreatePersistentImg.sh on Linux or VentoyPlugson on Windows).
  2. Generate an image file for each distribution, sizing it according to your needs (e.g., 4GB, 8GB):
    • Ubuntu / Linux Mint: Requires the label casper-rw.
    • Debian / Kali Linux: Requires the label persistence.
    • Fedora: Requires the label overlay-live.
  3. Rename the output files with clear names so they do not overwrite each other (e.g., ubuntu_persistent.dat and kali_persistent.dat).

Step 2: Organize the USB Directory Structure

Place the generated .dat files and your ISO files on the main partition of your Ventoy USB drive. While you can place files anywhere, an organized directory makes management easier:

/ (Ventoy Partition Root)
├── ISO/
│   ├── ubuntu-22.04-desktop-amd64.iso
│   └── kali-linux-live-amd64.iso
├── persistence/
│   ├── ubuntu_persistent.dat
│   └── kali_persistent.dat
└── ventoy/
    └── ventoy.json

Step 3: Configure ventoy.json

Create a folder named ventoy in the root of the USB drive (lowercase only) if it does not already exist. Inside this folder, create a text file named ventoy.json.

Open ventoy.json in a text editor and define the persistence block. Use an array to map each ISO path to its corresponding image path:

{
    "persistence": [
        {
            "image": "/ISO/ubuntu-22.04-desktop-amd64.iso",
            "backend": "/persistence/ubuntu_persistent.dat"
        },
        {
            "image": "/ISO/kali-linux-live-amd64.iso",
            "backend": "/persistence/kali_persistent.dat"
        }
    ]
}

Key Rules for Configuration:

  • Paths are case-sensitive and must start from the root of the partition (/).
  • Use forward slashes (/), even if editing on Windows.
  • Multiple persistence files can also be mapped to a single ISO as an array, prompting Ventoy to ask which persistence profile to boot into.

Alternative: Using VentoyPlugson

If you prefer not to write JSON manually, run the VentoyPlugson executable included in the Ventoy download package.

  1. Insert the USB drive and run VentoyPlugson.exe (Windows) or the script (Linux).
  2. Click Start to open the local web-based configuration GUI.
  3. Navigate to the Persistence Plugin section.
  4. Select your ISO files and link them to their respective .dat images using the visual file picker.
  5. The tool will automatically format and update the ventoy.json file for you.

Verification and Booting

Once configured, safely eject the drive and boot into it. When you select an ISO configured with persistence, Ventoy will automatically attach the mapped .dat file during boot. Any files saved to the desktop or system changes made during that session will be saved strictly to that ISO's assigned image file.
