How to Alias Long ISO Filenames in Ventoy

Ventoy allows users to replace long, cluttered ISO filenames with clean, readable titles in the boot menu using its native menu_alias plugin. While Ventoy does not inherently parse and invent dynamic titles on the fly without configuration, it provides a robust system through a JSON configuration file where you can map filenames to human-readable labels, or utilize automated scripts to generate dynamic aliases programmatically.

How the Ventoy Menu Alias Plugin Works

By default, Ventoy scans the USB drive and displays the exact filename of each ISO, WIM, or IMG file. Distributions often release ISOs with long names containing build numbers, architecture strings, and release dates.

Ventoy solves this through the ventoy.json configuration file located in the ventoy directory on the first partition of your USB drive. Within this file, the menu_alias array maps full paths or file names directly to user-defined display strings.

Configuring Aliases in ventoy.json

To set up aliases, create a folder named ventoy at the root of your Ventoy USB drive (if it does not already exist) and place a file named ventoy.json inside it.

Here is a standard configuration example:

{
    "menu_alias": [
        {
            "image": "/ISO/ubuntu-22.04.3-desktop-amd64.iso",
            "alias": "Ubuntu 22.04 LTS (Desktop)"
        },
        {
            "image": "/ISO/Win11_23H2_English_x64v2.iso",
            "alias": "Windows 11 23H2 64-bit"
        },
        {
            "image": "/ISO/archlinux-2024.01.01-x86_64.iso",
            "alias": "Arch Linux (Latest)"
        }
    ]
}

When Ventoy loads, it reads this configuration and displays the specified alias instead of the raw file path, while preserving the original boot behavior.

Handling Dynamic Aliases

Ventoy does not have a native regex engine or dynamic pattern replacer built directly into the bootloader to strip out build dates or version numbers automatically. However, you can achieve dynamic aliasing through the following methods:

1. Automated Script Generation

Because ventoy.json is a standard JSON file stored on a writable FAT32 or exFAT partition, you can use a local script (such as PowerShell, Bash, or Python) to dynamically parse ISO names and rewrite ventoy.json. For example, a script can scan the /ISO/ directory, identify OS signatures, trim unnecessary metadata strings, and output the updated alias mappings automatically whenever you add new files.

2. Ventoy Auto Memdisk and Variable Aliasing

If you use Ventoy's auto-installation or custom boot scripts, you can tie into Ventoy's secondary boot menus or Grub-based configurations (ventoy_grub.cfg) to script dynamic menu entries using GNU GRand Unified Bootloader (GRUB) syntax, which does support variables and string manipulation.

Summary

Ventoy supports aliases out of the box through its menu_alias plugin in ventoy.json. While the configuration itself requires explicit mappings, pairing this feature with an automated sync script offers a fully dynamic, clean boot menu for systems with frequently updated ISO files.
