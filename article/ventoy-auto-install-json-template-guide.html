Ventoy Auto Install JSON Template Guide

The ventoy-auto-install.json format—more commonly implemented via the auto_install section within the master ventoy.json file—is a structured JSON configuration used by the Ventoy bootloader to automate operating system installations. It maps specific ISO disk images to unattended setup configuration scripts (such as Windows unattend.xml, Linux Kickstart files, or Debian preseed files), allowing operating systems to install without user interaction.

File Location and Integration

To apply unattended installation templates, the configuration resides on the first partition of the Ventoy USB drive inside the /ventoy/ directory. While standalone reference files can be named ventoy-auto-install.json, Ventoy reads the active configuration directly from /ventoy/ventoy.json under the "auto_install" root array.

Basic JSON Structure

The schema consists of a root object containing an "auto_install" array. Each object within this array defines an ISO image path and the associated template file.

{
    "auto_install": [
        {
            "image": "/ISO/Windows_11.iso",
            "template": "/ventoy/script/windows_unattend.xml"
        },
        {
            "image": "/ISO/CentOS-8.iso",
            "template": "/ventoy/script/centos_ks.cfg"
        }
    ]
}

Supported Properties

  • image (String): Defines the full path to the image file relative to the root of the USB drive (for example, /ISO/ubuntu-22.04.iso). This field supports exact file paths, directory matching, and directory wildcards (such as /ISO/Windows/*.iso).
  • template (String or Array): Specifies the path to the unattended script or answer file. When set as a string, Ventoy immediately applies that single template. When set as an array of strings, Ventoy prompts the user with a menu to select the desired configuration at boot time.
  • autosel (Integer, Optional): Used only when template is an array. It specifies the default 1-based index of the template to select automatically when the menu appears.
  • timeout (Integer, Optional): Defines the countdown in seconds before the default selection chosen by autosel is automatically applied.

Multiple Template Configuration Example

When deploying multiple environments from a single installer, multiple scripts can be assigned to an image:

{
    "auto_install": [
        {
            "image": "/ISO/Ubuntu-22.04-Server.iso",
            "template": [
                "/ventoy/script/ubuntu_minimal.yaml",
                "/ventoy/script/ubuntu_full.yaml"
            ],
            "autosel": 1,
            "timeout": 10
        }
    ]
}

Compatible Template Types

Ventoy injects the template into the boot environment dynamically depending on the detected operating system:

  • Windows: Unattended XML files (Autounattend.xml or custom answer files).
  • Red Hat / CentOS / Fedora: Kickstart files (.ks or .cfg).
  • Debian / Ubuntu (Legacy): Preseed files (.seed or .cfg).
  • Ubuntu (Subiquity / Modern): Cloud-init user-data autoinstall files.
  • SUSE / openSUSE: AutoYaST XML profiles.
