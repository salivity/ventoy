Does Ventoy Support MS-DOS and FreeDOS Booting?

Ventoy provides full support for booting older legacy operating systems such as MS-DOS and FreeDOS, making it an effective multi-boot tool for running vintage software, legacy diagnostics, and hardware firmware flashing utilities. This article outlines how Ventoy handles these 16-bit environments, the file formats supported, critical hardware requirements, and the recommended settings needed for a successful boot.

Supported File Formats

Ventoy does not limit users to standard CD or DVD ISO files. To accommodate legacy operating systems that historically ran from floppies or small hard drives, Ventoy supports several image formats:

  • ISO Images: Standard FreeDOS installer and Live CDs.
  • Floppy Images (.IMG, .IMA): Raw 1.44MB or 2.88MB floppy disk images commonly used for MS-DOS boot disks.
  • Virtual Hard Disks (.VHD): Fixed-size disk images containing DOS installations.

Hardware and Firmware Requirements

While Ventoy supports modern UEFI environments, MS-DOS and FreeDOS are 16-bit real-mode operating systems that fundamentally cannot run on pure UEFI systems. To boot them via Ventoy:

  1. Enable CSM/Legacy Boot: You must enter your motherboard's BIOS/UEFI settings and enable the Compatibility Support Module (CSM) or Legacy Boot mode.
  2. Boot Ventoy in BIOS Mode: Select the non-UEFI entry for your Ventoy USB drive from your system's boot menu. If you boot Ventoy in UEFI mode, DOS images will fail to initialize.

Utilizing Memdisk Mode

Because DOS-based images rely on legacy BIOS interrupt calls (such as INT 13h) for disk access, they often cannot locate a virtual CD drive after the initial boot phase. Ventoy resolves this using its integrated Memdisk feature:

  • When selecting an MS-DOS .img or FreeDOS .iso from the Ventoy menu, press Ctrl+M or choose "Boot in memdisk mode" from the secondary options menu if standard booting fails.
  • Memdisk loads the entire disk image directly into system RAM and hooks the BIOS disk services, allowing the DOS environment to seamlessly read and write to the virtual drive.

With legacy boot enabled and the appropriate image files placed on the drive, Ventoy provides a reliable, modern method for deploying and running MS-DOS and FreeDOS environments.
