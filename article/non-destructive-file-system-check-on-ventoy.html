Non-Destructive File System Check on Ventoy

Running a non-destructive file system check on a Ventoy drive verifies data integrity without modifying files, repairing sectors automatically, or risking data loss. Ventoy drives are configured with two partitions: the primary partition (Partition 1) where ISO files and documents reside, and a small EFI boot partition (Partition 2). This guide outlines the steps to perform a safe, read-only file system check on Ventoy's primary partition using standard tools in Windows and Linux.

Identify the Primary Ventoy Partition

Before running any commands, confirm the identifier of the primary partition.

  • Windows: Open File Explorer or Disk Management to locate the drive letter assigned to the large partition labeled Ventoy (e.g., E:).
  • Linux: Open a terminal and run lsblk -f. Locate your USB device (such as /dev/sdb). The large partition containing your ISO files is almost always partition 1 (such as /dev/sdb1).

Method 1: Windows (CHKDSK in Read-Only Mode)

Windows includes the chkdsk utility. By default, running chkdsk without the /F (fix) or /R (repair) switches runs in read-only mode, scanning the drive without making modifications.

  1. Press Win + X and select Terminal (Admin) or Command Prompt (Admin).

  2. Run the following command (replace E: with the actual drive letter of your Ventoy partition):

    chkdsk E:

  3. The utility will scan the file system metadata, files, and allocation tables, then output a summary report. If errors are reported, chkdsk will state that problems were found, but no changes will be made to the partition.

Method 2: Linux (Read-Only fsck)

On Linux, the fsck family of tools uses the -n flag to open the file system in read-only mode, automatically answering "no" to any prompt that asks to fix an error.

1. Unmount the Partition

While read-only checks are safe, it is best practice to unmount the partition first to avoid false-positive error reports from active read/write operations:

sudo umount /dev/sdX1

(Replace /dev/sdX1 with your actual device identifier).

2. Run the Check Based on the File System Type

Ventoy formats Partition 1 as exFAT by default, but users can format it as NTFS, ext4, or other formats. Choose the command corresponding to your configuration:

  • For exFAT (Ventoy default):

    sudo fsck.exfat -n /dev/sdX1

    (Note: Depending on your Linux distribution, the tool may be named exfatfsck.)

  • For NTFS:

    sudo ntfsfix -n /dev/sdX1

  • For ext4:

    sudo e2fsck -n /dev/sdX1

The -n switch ensures that any detected errors are merely displayed in the terminal output without altering the partition's structure or the ISO files stored on it.
