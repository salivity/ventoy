Boot TrueNAS CORE and SCALE from Ventoy USB

Ventoy enables you to boot multiple operating system installers directly from a single flash drive, but booting TrueNAS requires handling its two distinct editions appropriately. While TrueNAS SCALE is Debian Linux-based and boots natively with default settings, TrueNAS CORE is built on FreeBSD, which historically encounters media-mounting issues when booted from virtual CD images. This guide details how to set up your USB drive and use the correct boot modes to launch both TrueNAS CORE and TrueNAS SCALE without installation failures.

Prepare the Ventoy Drive

  1. Download and install the latest version of Ventoy onto your USB drive.
  2. Download the official ISO images for both TrueNAS CORE and TrueNAS SCALE.
  3. Copy both .iso files directly into the root directory or a subfolder of your Ventoy USB partition.
  4. Safely eject the USB drive and plug it into the target server or system.
  5. Power on the system and enter the boot menu to select the Ventoy USB drive (UEFI mode is recommended for both systems).

Booting TrueNAS SCALE

Because TrueNAS SCALE is built on Debian Linux, Ventoy handles its ISO using standard Linux kernel loading mechanisms.

  1. Select the TrueNAS SCALE ISO from the Ventoy main menu.
  2. When prompted for boot options, choose Boot in normal mode.
  3. If normal mode fails or freezes during initialization, return to the menu, select the ISO again, and choose Boot in grub2 mode.
  4. The TrueNAS SCALE installer will load directly into the console setup menu.

Booting TrueNAS CORE

TrueNAS CORE uses the FreeBSD bootloader and kernel. When loaded via standard ISO emulation, the FreeBSD installer often cannot locate its root filesystem, triggering a mountroot> prompt. To bypass this, you must load the ISO entirely into memory.

  1. Locate the TrueNAS CORE ISO in the Ventoy menu.
  2. Highlight the TrueNAS CORE ISO and press Ctrl + m on your keyboard, or press F1 to enter the secondary menu and toggle Memdisk Mode.
  3. When Memdisk mode is active, the ISO name in Ventoy will display an [MEMDISK] tag.
  4. Press Enter to launch the installer.
  5. Ventoy will load the entire ISO into system RAM before handing control over to FreeBSD. This allows the FreeBSD installer to read the installation media without needing a dedicated physical CD/DVD drive.

Note: Your target machine must have enough free RAM to hold the entire CORE ISO image (at least 2 GB to 4 GB of available system memory) for Memdisk mode to function.

Resolving the mountroot> Error in CORE

If you boot TrueNAS CORE in normal mode by mistake and get dropped to the mountroot> prompt, the kernel cannot find the ISO's file path. You can either reboot and use Memdisk mode or manually point the kernel to the USB device:

  1. Type ? at the mountroot> prompt and press Enter to list available storage devices.
  2. Locate the partition corresponding to your Ventoy data drive (typically labeled as da0s1, da1s1, or similar).
  3. Enter the device string manually: 
    cd9660:/dev/da0s1
    (Replace da0s1 with your actual USB device identifier).
  4. Press Enter to continue the installer. Using Memdisk mode prior to boot remains the more reliable method to avoid this issue entirely.
