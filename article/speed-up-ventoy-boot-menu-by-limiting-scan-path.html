Speed Up Ventoy Boot Menu by Limiting Scan Path

Limiting the scan path in Ventoy significantly improves boot menu load times, particularly on high-capacity drives or drives containing thousands of non-bootable files. By default, Ventoy recursively traverses the entire storage partition to identify compatible ISO, WIM, IMG, and VHD files. Restricting this search to a specific directory eliminates unnecessary disk reading, allowing the bootloader menu to appear almost instantaneously.

Why Default Ventoy Scans Cause Delays

When a computer boots into Ventoy, the environment relies on basic UEFI or BIOS storage drivers. These pre-boot drivers are considerably slower than full operating system drivers.

By default, Ventoy searches every folder and subfolder on the first partition to index bootable images. If your drive also stores general backups, portable software, or deep directory trees, the firmware must inspect the metadata and file signatures of thousands of unrelated files. This creates a noticeable delay—often several seconds to over a minute on large external hard drives—before the graphical menu displays.

How Limiting the Scan Path Improves Performance

Restricting Ventoy to a designated directory stops the recursive scanning of the entire partition. Instead of querying the file allocation table across the whole disk, Ventoy immediately targets a single location (such as /ISO or /BootImages).

The performance benefits include:

  • Reduced I/O Overhead: Pre-boot firmware executes fewer read commands, bypassing slow file traversal routines.
  • Predictable Load Times: The boot menu loads at a consistent speed regardless of how many gigabytes of non-image files exist on the storage partition.
  • Instant Refresh: Pressing the refresh key (F5) inside the Ventoy interface updates the list instantly rather than performing another complete disk sweep.

How to Restrict the Scan Path

You can limit the directory scan by editing or creating the ventoy.json configuration file located in the ventoy folder on your Ventoy partition (create the folder X:\ventoy\ if it does not exist).

Add the VTOY_DEFAULT_SEARCH_ROOT directive inside the configuration file:

{
    "control": [
        { "VTOY_DEFAULT_SEARCH_ROOT": "/ISO" }
    ]
}

In this example, Ventoy will ignore the root of the drive and only scan the folder named ISO. Any ISO files stored outside this designated directory will be skipped, ensuring optimal load performance.

When Will You Notice the Difference?

  • Noticeable Improvement: Multi-terabyte external hard drives (HDDs), USB drives with thousands of small files, and slow legacy BIOS systems.
  • Minimal Improvement: Small, dedicated USB flash drives (16GB–32GB) containing only a handful of ISO files in the root directory.

If your Ventoy drive doubles as a daily-use storage device containing games, documents, or backups, restricting the search path is one of the most effective optimizations available.
