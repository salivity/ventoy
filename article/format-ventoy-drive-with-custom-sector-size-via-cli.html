Format Ventoy Drive with Custom Sector Size via CLI

This article explains how to format a USB drive with Ventoy and apply custom sector or cluster sizes using command-line interface (CLI) tools in Linux. While Ventoy's native script provisions the partition table and boot partition, altering the data partition's allocation and sector alignment requires combining Ventoy’s shell installer with native filesystem utilities like mkfs.exfat or mkfs.ntfs.

Step 1: Identify the Target Drive

Insert your USB flash drive and open your terminal. Run the following command to identify the correct block device:

lsblk

Locate your drive node (for example, /dev/sdb or /dev/sdc). Ensure you do not target your primary OS disk.

Step 2: Install the Ventoy Base System

Download and extract the latest Ventoy Linux package, then navigate into the extracted directory. Run Ventoy2Disk.sh to initialize the disk structure:

sudo ./Ventoy2Disk.sh -i -g /dev/sdX
  • Replace /dev/sdX with your target drive.
  • The -g flag creates a GPT partition layout, which is recommended for modern systems and proper 4K alignment.
  • The -i flag performs a fresh install.

This command writes the bootloader to Partition 2 (/dev/sdX2) and creates the main data partition on Partition 1 (/dev/sdX1).

Step 3: Reformat the Data Partition with Custom Sector Sizes

Ventoy allows Partition 1 to be reformatted to different filesystems and cluster configurations without breaking boot functionality. Unmount the partition before modifying it:

sudo umount /dev/sdX1

Formatting as exFAT with Custom Sectors per Cluster

Use mkfs.exfat to specify the volume label and cluster sizing:

sudo mkfs.exfat -s 128 -n "VENTOY" /dev/sdX1
  • -s <sectors>: Defines the number of sectors per cluster. Setting -s 128 on a standard 512-byte sector disk produces a 64 KB cluster size.

Formatting as NTFS with Custom Cluster/Sector Sizing

If using NTFS, specify the exact cluster byte size directly:

sudo mkfs.ntfs -Q -c 4096 -L "VENTOY" /dev/sdX1
  • -c <size>: Sets the cluster size in bytes (e.g., 4096, 16384, 65536).
  • -Q: Performs a quick format to avoid overwriting all blocks unnecessarily.

Step 4: Verify the New Configuration

Verify that the filesystem block and sector parameters were written properly:

sudo blkid /dev/sdX1
sudo blockdev --getpbsz --getss /dev/sdX

Partition 1 is now configured with your custom allocation settings, and Partition 2 remains untouched to preserve Ventoy's multi-boot environment. You can now mount the drive and copy ISO files into Partition 1.
