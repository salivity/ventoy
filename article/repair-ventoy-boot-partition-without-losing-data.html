Repair Ventoy Boot Partition Without Losing Data

A corrupted Ventoy boot partition (VTOYEFI) can prevent your multiboot drive from booting while leaving your ISO collection completely intact. This guide explains how to restore the boot partition safely without wiping or reformatting your main data partition, using the official Ventoy Update tool, partition repair utilities, and direct image restoration.

Method 1: Use the Native Ventoy Update Feature

The official Ventoy installer includes a non-destructive update function specifically designed to refresh the bootloader and the EFI system partition without touching the data partition.

On Windows

  1. Download the latest Ventoy release zip file from the official website and extract it.
  2. Plug in your corrupted Ventoy USB drive.
  3. Run Ventoy2Disk.exe as Administrator.
  4. Select your USB drive from the Device drop-down list.
  5. Verify that the current version and the target version are displayed.
  6. Click the Update button (do not click Install, as "Install" will wipe the drive).
  7. Confirm the prompt to proceed. The tool will rewrite the EFI boot files and repair the boot structure while leaving the data partition intact.

On Linux

  1. Download and extract the latest Linux tarball for Ventoy.
  2. Open a terminal and navigate to the extracted directory.
  3. Identify your USB drive's device path (for example, /dev/sdb) using lsblk.
  4. Run the update command using the -u flag: 
    sudo sh Ventoy2Disk.sh -u /dev/sdX
    (Replace /dev/sdX with your actual USB device node, such as /dev/sdb. Do not include a partition number.)

Method 2: Repair the File System with Disk Utilities

If the partition table is intact but the FAT16/FAT32 file system of the VTOYEFI partition has logical corruption, file system repair tools can fix it.

On Windows

  1. Press Win + X and select Disk Management.
  2. Locate the Ventoy drive. It will have two partitions: the large data partition and a small (~32MB) partition labeled VTOYEFI.
  3. Right-click the VTOYEFI partition, select Change Drive Letter and Paths, and assign it a temporary letter (e.g., Z:).
  4. Open Command Prompt as Administrator and run: 
    chkdsk Z: /f
  5. Once completed, remove the drive letter in Disk Management to keep the EFI partition hidden.

On Linux

  1. Identify the second partition of the Ventoy drive (typically /dev/sdX2): 
    lsblk
  2. Unmount the partition if it is mounted: 
    sudo umount /dev/sdX2
  3. Run fsck.vfat to automatically repair file system errors: 
    sudo fsck.vfat -a /dev/sdX2

Method 3: Restore the EFI Partition Image via Linux (Advanced)

If the boot partition is severely corrupted or unreadable, you can rewrite the partition image directly from the official Ventoy release files using the dd command.

  1. Download and extract the Ventoy Linux package.
  2. Navigate to the boot directory inside the extracted folder: 
    cd ventoy-*/boot/
  3. Locate the file named boot.img or ventoy.disk.img.xz.
  4. Decompress the disk image if it is compressed: 
    xz -d -k ventoy.disk.img.xz
  5. Identify your USB drive's second partition (e.g., /dev/sdX2).
  6. Write the image directly to the second partition: 
    sudo dd if=ventoy.disk.img of=/dev/sdX2 bs=1M status=progress
    (Ensure you target partition 2 specifically, not the entire disk /dev/sdX or partition 1 /dev/sdX1.)
  7. Run sync to ensure all writes are flushed before unplugging the drive.
