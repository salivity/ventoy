Ventoy.json Location on a Ventoy Drive

This guide explains the exact directory and file structure required for the ventoy.json configuration file on a Ventoy USB drive. By understanding the proper partition and folder placement, you can ensure that custom plugins, themes, global control settings, and menu configurations are recognized and loaded properly by Ventoy during boot.

The Required Directory

The ventoy.json file must reside in a folder named ventoy located in the root of the first partition of the USB drive.

  • Full Path (Windows): X:\ventoy\ventoy.json (where X: is the drive letter assigned to the Ventoy data partition)
  • Full Path (Linux): /media/user/Ventoy/ventoy/ventoy.json (or /ventoy/ventoy.json relative to the root of the partition)

Correct Partition Selection

A standard Ventoy drive is split into two partitions upon installation:

  1. Partition 1 (Ventoy Data Partition): Formatted typically as exFAT (or NTFS, ext4, FAT32) to hold your ISOs, image files, and user data.
  2. Partition 2 (VTOYEFI): A small, hidden EFI system partition reserved for the bootloader.

The ventoy.json file must always go on Partition 1 (the main partition where you copy your ISO files), never on the hidden EFI boot partition.

Step-by-Step Placement

  1. Open your Ventoy USB drive in your file manager.
  2. At the root directory (the same level where your ISO files or folders are kept), create a new folder named ventoy (all lowercase is recommended).
  3. Place or create your ventoy.json file directly inside this ventoy folder.

Important Notes

  • Naming and Casing: While Ventoy's file system drivers can be case-insensitive depending on the underlying filesystem, using strict lowercase—both for the ventoy directory and the ventoy.json filename—prevents compatibility issues across different operating systems.
  • JSON Syntax: Ventoy will fail to load your configurations if the file contains invalid JSON syntax. Ensure your file is saved with standard UTF-8 encoding and validated for syntax errors.
