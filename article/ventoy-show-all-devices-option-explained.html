Ventoy Show All Devices Option Explained

This article explains the purpose, functionality, and risks associated with the "Show all devices" toggle in the Ventoy graphical user interface (GUI). By reading further, you will learn how Ventoy detects storage drives by default, what changes when this setting is activated, and why caution is required when using it.

Default Drive Detection in Ventoy

By default, the Ventoy installation tool restricts its target device list to removable media. When you open the application, it automatically scans your system and populates the device dropdown menu with recognized USB flash drives, SD cards (via card readers), and standard removable storage units.

This behavior acts as a safety mechanism. Because installing Ventoy formats the target drive and creates a new partition layout, limiting the menu to removable disks prevents users from accidentally selecting and erasing critical system drives.

What the "Show All Devices" Toggle Does

The "Show all devices" option is located under the Option dropdown menu in the top navigation bar of the Ventoy GUI. When this option is checked, Ventoy disables its hardware filter and queries the operating system for every connected storage disk, regardless of its classification.

Once enabled, the device selection list updates to show:

  • Internal Drives: Primary and secondary NVMe SSDs, SATA SSDs, and internal mechanical hard drives (HDDs).
  • Fixed External Drives: High-capacity external desktop drives or USB enclosures that identify to the operating system as "Fixed Disks" rather than "Removable Disks."
  • Advanced Storage: Connected storage arrays, virtual disks, and certain types of Thunderbolt or eSATA storage.

When to Use This Option

In most standard workflows, this option should remain disabled. However, there are specific scenarios where toggling it on is necessary:

  1. External SSDs and Hard Drives: Many modern portable SSDs and high-capacity external drives are flagged at the hardware firmware level as fixed disks. Under default settings, Ventoy will not detect them. Enabling "Show all devices" allows you to install Ventoy onto these fast, high-capacity external drives.
  2. Internal Drive Installations: If you are configuring a dedicated multi-boot test system and wish to install Ventoy directly onto an internal drive rather than booting from a USB stick, this option makes the internal drive accessible in the GUI.

Risks and Precautions

Enabling "Show all devices" significantly increases the risk of data loss. If you select the wrong disk and proceed with the installation, Ventoy will destroy the partition table and overwrite the existing data on that drive, including your primary Windows or Linux installation.

Before clicking Install with this option active, always verify:

  • Drive Capacity: Ensure the gigabyte (GB) or terabyte (TB) count matches your target drive, not your host system's primary storage.
  • Model Identifier: Look closely at the drive model name provided in the dropdown (e.g., matching the vendor name of your external drive).
  • Disk Management / Partition Tools: Cross-reference disk letters or physical disk numbers using Windows Disk Management or Linux terminal utilities (such as lsblk) before committing changes.
