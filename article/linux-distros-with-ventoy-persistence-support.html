Linux Distros with Ventoy Persistence Support

Ventoy offers a robust persistence plugin that allows users to save changes, installed packages, and configuration files across reboots on live USB environments. While Ventoy itself provides the underlying injection mechanism, persistence relies on the distribution's native live-boot system to recognize and mount the persistence backend image. This guide covers which major Linux distributions officially support persistence under Ventoy, detailing the supported families and their technical requirements.

How Ventoy Handles Persistence

Ventoy does not modify ISO images directly. Instead, it uses a backend image file (usually a .dat file formatted with ext4) and a configuration file named ventoy.json. During boot, Ventoy maps the virtual disk image to the live system using the distribution's native persistence parameters.

Officially Supported Distribution Families

Ventoy's persistence plugin explicitly supports the live-boot frameworks utilized by the following distribution families:

1. Ubuntu and Derivatives (Casper Framework)

Distributions relying on Ubuntu's casper live-boot engine work natively with Ventoy persistence using casper-rw labels.

  • Ubuntu (Desktop, Server, and official flavors like Kubuntu, Xubuntu, Lubuntu)
  • Linux Mint (Cinnamon, MATE, Xfce editions)
  • Pop!_OS
  • Zorin OS
  • elementary OS

2. Debian and Debian-Based Systems (Live-Boot Framework)

Debian-based systems utilize Debian's native live-boot script, which looks for storage tagged with the persistence label.

  • Debian Live
  • Kali Linux
  • Parrot OS
  • PureOS

3. Fedora and Red Hat Family (Dracut / Live-Sys)

Fedora uses dracut modules to handle persistence via an overlay filesystem labeled live-rw.

  • Fedora Workstation and Spins
  • CentOS Stream / Rocky Linux / AlmaLinux (Live media editions)

4. Arch Linux and Derivatives (Archiso / Cowspace)

Arch-based live environments utilize archiso with a Copy-On-Write (cowspace) allocation.

  • Arch Linux
  • Manjaro Linux
  • EndeavourOS
  • Garuda Linux

5. openSUSE Family

openSUSE uses Kiwi-based live images that support read-write overlays.

  • openSUSE Tumbleweed (Live versions)
  • openSUSE Leap (Live versions)

6. Specialized and Lightweight Distros

Several independent or lightweight systems have built-in compatibility with Ventoy's persistence mapping:

  • Puppy Linux
  • antiX Linux
  • MX Linux (utilizes custom persistence mechanisms mapped via Ventoy configurations)

Configuration Requirements

To enable persistence for any supported distribution, you must configure two elements on the Ventoy USB drive:

  1. A Persistence Image File: A pre-allocated .dat file formatted with an ext4 filesystem. Ventoy provides a script tool (CreatePersistentImg.sh) to generate these files with appropriate labels such as casper-rw or persistence.
  2. The JSON Configuration: A file located at /ventoy/ventoy.json defining the association between the target ISO file and the corresponding persistence image.
{
    "persistence": [
        {
            "image": "/ISO/ubuntu-22.04-desktop-amd64.iso",
            "backend": "/persistence/ubuntu_casper.dat"
        }
    ]
}

Once mapped, booting the specified ISO via the Ventoy menu automatically loads the persistence overlay without requiring additional kernel boot parameters.
