How Ventoy Handles Multi-Language Boot Menus

Ventoy provides comprehensive multi-language support in its boot menu through a combination of built-in translation files, dynamic hotkey switching, Unicode font rendering, and persistent configuration options. By decoupling language settings from the booted ISO files, Ventoy enables users to navigate its interface, system prompts, and configuration menus in their preferred language natively at boot time.

Built-In Translation Architecture

Ventoy’s multi-language framework relies on standard JSON files that store key-value pairs mapping internal string identifiers to localized text. These files cover all menu text, including navigation tips, error alerts, function key descriptions, and secondary menu labels. Because the UI is built on a modified GRUB2 environment, the system utilizes integrated Unicode fonts (such as GNU Unifont) to correctly render non-Latin scripts, including Cyrillic, Greek, Arabic, and CJK (Chinese, Japanese, and Korean) characters.

Dynamic Runtime Switching

Users can change the display language on the fly directly from the main boot screen without restarting the computer:

  • The "L" Hotkey: Pressing the L key on the keyboard instantly invokes the language selection popup menu.
  • Instant Redraw: Selecting a language from this list immediately updates the interface text without requiring a reload of the disk contents or the underlying GRUB engine.
  • Session Scope: Changes made via the runtime menu remain active for the duration of the current boot session.

Permanent Configuration via ventoy.json

To make a language preference permanent, Ventoy allows administrators and users to define a default language using the ventoy.json configuration file placed in the ventoy directory of the USB drive's primary partition.

Within the control section of this file, the VTOY_DEFAULT_MENU_LANG parameter can be assigned a specific language code (such as "zh_CN" for Simplified Chinese, "de_DE" for German, or "es_ES" for Spanish). When Ventoy boots, it reads this configuration and initializes the interface directly into the specified language, bypassing the default English setting.

Custom Translations and Overrides

Ventoy supports custom localization additions and modifications. If an existing translation needs corrections, or if a user wants to add an unsupported language or dialect, they can provide a custom languages.json file inside the /ventoy/ directory. Ventoy checks for external language definition files first, allowing local files to override or expand upon the internal translation database without altering the underlying core installation.
