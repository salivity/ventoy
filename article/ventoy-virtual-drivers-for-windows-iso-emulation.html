Ventoy Virtual Drivers for Windows ISO Emulation

When booting a Windows installation or Windows PE environment directly from an ISO file, Ventoy utilizes a specialized virtual storage driver—primarily ventoy.sys—to emulate a physical optical disc drive. This article explains which drivers Ventoy creates, why they are required during the Windows boot process, and how they bridge the gap between firmware-level emulation and the Windows kernel.

The Need for Virtual Optical Drivers

During the initial boot stage (UEFI or legacy BIOS), Ventoy maps the Windows ISO image into memory or hooks disk access interrupts so the system can load the bootloader and Windows PE kernel (boot.wim). However, as soon as Windows initializes its own kernel and switches to protected mode, it stops using firmware-level hooks. Without a dedicated Windows driver, Windows loses access to the ISO file, typically resulting in the error: "A media driver your computer needs is missing."

Ventoy Virtual Device Drivers in Windows

To resolve this issue, Ventoy injects a proprietary virtual device driver into the running Windows environment:

  • ventoy.sys (Ventoy Virtual Storage Driver): This is the core kernel-mode driver injected into the Windows PE or Windows Setup environment. Depending on the architecture, Ventoy provides x86, x64, and ARM64 builds of this driver.
  • Virtual SCSI Adapter / CD-ROM Device: Working alongside the driver, Ventoy creates a virtual SCSI/Storport controller device. Through this virtual controller, it presents the raw ISO file located on the physical USB drive as a standard optical disc drive (CD/DVD-ROM).

How the Emulation Works

  1. Driver Injection: Before Windows PE loads, Ventoy prepares an in-memory driver injection mechanism (often using dynamic runtime hooks or patching the registry of the loaded WIM in memory).
  2. Driver Loading: When Windows loads its hardware abstraction layer and core storage drivers, it initializes ventoy.sys.
  3. Offset Mapping: ventoy.sys communicates with the physical USB drive where the ISO file resides. It maps the contiguous sector ranges of the ISO directly to the virtual optical drive.
  4. Device Presentation: In Windows Device Manager, the emulated disc appears under DVD/CD-ROM drives or Storage controllers as a virtual device. Windows Setup recognizes this as a standard optical drive containing the setup media, allowing the installation to proceed normally.
