Does Ventoy Support ARM64 and AArch64?

Ventoy provides official support for both ARM64 and AArch64 processor architectures. This capability allows users to create bootable USB drives capable of booting ARM-based ISOs, IMGs, and other disk images directly on compatible ARM hardware. While the feature functions similarly to Ventoy on standard x86 systems, specific hardware and firmware requirements apply when booting on ARM-based machines.

ARM64 Support in Ventoy

Ventoy introduced support for the ARM64 (AArch64) architecture starting with version 1.0.80. This update expanded the utility beyond traditional x86 and x86_64 platforms, allowing systems powered by 64-bit ARM processors to utilize Ventoy's file-copy boot mechanism.

When using Ventoy on ARM64 hardware, you can copy supported ARM64 installation images (such as Ubuntu, Debian, openSUSE, or Windows on ARM) directly to the USB drive and boot them from the Ventoy selection menu.

How ARM64 Booting Works on Ventoy

On traditional PCs, Ventoy supports both legacy BIOS and UEFI firmware. On ARM64 platforms, Ventoy operates exclusively through UEFI, as ARM architecture does not use legacy x86 BIOS standards.

Key characteristics of Ventoy’s ARM64 support include:

  • UEFI Only: The target device must utilize standard UEFI firmware implementation to load the Ventoy bootloader.
  • Architecture-Specific Binaries: Ventoy includes the necessary EFI boot files (BOOTAA64.EFI) alongside its standard x86 binaries, allowing a single Ventoy drive to technically support multiple CPU architectures if configured properly.
  • Standard ISO Booting: Linux distributions compiled for AArch64 that support standard UEFI boot processes can be launched without unpacking the images.

Limitations and Hardware Compatibility

While Ventoy supports the ARM64 architecture at the software level, real-world compatibility depends heavily on the target hardware's boot environment:

  1. Enterprise and Server Hardware: ARM64 servers (such as those using Ampere Altra processors) follow standard UEFI specifications, making them fully compatible with Ventoy.
  2. SBCs (Single Board Computers): Devices like the Raspberry Pi or Rockchip boards typically do not use a standard PC-style UEFI implementation out of the box. Booting Ventoy on these boards often requires custom UEFI firmware overlays (such as Tianocore EDK2 firmware) rather than their default U-Boot loaders.
  3. Windows on ARM Laptops: Laptops running Qualcomm Snapdragon processors generally utilize UEFI, but vendor-specific Secure Boot configurations and driver limitations may require Secure Boot to be disabled to boot Ventoy.

Ventoy fully supports ARM64 and AArch64, provided the target machine provides a standard UEFI runtime environment to initialize the bootloader.
