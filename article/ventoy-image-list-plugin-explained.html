Ventoy Image List Plugin Explained

The Ventoy image list plugin is a configuration tool that gives users precise control over which bootable images appear in the Ventoy boot menu and the exact order in which they are displayed. By default, Ventoy searches the entire USB drive and displays every compatible file it finds in alphabetical order. This article explains what the image list plugin is, how it overrides default behavior, and the specific display and filtering options it controls.

What Is the Ventoy Image List Plugin?

Ventoy is designed to automatically scan partitions for supported image formats—such as ISO, WIM, VHD, and EFI files—and generate a dynamic boot list. While this automated scan is convenient, it can become cluttered if you store testing files, backup images, or non-bootable utilities on the same drive.

The image list plugin is a feature configured via the ventoy.json configuration file. It replaces the automatic scanning mechanism with a user-defined whitelist, ensuring that Ventoy only displays the specific images you designate.

What Does the Plugin Control?

The image list plugin controls three primary aspects of the Ventoy boot environment:

  1. File Visibility (Whitelisting): Instead of showing every bootable file on the drive, the menu strictly displays only the files defined in the plugin's list. Any image file located on the drive that is omitted from the list will be hidden from the boot menu.
  2. Display Order: By default, Ventoy sorts files alphabetically. The image list plugin forces the menu to display images in the exact sequence in which they are written in the configuration file, allowing you to prioritize frequently used operating systems or rescue disks at the top of the list.
  3. Directory Targeting: The plugin maps exact file paths relative to the root of the USB drive. This allows you to selectively pull images stored across different directories and subdirectories into a single, clean menu without displaying the entire contents of those folders.

How It Is Configured

The image list plugin operates through the ventoy.json file located inside the ventoy folder at the root of the USB drive.

To use it, an image_list array is added to the JSON structure containing the absolute paths of the target files. For example:

{
    "image_list": [
        "/ISO/ubuntu-22.04-desktop-amd64.iso",
        "/ISO/Win11_English_x64.iso",
        "/Rescue/archlinux-x86_64.iso"
    ]
}

In this configuration, only the three listed operating systems will appear in the boot menu, and they will appear in that exact order, regardless of any other ISO or WIM files stored on the drive.
