How to Verify Ventoy Digital Signature

Verifying the digital signature of a downloaded Ventoy release ensures that the archive is authentic, unmodified, and safe to use. This guide outlines the straightforward steps required to confirm the integrity of Ventoy archives using GPG (GNU Privacy Guard) and SHA-256 checksums on both Linux and Windows environments.

Step 1: Download Required Files

To verify the release, download the following items from the official Ventoy GitHub releases page:

  1. The Ventoy archive (for example, ventoy-x.x.xx-linux.tar.gz or ventoy-x.x.xx-windows.zip).
  2. The corresponding signature file (usually ending in .asc or .sig) or the signed checksum file (sha256.txt / sha256.txt.asc).

Ensure that both the archive and signature files are saved in the same directory.

Step 2: Import the Ventoy Developer Public Key

Before validating the signature, you must have the developer's public PGP key imported into your GPG keyring.

  1. Open your terminal or command prompt.
  2. Fetch the Ventoy public key directly from a public keyserver by running: 
    gpg --keyserver keyserver.ubuntu.com --recv-keys 4A68DF2A
    (Note: Verify the latest Key ID published on the official Ventoy project repository if keys have been updated).

Alternatively, if a public key file (ventoy.asc or similar) is provided directly on the project page, import it with:

gpg --import ventoy.asc

Step 3: Verify the Signature with GPG

If the developer provided a detached signature for the archive directly:

gpg --verify ventoy-x.x.xx-linux.tar.gz.asc ventoy-x.x.xx-linux.tar.gz

If the signature is for the sha256.txt checksum list:

gpg --verify sha256.txt.asc sha256.txt

Interpreting the Result

Look for the output line:

gpg: Good signature from "Ventoy <...>"

You may see a warning stating that the key is not certified with a trusted signature. This is normal in GPG unless you have personally signed the developer's key; the critical indicator is the Good signature confirmation.

Step 4: Validate the File Checksum

If you verified the signature of sha256.txt, you must match the hash of your downloaded archive against that verified file.

On Linux:

Run the checksum validation utility:

sha256sum -c sha256.txt --ignore-missing

The output should report OK next to your downloaded archive.

On Windows (PowerShell):

Calculate the hash of the downloaded zip file:

Get-FileHash .\ventoy-x.x.xx-windows.zip -Algorithm SHA256

Compare the output string with the corresponding value listed in the verified sha256.txt file. If the hashes match exactly, the archive is verified and intact.
