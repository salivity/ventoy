Ventoy Visual Indicators During Image Loading

Ventoy provides dedicated on-screen visual feedback to confirm drive activity and progress whenever an operating system image is selected for booting. Depending on the boot method chosen and whether custom themes are applied, these visual cues range from percentage-based progress bars to real-time status messages that inform the user that the storage media is actively being read.

On-Screen Progress Bar

The most prominent visual indicator Ventoy offers occurs during operations requiring sustained disk reads, such as when booting an image in Memdisk mode. In this scenario, Ventoy reads the entire ISO file into physical RAM before booting. During this process, Ventoy displays an active progress bar across the screen alongside a percentage counter (0% to 100%). This bar fills dynamically as data chunks are retrieved from the USB flash drive or external drive.

Real-Time Status Text

In standard boot mode, where images are mapped virtually rather than fully copied into memory, drive access happens almost instantaneously. Ventoy displays short status strings such as "Loading...", "Processing...", or file-specific mapping notices. These textual prompts confirm that the bootloader has registered the command and is actively reading the disk's partition table, file allocation, and kernel headers before handing control over to the target operating system.

Graphical Theme Spinners and Custom Gauges

Ventoy supports custom GRUB2 themes configured via the ventoy.json file. When a graphical theme is installed, default text indicators can be augmented or replaced by custom user interface elements. These include graphical loading spinners, themed progress gauges, or custom dialog boxes that trigger automatically while Ventoy accesses and mounts the image from the storage drive.
