Can Ventoy Boot Compressed Gzip or XZ Disk Images?

Ventoy cannot boot disk images directly from Gzip (.gz) or XZ (.xz) compressed formats. Because Ventoy operates by mapping disk sectors directly to the host system via BIOS or UEFI interfaces, image files must remain uncompressed so the operating system can read raw sectors at runtime. Users with compressed image files must extract them to raw formats like ISO, IMG, or VHD before copying them to the Ventoy USB drive.

The Short Answer

No. Ventoy does not support booting disk images packaged in .iso.gz, .img.gz, .iso.xz, .img.xz, or any other Gzip- or XZ-compressed archive formats. If you place a compressed archive on your Ventoy USB drive, it will either be ignored in the boot menu or fail to boot when selected.

Why Ventoy Requires Uncompressed Images

Ventoy's core architecture relies on directly hooking into the boot process to simulate an optical drive or virtual disk device.

  • Direct Sector Mapping: Ventoy hooks system calls (INT 13h in legacy BIOS or the EFI Block I/O protocol in UEFI) to translate sector requests directly to the file stored on the USB drive.
  • Random Read Access: Operating systems require instant, non-sequential sector reads across the image. Standard compression formats like Gzip and XZ stream-compress data, making random read access impossible without decompressing the entire file into RAM first.
  • RAM Limitations: Decompressing multi-gigabyte modern operating system installers entirely into system memory prior to booting would exceed the available RAM on many machines and severely slow down the boot process.

Supported File Formats

To ensure compatibility with Ventoy, keep files in their uncompressed, native disk image structures. Ventoy natively supports:

  • ISO: Standard optical disc images (.iso)
  • WIM: Windows Imaging Format files (.wim)
  • IMG: Raw disk/floppy images (.img)
  • VHD / VHDX: Virtual Hard Disk images (.vhd, .vhdx)
  • EFI: Standalone EFI executable files (.efi)

How to Prepare Compressed Images for Ventoy

If you have downloaded an image compressed with Gzip or XZ, you must extract it before copying it to your Ventoy storage partition:

  1. For .gz files: Decompress using 7-Zip on Windows, or run gzip -d filename.iso.gz in a Linux terminal.
  2. For .xz files: Decompress using 7-Zip on Windows, or run unxz filename.iso.xz or xz -d filename.img.xz on Linux.
  3. Copy the extracted file: Move the resulting .iso, .img, or .vhd file directly into your Ventoy USB drive's data partition.
