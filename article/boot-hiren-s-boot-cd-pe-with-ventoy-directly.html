Boot Hiren's BootCD PE with Ventoy Directly

Ventoy fully supports booting Hiren's BootCD PE without any modifications, special configurations, or file extractions. Because Hiren's BootCD PE is based on standard Windows Preinstallation Environment (WinPE) architecture, Ventoy can map and boot the ISO directly from the USB drive. This guide covers how this native compatibility works, how to set it up, and what to expect when booting Hiren's BootCD PE through Ventoy.

Native Compatibility Explained

Ventoy is designed to boot ISO, WIM, IMG, VHD, and EFI files directly by loading them into memory or mounting them via internal drivers during startup. Because Hiren’s BootCD PE uses standard Windows PE bootloaders (bootmgr and boot.sdi), Ventoy injects its runtime drivers seamlessly during boot.

There is no need to extract the ISO contents, alter the internal boot.wim file, or use Ventoy plugins. The ISO functions identically to a dedicated USB drive created with tools like Rufus.

Steps to Boot Hiren's BootCD PE on Ventoy

  1. Prepare the Ventoy Drive: Install Ventoy on your target USB flash drive using the official Ventoy installer.
  2. Download the ISO: Obtain the official, unmodified HBCD_PE_x64.iso image from the official Hiren's BootCD PE release page.
  3. Copy the File: Drag and drop the downloaded ISO directly onto the main partition of your Ventoy USB drive. Do not rename or extract the archive.
  4. Boot from USB: Insert the USB drive into the target computer, enter the BIOS/UEFI boot menu, and select the USB drive.
  5. Select the ISO: Choose Hiren's BootCD PE from the graphical Ventoy menu to launch directly into the desktop environment.

Firmware and Architecture Support

  • UEFI and Legacy BIOS: Hiren's BootCD PE boots successfully on both modern UEFI-based systems and older Legacy BIOS hardware via Ventoy.
  • Secure Boot: If your target machine has Secure Boot enabled, Ventoy’s built-in key enrollment (via the "Enroll Key" prompt on first boot) allows Hiren's BootCD PE to load without disabling security settings in your BIOS.
  • Driver and Tool Loading: Once booted, the WinPE startup scripts will automatically detect the mounted virtual drive, load the network and storage drivers, and populate the Start Menu with all bundled diagnostic utilities.
