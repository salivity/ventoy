Can Ventoy Boot VMDK Files Directly?

Ventoy does not natively support booting VMware disk images with the .vmdk extension directly from a USB drive. While Ventoy is a versatile multi-boot utility capable of loading various file types, it natively recognizes only ISO, WIM, IMG, VHD, VHDX, and EFI files. To run an operating system stored within a VMDK file through Ventoy, you must first convert the virtual disk into a supported format, such as VHD, VHDX, or a raw disk image.

Ventoy Supported Formats

Ventoy operates by directly scanning the partitions of your USB drive for specific bootable image extensions. The officially supported image formats are:

  • ISO: Standard optical disc images (Linux distributions, Windows installers, rescue disks).
  • WIM: Windows Imaging Format files.
  • IMG: Raw sector-by-sector disk images.
  • VHD / VHDX: Microsoft Virtual Hard Disk formats (requires the Ventoy VHD boot plugin for Windows systems).
  • EFI: Raw EFI executable binaries.

Because .vmdk (Virtual Machine Disk) is structured primarily for VMware environments and often contains descriptor files or split sparse extents, Ventoy’s bootloader cannot parse it out of the box.

Workarounds to Boot a VMDK with Ventoy

To boot the system contained inside a .vmdk file, you need to convert it into a compatible format before copying it to your Ventoy drive.

1. Convert VMDK to VHD or VHDX

Converting the VMDK to Microsoft's VHD or VHDX format is the most reliable method for Windows-based virtual machines. You can use free conversion utilities such as:

  • qemu-img: A cross-platform command-line tool. You can convert the file using the following command: 
    qemu-img convert -f vmdk -O vpc source.vmdk target.vhd
    (Note: For VHDX, change -O vpc to -O vhdx)
  • StarWind V2V Converter: A free GUI tool that safely converts VMware disk files into bootable VHD/VHDX images without data corruption.

If you are booting a Windows VHD/VHDX, you must also place the official ventoy_vhdboot.dat plugin inside a folder named ventoy in the root of the USB drive.

2. Convert VMDK to Raw IMG

For Linux-based or custom operating system disks, converting the VMDK into a raw image file (.img) is often the best choice:

qemu-img convert -f vmdk -O raw source.vmdk target.img

Once the conversion is complete, place the resulting .img file anywhere on the Ventoy partition, and Ventoy will automatically list it in the boot menu.
