Test Ventoy USB in VirtualBox and VMware

Ventoy fully supports virtual testing in both VMware Workstation and Oracle VM VirtualBox, allowing users to verify their multiboot drives and ISO files without restarting the physical computer. Users can boot a physical Ventoy USB drive inside a virtual machine through direct USB passthrough, raw physical disk mapping, or by using Ventoy's dedicated virtual disk link utility. This setup provides a safe, efficient environment to troubleshoot configurations, test new operating system images, and ensure boot menus function properly before deploying them to physical hardware.

Using the VentoyVlnk Utility

Ventoy includes an official companion tool called VentoyVlnk (available in the Ventoy download package) specifically designed for virtual machine testing.

  1. Connect the Ventoy USB drive to the computer.
  2. Run VentoyVlnk.exe with administrative privileges.
  3. Select the physical drive corresponding to the Ventoy USB and click Create.
  4. The tool generates a lightweight .vmdk descriptor file that points directly to the physical drive.
  5. Attach this .vmdk file as an existing virtual hard disk in either VMware Workstation or VirtualBox.

Testing in Oracle VM VirtualBox

There are two primary methods to boot a Ventoy drive in VirtualBox:

Method 1: Using VentoyVlnk

  1. Create a new virtual machine in VirtualBox without adding a virtual hard disk.
  2. Go to VM Settings > Storage.
  3. Under the storage controller, add an existing hard disk and choose the .vmdk file created by the VentoyVlnk tool.
  4. If testing UEFI-based ISOs, open Settings > System > Motherboard and check Enable EFI (special OSes only).
  5. Start the virtual machine to load the Ventoy menu.

Method 2: USB Device Filter

  1. Ensure the VirtualBox Extension Pack is installed on the host.
  2. Go to VM Settings > Ports > USB.
  3. Enable the USB Controller (preferably USB 3.0 xHCI).
  4. Add a new USB filter and select the Ventoy flash drive from the list.
  5. Boot the virtual machine and enter the VM's boot menu to select the USB drive as the primary boot device.

Testing in VMware Workstation

VMware Workstation natively supports booting directly from physical disks without third-party utilities.

Method 1: Direct Physical Disk Mapping

  1. Run VMware Workstation as an administrator.
  2. Create a new virtual machine or select an existing one, then navigate to VM > Settings.
  3. Under the Hardware tab, click Add, select Hard Disk, and click Next.
  4. Choose the disk type (SCSI, SATA, or NVMe) and click Next.
  5. Select Use a physical disk (for advanced users) and proceed.
  6. Under the Device dropdown, select the physical drive index of the Ventoy USB, and choose Use entire disk.
  7. Name the configuration file, finish the wizard, and boot the virtual machine.

Method 2: USB Controller Passthrough

  1. Connect the Ventoy USB to the host computer.
  2. Power on the virtual machine.
  3. In the VMware top menu, navigate to VM > Removable Devices.
  4. Locate the Ventoy USB drive and select Connect (Disconnect from host).
  5. Restart the VM into its firmware menu to choose the USB drive as the boot target.

Important Configuration Notes

  • Firmware Mode (Legacy BIOS vs. UEFI): Ensure the VM's firmware matches the intended boot mode. VMware allows toggling between BIOS and UEFI in VM Settings > Options > Advanced. VirtualBox toggles this under System > Motherboard > Enable EFI.
  • Administrative Rights: Direct access to physical storage devices requires administrative privileges on Windows and root/disk group permissions on Linux. Virtualization software must be launched with elevated permissions to read raw USB sectors properly.
  • Write Protection: Do not modify, format, or write to the mapped Ventoy disk partitions from within the guest operating system during testing, as concurrent read/write actions from both the host and guest can lead to file corruption.
