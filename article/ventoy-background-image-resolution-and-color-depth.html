Ventoy Background Image Resolution and Color Depth

Customizing the Ventoy boot menu background enhances the user interface, but using improper image specifications can lead to rendering glitches, distortion, or black screens. This guide provides the recommended resolution, optimal color depth, supported file formats, and technical requirements needed to ensure your custom background displays properly across both legacy BIOS and modern UEFI systems.

Recommended Resolution

The ideal resolution depends on the target display and the boot mode of your hardware:

  • Standard Modern Systems (UEFI): 1920x1080 (Full HD) is the most widely recommended resolution. It provides a sharp, clean appearance on the vast majority of modern laptops and desktop monitors.
  • Maximum Compatibility (Legacy BIOS / Older Displays): 1024x768 or 800x600 is recommended if you frequently boot older machines. Legacy BIOS systems and certain virtual machines cannot initialize high-resolution VESA/GOP display modes and will default to standard 4:3 resolutions.
  • 4K and High-DPI Displays: While 3840x2160 can be used on modern UEFI systems that support high-resolution GOP drivers, it may result in extremely small fonts in the GRUB2 interface. For 4K screens, 1920x1080 remains the safer choice as it scales predictably.

Ventoy's underlying GRUB2 engine will stretch or clip images that do not match the active display mode. To prevent distortion, match the image resolution to the resolution property defined in your theme.txt or ensure it matches the native aspect ratio (typically 16:9) of your screen.

Recommended Color Depth

  • Optimal Color Depth: 24-bit TrueColor (8 bits per channel RGB).
  • Alpha Channel Support: 32-bit (24-bit RGB + 8-bit Alpha channel) is supported for PNG files, allowing for transparency effects in UI elements.

Avoid using 8-bit indexed color palettes (common in animated GIFs or optimized web assets), as the bootloader may fail to map colors correctly, resulting in banding, inverted colors, or complete rendering failure.

Supported File Formats and Encoding

  • PNG (Recommended): Use standard non-interlaced PNG files. PNG is the preferred format because GRUB2 renders it cleanly without JPEG compression artifacts, ensuring sharp menu lines and readable text overlays.
  • JPG / JPEG: Use standard baseline JPG files. Avoid saving images with "progressive" encoding, as the GRUB2 bootloader does not support progressive JPEGs and will display a black screen.

Implementation Guidelines

To apply your background, place the image file inside the ventoy directory on your USB drive (for example, /ventoy/theme/background.png) and reference it in your theme.txt file under the desktop image attribute:

desktop-image: "background.png"

If specifying a custom display mode, ensure the set theme or display resolution entry in your Ventoy theme matches your background's exact pixel dimensions to avoid unwanted stretching.
