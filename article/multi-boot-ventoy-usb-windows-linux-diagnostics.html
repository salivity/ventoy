Multi-Boot Ventoy USB: Windows, Linux, Diagnostics

You can easily combine Windows installers, Linux live distributions, and hardware diagnostic utilities on a single USB drive using Ventoy. Unlike traditional bootable media creators that require reformatting a drive for each operating system, Ventoy creates a bootable environment that directly executes raw ISO, WIM, IMG, and VHD files. This guide explains how Ventoy works, how to set up your multi-boot drive, and best practices for managing multiple operating systems and diagnostic tools seamlessly.

How Ventoy Works

Ventoy bypasses the traditional method of extracting ISO image contents directly to the root of a storage device. When installed, it divides the USB drive into two partitions: a small, protected FAT partition housing the Ventoy bootloader and EFI files, and a large exFAT (or NTFS/ext4) data partition.

When you boot from the USB drive, Ventoy provides a graphical menu listing every bootable image file stored on the data partition. Selecting an entry mounts that image directly in memory or through a virtual disk hook, allowing the target operating system or diagnostic utility to boot natively.

Setting Up the USB Drive

  1. Download Ventoy: Obtain the latest installation package for Windows or Linux from the official Ventoy release repository.
  2. Install to USB: Insert your target flash drive (a minimum of 32 GB is recommended to hold multiple operating systems) and launch the Ventoy installer. Select your drive and click Install. Note that this initial process will format the drive, erasing all existing data.
  3. Configure Partition Style (Optional): In the Ventoy settings menu, you can choose between MBR and GPT partition schemes. Ventoy supports both UEFI and legacy BIOS modes regardless of the partition scheme selected, though GPT is recommended for modern hardware.

Adding Your Operating Systems and Utilities

Once the initial installation completes, you manage the USB drive like standard storage. To add bootable environments, simply copy the unmodified ISO files into the main partition of the flash drive:

  • Windows Installers: Copy standard Windows 10 or Windows 11 installation ISOs directly to the drive. Ventoy automatically bypasses modern UEFI requirements like TPM and Secure Boot checks if configured via its configuration plugins.
  • Linux Distributions: Add any popular live or install images, including Ubuntu, Fedora, Arch Linux, or Kali Linux.
  • Hardware Diagnostics: Include recovery and testing images such as MemTest86+, Clonezilla for disk cloning, GParted for drive partitioning, or the Ultimate Boot CD (UBCD).

Organization and Best Practices

  • Folder Hierarchy: Ventoy recursively scans the drive for supported image types. You can create subfolders (e.g., /Windows, /Linux, /Diagnostics) to keep your files organized. Ventoy will display all discovered images in its main menu.
  • Avoid Non-Standard Characters: Do not use spaces or non-ASCII characters in the filenames or directory paths of your ISO files, as some Linux kernel boot parameters fail to parse spaces properly.
  • Persistence for Linux: By default, changes made during a live Linux session are lost on reboot. Ventoy supports persistence plugins, allowing you to link an image file (such as Ubuntu) to a persistence data file stored on the drive.
  • Secure Boot Support: Ventoy supports UEFI Secure Boot. On the first boot on a Secure Boot-enabled system, you will be prompted to enroll the "Ventoy Key" into your machine's MOK (Machine Owner Key) database. Once enrolled, the drive will boot without requiring you to disable Secure Boot in the system firmware.
