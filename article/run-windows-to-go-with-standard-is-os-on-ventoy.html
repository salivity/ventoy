Run Windows To Go with Standard ISOs on Ventoy

Ventoy fully supports running portable Windows environments like Windows To Go directly alongside standard operating system ISO files on the exact same USB drive. By utilizing VHD and VHDX virtual hard disk files, users can carry a fully functional, persistent Windows desktop while simultaneously maintaining a multi-boot library of Linux distributions, rescue utilities, and standard Windows installer media on a single device.

How Ventoy Handles Windows To Go

Instead of dedicating an entire flash drive to a single Windows To Go (WTG) installation, Ventoy allows you to encapsulate the portable OS inside a single .vhd or .vhdx file. Ventoy recognizes and boots virtual hard disks directly from its main storage partition, treating them just like any standard .iso, .img, or .efi file in your menu.

Because the operating system resides entirely within the VHD container, all file modifications, software installations, and user settings persist across reboots without interfering with the other ISO images stored on the drive.

Requirements for Running WTG on Ventoy

To boot a Windows To Go environment alongside standard ISOs, you need:

  • Ventoy USB Drive: A flash drive or external SSD formatted with Ventoy.
  • A Windows To Go VHD/VHDX File: A virtual disk containing an installed, bootable version of Windows.
  • The Ventoy VHD Plugin: A small helper file (ventoy_vhdboot.img) that provides the necessary drivers for Ventoy to chainload Windows from a virtual disk in both UEFI and Legacy BIOS modes.

Step-by-Step Setup

  1. Create the VHD/VHDX: Use tools such as Rufus, Hasleo WinToUSB, or the native Windows Disk Management tool alongside DISM to install Windows into a fixed or dynamically expanding VHD/VHDX container.
  2. Install the VHD Boot Plugin: Download the ventoy_vhdboot package from Ventoy's official plugin repository. Extract the ventoy_vhdboot.img file and place it inside a folder named ventoy located in the root of your Ventoy partition.
  3. Transfer the Files: Copy your created .vhd or .vhdx file directly into the Ventoy USB partition, placing it in the same directory (or organized subdirectories) alongside your installer ISOs.
  4. Boot and Configure: Boot from the Ventoy drive, select your VHD/VHDX from the on-screen menu, and complete the initial Windows setup (OOBE) if running it for the first time.

Performance Considerations

  • Drive Hardware: Running a full Windows operating system generates frequent read and write requests. A fast USB 3.1/3.2 flash drive, or preferably an external NVMe/SATA SSD enclosure, is recommended to prevent system stuttering.
  • VHD Disk Type: While dynamic VHDs save initial space on your Ventoy drive, fixed-size VHDs offer significantly faster read/write performance and lower fragmentation, which is beneficial for portable OS stability.
