Does Ventoy Accept Community Translations?

Yes, the Ventoy development repository actively accepts community language translations. Because Ventoy is an open-source project designed for a global audience, the developers rely on community contributions to localize the software. Users can submit new translations or improve existing ones by submitting Pull Requests (PRs) directly through the official Ventoy repository on GitHub.

How Ventoy Translations Work

Ventoy’s user interfaces—including the Ventoy2Disk desktop utility and the WebUI—utilize standardized JSON files to manage localization strings. Each supported language is mapped within these configuration files, allowing the software to dynamically load localized text for menus, buttons, status indicators, and warning dialogues.

Where Translation Files Are Located

Translations are stored in dedicated directories within the source code. The primary localization files are typically found in the repository under:

  • Ventoy2Disk/language/ or within the WebUI source folders, primarily defined in languages.json.

In this file, each language has an entry containing key-value pairs representing the original English string and the corresponding translated text.

How to Contribute a Translation

To contribute a translation to the Ventoy project:

  1. Fork the Repository: Create a fork of the official Ventoy GitHub repository under your personal GitHub account.
  2. Locate the Language File: Navigate to the language configuration files within the source tree.
  3. Add or Edit Strings:
    • If improving an existing language, locate your language code and update the translated values.
    • If adding a new language, append a new language structure using the appropriate ISO language code and provide the translated strings for all required keys.
  4. Preserve Format and Encoding: Ensure the file remains valid JSON and is saved using UTF-8 encoding without BOM to prevent display issues or software crashes.
  5. Submit a Pull Request: Commit the changes to your fork and open a Pull Request against the main branch of the Ventoy repository. Include a clear title indicating the addition or update of the specific language.

Once submitted, the maintainer reviews the changes for formatting and integrates them into the next official software release.
