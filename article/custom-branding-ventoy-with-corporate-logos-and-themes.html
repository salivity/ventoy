Custom Branding Ventoy with Corporate Logos and Themes

Ventoy can be fully branded for corporate environments. By leveraging Ventoy's native plugin architecture and the underlying GRUB2 theming engine, organizations can replace default boot screens with custom corporate logos, tailored color schemes, custom typography, and mandatory legal or compliance disclaimers.

Theming Engine and Structure

Ventoy relies on GRUB2 to render its boot environment. Because GRUB2 supports graphical themes, any visual asset or layout configuration supported by GRUB2 can be applied to Ventoy.

Branding is managed using two primary components on the primary data partition of the Ventoy USB drive:

  1. ventoy/ventoy.json: The global configuration file used to define plugin settings, including the theme path.
  2. Theme Directory: A dedicated folder (typically ventoy/theme/) containing graphical assets, font files, and a theme.txt layout descriptor.

Applying Corporate Logos and Color Schemes

Customizing the visual appearance involves modifying or replacing the assets referenced by theme.txt:

  • Background Art and Logos: Corporate logos and background graphics can be saved as high-resolution PNG or JPG files and set as the canvas background. If a persistent corporate logo is required over dynamic menus, it can either be baked directly into the background wallpaper or defined as a separate bitmap component within theme.txt.
  • Color Palettes: Every text element, highlight bar, menu border, and scrollbar can be configured to match corporate brand guidelines. Hexadecimal color codes (e.g., #FFFFFF) are declared inside theme.txt for properties such as item_color, selected_item_color, and menu_pixmap_style.
  • Custom Typography: Organizations can convert standard TrueType fonts (TTF) into the GRUB font format (.pf2) using the grub-mkfont utility. This allows boot screens to adhere strictly to corporate typography standards.

Adding Legal Disclaimers

Enterprises often require acceptable use policies or legal disclaimers on bootable diagnostic and deployment media. Ventoy accommodates disclaimers through three primary methods:

  1. Static Visual Embedding: The simplest approach is embedding the legal text directly onto the background image using an image editor. This guarantees the disclaimer displays consistently regardless of screen resolution scaling.
  2. GRUB Label Components: The theme.txt file supports static label components. Administrators can define a text block at the top or bottom of the screen containing the disclaimer, specifying font size, alignment, and color.
  3. Menu Aliases and Help Text: Ventoy allows custom text, titles, and tips to be mapped to individual menu options via the menu_alias and theme plugins in ventoy.json, providing contextual warnings before an image is booted.

Configuration Example

To activate a custom corporate theme, create the configuration file at /ventoy/ventoy.json with the following structure:

{
    "theme": {
        "file": "/ventoy/theme/corporate/theme.txt",
        "gfxmode": "1920x1080"
    }
}

Inside /ventoy/theme/corporate/theme.txt, define the visual properties and legal notices:

title-text: ""
desktop-image: "background.png"
terminal-font: "Corporate-Font-14.pf2"

+ label {
    top = 90%
    left = 10%
    width = 80%
    text = "UNAUTHORIZED ACCESS PROHIBITED. All activities are monitored and logged."
    color = "#FF0000"
    font = "Corporate-Font-12.pf2"
    align = "center"
}
