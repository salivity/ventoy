How to Update Ventoy Without Losing ISO Files

Updating Ventoy to the latest version does not require formatting your USB drive or re-copying your collection of ISO files. Ventoy separates the drive into two partitions: a hidden EFI boot partition containing the Ventoy system files and a standard partition that holds your images. By using the dedicated update function rather than a fresh installation, the software only overwrites the system partition, leaving all your stored data completely intact.

Updating Ventoy on Windows

  1. Download the latest Ventoy release zip file (ventoy-x.x.xx-windows.zip) from the official repository and extract it to your computer.
  2. Insert your existing Ventoy USB drive into your PC.
  3. Open the extracted folder and run Ventoy2Disk.exe.
  4. Select your USB drive from the Device drop-down list.
  5. Check the version numbers displayed on the interface:
    • Ventoy In Device: Displays the version currently installed on your USB.
    • Ventoy In Package: Displays the new version ready to be installed.
  6. Click the Update button. Do not click "Install", as "Install" reformats the drive and erases all data.
  7. Confirm the prompt when asked to proceed with the update.

Once the progress bar completes, a message will confirm that the update was successful. Your ISOs, custom themes, and configuration files will remain untouched.

Updating Ventoy on Linux

You can update Ventoy on Linux using either the graphical interface or the command line.

Using the Command Line (CLI)

  1. Download the latest Linux tarball (ventoy-x.x.xx-linux.tar.gz) and extract it.
  2. Plug in your Ventoy USB drive and identify its device identifier (e.g., /dev/sdb, not a specific partition like /dev/sdb1) using the lsblk command.
  3. Open a terminal inside the extracted Ventoy directory.
  4. Run the installation script with the update flag (-u): 
    sudo sh Ventoy2Disk.sh -u /dev/sdX
    (Replace /dev/sdX with your actual drive letter).
  5. Review the version information displayed in the terminal and confirm the prompt to proceed.

Using the Linux GUI

  1. Inside the extracted directory, launch the graphical tool corresponding to your system architecture (e.g., sudo ./VentoyGUI.x86_64).
  2. Select your USB drive from the device list.
  3. Verify the installed and package versions.
  4. Click the Update button.

Verifying the Update

After the process finishes, you can safely remove the USB drive. When you next boot into the Ventoy USB, the new version number will appear at the bottom of the boot selection screen alongside all of your pre-existing ISO files.
