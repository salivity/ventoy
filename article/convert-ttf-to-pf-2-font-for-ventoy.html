Convert TTF to PF2 Font for Ventoy

Ventoy uses the GRUB2 bootloader engine to render its visual themes, which relies on the custom PFF2 (.pf2) bitmap font format rather than modern scalable TrueType (.ttf) or OpenType (.otf) fonts. To customize the typography of your Ventoy menu, you must convert your TTF files into the PF2 format using the grub-mkfont utility. This guide walks you through installing the required tool, converting the font at your desired size, and placing the resulting file onto your Ventoy drive.

Step 1: Install grub-mkfont

The grub-mkfont tool is the official utility used to generate PF2 files. It is natively available on Linux and can be used on Windows via the Windows Subsystem for Linux (WSL).

Install it using your system's package manager:

  • Ubuntu / Debian / WSL: 
    sudo apt update
sudo apt install grub-common
  • Fedora / RHEL: 
    sudo dnf install grub2-tools
  • Arch Linux: 
    sudo pacman -S grub

Step 2: Convert the TTF Font to PF2

Because PF2 is a pre-rendered bitmap format, you must specify the exact font size during conversion. If you need multiple sizes for different elements (such as titles versus menu items), you must generate separate PF2 files for each size.

Run the grub-mkfont command with the following syntax:

grub-mkfont -s [size] -o [output.pf2] [input.ttf]

Parameters:

  • -s: Sets the font size in points/pixels (common sizes are 14, 16, 18, or 24).
  • -o: Defines the path and filename for the generated .pf2 file.

Example: To convert Roboto-Regular.ttf into a 16pt font named roboto_16.pf2, run:

grub-mkfont -s 16 -o roboto_16.pf2 Roboto-Regular.ttf

Step 3: Add the PF2 Font to Ventoy

  1. Plug in your Ventoy USB drive and open the primary partition.
  2. Navigate to your theme directory (typically located at ventoy/theme/YourThemeName/).
  3. Copy your newly created .pf2 file into the theme directory.
  4. Open your theme's theme.txt configuration file in a text editor.
  5. Update the font properties to target your new file:
title-font: "roboto_16.pf2"
item_font: "roboto_16.pf2"

Save the file and reboot your system to verify the new typography in your Ventoy boot menu.
