Verify Ventoy ISO with Upstream SHA-256 Hash

Yes, an ISO file booted via Ventoy can be verified with its official upstream SHA-256 hash. Because Ventoy operates by dynamically mapping the original ISO image directly into memory or presenting it via block-level loop devices without modifying its contents, the underlying file remains completely identical to the upstream release. This guide outlines how Ventoy handles ISOs and explains the methods available to verify the SHA-256 hash before, during, and after booting.

How Ventoy Preserves File Integrity

Unlike traditional bootable USB creation tools that extract the contents of an ISO or alter its bootloader to make it bootable on a flash drive, Ventoy leaves the original ISO file untouched. When you copy an ISO to the Ventoy partition, it acts purely as standard storage. During boot, Ventoy reads the contiguous disk sectors of the file and hooks the OS boot process (using mechanisms like dm-linear or internal memory mapping) to present the unmodified image to the operating system. Because no bytes are altered, the SHA-256 checksum remains identical to the one published by the OS vendor.

Method 1: Verification Before Booting (Recommended)

The most direct way to verify the hash is to check the file located on the Ventoy USB drive from your host operating system prior to booting.

  • Linux / macOS: Open a terminal, navigate to your mounted Ventoy drive, and run: 
    sha256sum /path/to/ventoy/image.iso
  • Windows (PowerShell): Run the following command: 
    Get-FileHash -Algorithm SHA256 "E:\path\to\image.iso"
  • Windows (Command Prompt): 
    certutil -hashfile "E:\path\to\image.iso" SHA256

Compare the resulting output string directly with the SHA-256 checksum provided by the upstream distributor.

Method 2: Verification at the Ventoy Boot Menu

Ventoy includes built-in verification capabilities directly within its boot interface, allowing you to confirm the hash before launching the installer or live system.

  1. Ventoy Checksum Menu: In modern versions of Ventoy, highlight your desired ISO in the boot list and press Ctrl + c (or look for the checksum prompt displayed on your specific theme) to calculate and display the MD5, SHA-1, and SHA-256 hashes of the selected file.
  2. Ventoy Checksum Plugin (ventoy.json): You can automate verification by using Ventoy's official plugin. By defining an upstream hash inside a ventoy.json configuration file located in the ventoy folder, Ventoy can automatically validate the ISO against the expected SHA-256 string before launching the boot sequence.

Method 3: Verification from Inside the Booted Live Environment

Once booted into a live environment, verifying the overall ISO hash depends on how the live system mounts its source media:

  • Accessing the Ventoy Drive: If the booted operating system mounts the underlying physical USB drive (often found under /dev/sdX1 on Linux), you can run sha256sum directly against the .iso file stored on the disk.
  • Checking Mapped Virtual Devices: Ventoy typically creates a virtual loop device (such as /dev/loop0 or /dev/dm-0) representing the ISO. Calculating the SHA-256 hash of this raw mapped device will match the upstream ISO hash, provided the virtual device exposes the exact sector count of the original image without padding: 
    head -c $(stat -c %s /path/to/original.iso) /dev/loop0 | sha256sum
  • Internal Installer Integrity Checks: Note that built-in distro tools (such as Ubuntu’s "Check disc for defects") do not check the full ISO SHA-256 hash. Instead, they scan individual files against an internal md5sum.txt file located inside the ISO. While useful for finding read errors, this is distinct from comparing the full image against the upstream SHA-256 release hash.
