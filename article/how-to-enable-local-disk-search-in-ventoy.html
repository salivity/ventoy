How to Enable Local Disk Search in Ventoy

Ventoy allows you to boot ISO, WIM, and other supported image files directly from internal hard drives instead of copying them to your USB drive. This guide covers how to enable local disk search in Ventoy automatically using the configuration file, as well as how to quickly browse internal disks on the fly using boot menu hotkeys.

Method 1: Enable Automatic Search via ventoy.json

To make Ventoy scan your internal local disks automatically every time it boots, configure the global control setting in the ventoy.json file.

  1. Access the Ventoy Partition: Plug your Ventoy USB drive into your computer and open the partition where your ISO files are stored.
  2. Create the Ventoy Folder: In the root directory of the USB drive, check if a folder named ventoy exists. If not, create a new folder and name it ventoy (lowercase).
  3. Create or Edit ventoy.json: Inside the ventoy folder, open or create a file named ventoy.json.
  4. Add the Configuration Code: Paste the following JSON structure into the file:
{
    "control": [
        { "VTOY_SEARCH_LOCAL_DISK": "1" }
    ]
}
  1. Save the File: Save your changes. When you next boot from the Ventoy USB drive, it will automatically index and list bootable image files located on your internal hard drives and SSDs alongside your USB files.

Note: Searching large or multiple internal disks can increase the initial boot time of the Ventoy menu.

Method 2: Manually Browse Local Disks via Hotkey (F2)

If you only need to boot an image from a local disk occasionally, you can browse local drives manually without modifying configuration files.

  1. Boot your computer using the Ventoy USB drive.
  2. At the main Ventoy boot menu, press F2 on your keyboard to enter Browse Mode.
  3. Ventoy will display a list of all detected storage devices and partitions, including internal SATA, NVMe, and external drives.
  4. Select the partition containing your boot files and press Enter.
  5. Navigate through the directory folders to locate your .iso or .wim file, select it, and press Enter to boot normally.
