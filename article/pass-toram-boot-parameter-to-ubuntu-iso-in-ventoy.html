Pass toram Boot Parameter to Ubuntu ISO in Ventoy

Loading an Ubuntu live environment entirely into system memory via the toram kernel parameter significantly improves operating speed and allows you to safely disconnect the USB drive during use. Ventoy provides multiple ways to accomplish this, either dynamically during boot or automatically through a persistent configuration script. This guide covers how to append toram to your Ubuntu ISO boot arguments using both methods.

Method 1: Appending toram at Boot Time (Temporary)

This method requires no prior setup and works on-the-fly for a single session:

  1. Insert your Ventoy USB drive and boot your computer from it.
  2. Navigate the Ventoy list, select your Ubuntu ISO, and press Enter.
  3. Choose Boot in normal mode (or Boot in grub2 mode if normal mode is unavailable).
  4. When the Ubuntu GRUB menu appears with options such as "Try or Install Ubuntu", highlight the default entry and press the e key to edit the boot configuration.
  5. In the editor screen, use the arrow keys to locate the line starting with linux (typically ending with quiet splash ---).
  6. Move the cursor to the end of that line, add a space, and type: 
    toram
  7. Press Ctrl + X or F10 to boot the system.

Ubuntu's casper live-boot scripts will copy the entire filesystem into your computer's RAM before loading the desktop.

Method 2: Automating with ventoy_grub.cfg (Persistent)

If you use the toram option frequently, you can define a custom GRUB menu entry in Ventoy so you do not have to type the parameter manually each time.

  1. Mount your Ventoy USB drive on your computer.
  2. In the root of the USB drive (the main storage partition where your ISO files reside), create a folder named ventoy if it does not already exist.
  3. Inside the ventoy folder, create a plain text file named ventoy_grub.cfg.
  4. Open ventoy_grub.cfg in a text editor and add the following entry, replacing /ubuntu-24.04-desktop-amd64.iso with the exact path and filename of your ISO:
menuentry "Ubuntu Live (Load to RAM)" {
    set iso_path="/ubuntu-24.04-desktop-amd64.iso"
    export iso_path
    search --no-floppy --file --set=root $iso_path
    loopback loop $iso_path
    linux (loop)/casper/vmlinuz boot=casper iso-scan/filename=$iso_path toram quiet splash ---
    initrd (loop)/casper/initrd
}
  1. Save the file and safely eject the USB drive.
  2. Boot from the Ventoy drive and press F6 on the main menu to open the Ventoy custom menu.
  3. Select Ubuntu Live (Load to RAM) to boot directly into RAM.

Method 3: Using Ventoy's Memdisk Mode

Ventoy also includes a built-in feature to load the entire ISO into memory prior to execution:

  1. Select your Ubuntu ISO on the Ventoy boot menu.
  2. Press Ctrl + M to switch to Memdisk mode (you will see the menu state change).
  3. Press Enter to boot the ISO.

Note: While Memdisk mode copies the raw image to RAM directly at the bootloader level, native Linux kernel support for this varies depending on the ISO version. Using the official casper parameter (toram) via Method 1 or Method 2 provides the most reliable result across standard Ubuntu releases.
