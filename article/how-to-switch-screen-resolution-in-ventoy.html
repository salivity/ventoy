How to Switch Screen Resolution in Ventoy

This article explains how to change the display resolution in the Ventoy bootloader using built-in keyboard shortcuts. If the default interface appears stretched, distorted, or fails to render properly on your monitor, adjusting the resolution settings directly from the boot menu ensures proper visibility and ease of navigation without modifying configuration files beforehand.

The Hotkey for Changing Resolution

In the Ventoy bootloader, the primary hotkey used to access resolution settings is F5.

Pressing F5 opens the Tools menu. From there, you can access the display options by following these steps:

  1. Boot your computer using the Ventoy USB drive to reach the main menu.
  2. Press the F5 key on your keyboard to open the Tools screen.
  3. Use the arrow keys to highlight Resolution Configuration and press Enter.
  4. A list of all video modes and resolutions supported by your graphics hardware and display will appear.
  5. Select your preferred resolution (such as 1920x1080, 1024x768, or 800x600) and press Enter.

The Ventoy interface will immediately reload in the selected screen resolution.

Switching to Text Mode with F7

If your display cannot render the graphical user interface at all, you can use F7.

Pressing F7 switches Ventoy from graphical mode to standard text mode. Text mode bypasses high-resolution graphics drivers and renders a basic terminal interface, which resolves black-screen issues and incompatible refresh rates on older or specialized hardware. Pressing F7 again toggles the display back to graphical mode.
