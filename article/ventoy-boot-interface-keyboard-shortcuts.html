Ventoy Boot Interface Keyboard Shortcuts

Ventoy is a popular tool for creating multi-boot USB drives that allows users to launch ISO, WIM, IMG, VHD(x), and EFI files directly from a single drive. Beyond standard menu navigation, the main Ventoy boot interface includes a variety of built-in keyboard shortcuts to alter boot methods, toggle display settings, and access system utility options. This guide outlines every functional hotkey available on Ventoy's primary boot screen to help you navigate and configure your boot environment efficiently.

Function Key Shortcuts

  • F1 (Memdisk Mode): Loads the selected ISO file entirely into system memory (RAM) before executing it. This is useful for smaller recovery tools, WinPE, or live distributions that struggle with standard virtual disk mapping.
  • F2 (Power Menu): Opens the power management menu, allowing you to reboot or shut down the machine directly from the boot interface.
  • F3 (Tree View): Toggles between the default flat list view (which shows all supported files across the entire drive) and a hierarchical directory tree view.
  • F4 (Local Boot): Scans and displays operating systems installed on the machine's local hard drives or SSDs, allowing you to bypass the USB drive and boot existing local installations.
  • F5 (Tools Menu): Displays system configuration and diagnostic tools. From here, you can change screen resolutions, toggle text and graphic modes, reload JSON configurations, and inspect hardware details.
  • F6 (ExMenu): Loads user-defined external menu scripts, such as custom GRUB2 or iPXE configuration files.
  • F7 (Text Mode): Toggles the interface between high-resolution graphical display mode and lightweight, low-resolution text mode. This is particularly useful on hardware with incompatible or bugged graphics drivers.

Control Key Combinations

Before pressing Enter to boot an image, you can use specific Ctrl key modifiers to change how Ventoy mounts and executes the selected file:

  • Ctrl + r (wimboot Mode): Forces Ventoy to use the wimboot loader instead of standard methods, specifically intended for Windows imaging files (WIM).
  • Ctrl + u (UDF Mode): Forces UDF filesystem driver emulation when mounting compatible ISO images.
  • Ctrl + d (Debug Mode): Enables verbose debug output during the boot process to troubleshoot bootloader failures.
  • Ctrl + n (Normal Mode): Resets the launch configuration to the default boot method.
  • Ctrl + i (Ignore Check): Skips file integrity and compatibility checks prior to loading.
  • Ctrl + g (GRUB2 Mode): Boots the ISO using GRUB2's native loopback command rather than Ventoy’s custom virtual disk mechanism.

Standard Navigation Keys

  • Up / Down Arrow Keys: Move up and down through the list of bootable image files or directories.
  • Enter: Boots the selected image using the active mode, or enters the selected directory in Tree View.
  • Esc: Returns to the parent directory in Tree View, exits sub-menus, or cancels secondary prompts.
  • Page Up / Page Down: Jumps one full screen of entries up or down for fast navigation on drives containing many files.
