Boot Windows VHD With Ventoy: Compatibility Guide

Ventoy supports booting VHD and VHDX images containing a fully installed Windows operating system, allowing users to run portable, native Windows environments directly from a USB drive. However, because a standard Windows installation disconnects USB storage controllers during the initial boot phase, achieving a successful boot requires the use of Ventoy's dedicated VHD boot plugin.

Native Windows VHD Boot Support in Ventoy

Ventoy can boot both fixed and dynamic VHD/VHDX virtual disks. When a full Windows operating system is installed inside a VHD file, it is commonly referred to as Native VHD Boot or a Windows To Go environment. Ventoy recognizes these files alongside standard ISOs and presents them directly in the boot menu.

The USB Boot Limitation and the Solution

Standard Windows installations are not designed to boot from external USB drives. During the boot process, Windows reinitializes the USB controllers, which temporarily cuts off access to the USB drive containing the VHD file. This interruption causes the operating system to crash with an INACCESSIBLE_BOOT_DEVICE blue screen error (BSOD).

To resolve this issue, Ventoy provides a specialized plugin file named ventoy_vhdboot.img. This utility hooks into the Windows boot loader to maintain the virtual disk connection through the transition from the firmware boot phase to the loaded Windows kernel.

Requirements for Running Windows VHD on Ventoy

To successfully run a fully installed Windows system from a VHD using Ventoy, several conditions must be met:

  • The VHD Boot Plugin: The ventoy_vhdboot.img file must be retrieved from the official Ventoy plugin release and placed in the ventoy directory on the USB drive.
  • OS Preparation: The Windows installation inside the VHD should ideally be configured with generic drivers or prepared with Sysprep so it can adapt to different host hardware.
  • Boot Mode Consistency: The partition style of the VHD (MBR or GPT) must align with the target system's boot mode (Legacy BIOS or UEFI). For maximum compatibility across modern hardware, UEFI with a GPT-based VHD is recommended.
  • USB Hardware Speed: Because Windows continuously reads and writes system files during runtime, the USB drive should support USB 3.0 or higher to maintain usable system performance.

Once the ventoy_vhdboot.img file is properly placed in the ventoy folder, you simply place your Windows .vhd or .vhdx file anywhere on the storage partition of your Ventoy drive, select it from the boot menu, and boot the operating system normally.
