How to Format Ventoy Partition as exFAT

This guide explains how to set the main data partition of a Ventoy USB drive to the exFAT file system. Ventoy divides a flash drive into two partitions: a hidden boot partition (VTOYEFI) and a primary data partition where ISO files are stored. While exFAT is the default file system for Ventoy, you can explicitly configure it during the initial installation or safely reformat the primary data partition on an existing Ventoy drive without damaging the bootloader.

Method 1: Set exFAT During Initial Installation

If you are creating a new Ventoy drive using the official Ventoy tool, you can select exFAT before installing.

  1. Insert your USB drive into your computer.
  2. Open the Ventoy2Disk application.
  3. Select your USB device from the Device drop-down menu.
  4. Click on the Option menu in the top toolbar.
  5. Navigate to Partition Configuration.
  6. Check the Partition File System setting and select exFAT from the drop-down list.
  7. Click OK to save the settings.
  8. Click Install to format the drive and install Ventoy with an exFAT data partition.

Method 2: Reformat an Existing Ventoy Partition (Windows)

If Ventoy is already installed and you want to switch or reset the data partition to exFAT, format only the primary partition. Do not format the secondary EFI partition.

  1. Insert your Ventoy USB drive into your Windows PC.
  2. Open File Explorer and locate the drive labeled Ventoy.
  3. Right-click the Ventoy drive and select Format...
  4. Under File system, select exFAT.
  5. Set the Allocation unit size to the default value.
  6. Ensure the Volume label is set to Ventoy.
  7. Check the Quick Format box.
  8. Click Start and confirm the prompt to format the partition.

Method 3: Reformat an Existing Ventoy Partition (Linux)

You can reformat the data partition in Linux using the terminal while keeping the boot partition intact.

  1. Open a terminal.
  2. Identify the partition identifiers of your USB drive: 
    lsblk
    Ventoy will typically show as a drive with two partitions (e.g., /dev/sdb1 for data and /dev/sdb2 for VTOYEFI).
  3. Unmount the data partition if it is currently mounted: 
    sudo umount /dev/sdX1
    (Replace /dev/sdX1 with your actual Ventoy data partition).
  4. Format the first partition as exFAT: 
    sudo mkfs.exfat -n Ventoy /dev/sdX1
  5. Run sync to ensure all operations are completed before unplugging the drive.
