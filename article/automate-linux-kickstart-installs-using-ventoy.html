Automate Linux Kickstart Installs Using Ventoy

Ventoy fully supports automating Linux Kickstart installations during the boot process using its built-in Auto Install Plugin. By pairing vanilla Linux distribution ISOs with automated installation scripts via a central JSON configuration file, Ventoy can inject Kickstart files into the boot environment automatically, eliminating the need to modify original ISO files or manually enter boot parameters.

How Ventoy Automates Kickstart Installations

Ventoy achieves unattended installations through the auto_install plugin. When you boot an installer image—such as Red Hat Enterprise Linux, CentOS, Rocky Linux, Fedora, or AlmaLinux—Ventoy detects the selected ISO, references a configuration script, and dynamically appends the necessary kernel parameters (like inst.ks=...) at boot time. This points the installer's kernel directly to your specified Kickstart (ks.cfg) file.

Setting Up Automated Kickstart in Ventoy

To configure automated installations, your Ventoy USB drive must be formatted and partitioned normally, after which you configure the plugin files inside the primary partition.

  1. Create the Configuration Directory: In the root of the Ventoy storage partition, create a directory named ventoy.

  2. Add Your Kickstart Script: Save your Kickstart template (e.g., centos8_ks.cfg or rhel9_ks.cfg) inside the ventoy folder or a dedicated subfolder, such as /ventoy/script/.

  3. Configure ventoy.json: Create a file named ventoy.json inside the /ventoy/ directory. Use the auto_install block to map specific ISO files to their corresponding Kickstart scripts.

{
    "auto_install": [
        {
            "image": "/ISO/Rocky-9-x86_64-dvd.iso",
            "template": "/ventoy/script/rocky9_ks.cfg"
        }
    ]
}

You can define multiple mappings within this array. Ventoy matches the selected ISO image path with the assigned script template.

Managing Multiple Configurations

If you want the option to choose between an unattended installation and an interactive installation, Ventoy allows you to assign multiple templates or an array of configurations to a single ISO:

{
    "auto_install": [
        {
            "image": "/ISO/RHEL-9.iso",
            "template": [
                "/ventoy/script/rhel_server_ks.cfg",
                "/ventoy/script/rhel_workstation_ks.cfg"
            ]
        }
    ]
}

When booting this ISO, Ventoy prompts you with a menu to select which Kickstart template to deploy, or to boot the ISO normally without automation.

Supported Environments and Variables

Ventoy's automation engine is not limited to Red Hat-based Kickstart; it also supports Debian/Ubuntu Preseed scripts, SUSE AutoYaST XML files, and Windows unattend.xml answers.

Additionally, Ventoy provides internal template variables (such as disk identifiers and device paths) that can be dynamically expanded inside the configuration files, making it easier to define universal deployment scripts that work across diverse hardware without manual modification.
