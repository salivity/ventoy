How to Boot ISO in Memdisk Mode with Ventoy

Ventoy includes an alternative execution feature called Memdisk mode, which loads an entire ISO image directly into the computer's physical memory before booting. This article explains how to select and enable Memdisk mode for any specific ISO file directly from the Ventoy boot menu, ensuring compatibility for smaller utility images, WinPE environments, and legacy boot media that fail under normal boot modes.

Steps to Activate Memdisk Mode

  1. Boot into Ventoy: Insert your Ventoy USB drive into your target computer and boot into the main Ventoy interface.
  2. Locate the ISO: Use the arrow keys on your keyboard to navigate through the list and highlight the specific ISO you want to run.
  3. Open the Boot Option Menu: Press Enter on the highlighted ISO. In modern versions of Ventoy, pressing Enter does not boot immediately; instead, it opens a secondary selection menu with available launch modes.
  4. Select Memdisk Mode: Use the arrow keys to scroll down and select Boot in memdisk mode, then press Enter to start the loading process.

Alternative Hotkey Method

You can also trigger Memdisk mode without opening the sub-menu:

  1. Highlight the target ISO in the main Ventoy menu.
  2. Press Ctrl + m on your keyboard.
  3. Ventoy will toggle Memdisk mode for that specific file and launch it into RAM immediately.

Requirements and Limitations

  • RAM Capacity: Because the image is written directly to memory, your system must have significantly more available RAM than the total file size of the ISO.
  • Operating System Support: Memdisk mode is primarily designed for WinPE, DOS utilities, small rescue disks, and legacy environments. It generally will not work for large, standard Linux distributions (such as Ubuntu or Fedora) that require their root filesystems to be loaded from disk stages.
