How to Map Function Keys to Utilities in Ventoy

Mapping the F1 through F12 function keys to specific utilities in Ventoy allows you to launch vital diagnostics, recovery environments, and maintenance tools with a single keystroke. This functionality is achieved using Ventoy’s extension menu configuration file (ventoy_grub.cfg), which leverages the underlying GRUB2 bootloader engine to assign hotkeys directly to menu entries. This guide walks you through setting up the configuration file, assigning function keys with the --hotkey parameter, and scripting direct-boot entries for your utilities.

1. Create the Ventoy Extension Configuration

Ventoy scans the primary data partition (where your ISO images reside) for a dedicated configuration directory.

  1. Connect your Ventoy USB drive to your computer.
  2. Open the main file partition of the drive.
  3. Check for a folder named ventoy (all lowercase) in the root directory. If it does not exist, create it.
  4. Inside the /ventoy/ directory, create a new text file named ventoy_grub.cfg.

2. Define Menu Entries with Hotkeys

The ventoy_grub.cfg file accepts standard GRUB2 scripting. To bind an action to a function key, add the --hotkey flag followed by the desired key identifier (e.g., f1, f2, up to f12) directly to the menuentry definition.

Open /ventoy/ventoy_grub.cfg in a text editor and add your entries using the following syntax:

menuentry "MemTest86+ [F1]" --hotkey=f1 {
    set iso_path="/ISO/memtest86.iso"
    loopback loop $iso_path
    linux (loop)/boot/memtest.bin
}

menuentry "Clonezilla Live [F2]" --hotkey=f2 {
    set iso_path="/ISO/clonezilla.iso"
    loopback loop $iso_path
    linux (loop)/live/vmlinuz boot=live findiso=$iso_path union=overlay components quiet
    initrd (loop)/live/initrd.img
}

menuentry "Reboot System [F11]" --hotkey=f11 {
    reboot
}

menuentry "Power Off [F12]" --hotkey=f12 {
    halt
}

3. Key Naming Syntax

When defining hotkeys, follow these formatting guidelines:

  • Keys are case-insensitive in GRUB syntax (f1 through f12 or F1 through F12).
  • Do not leave a space between --hotkey= and the key name.
  • Including the key bracket in the label (e.g., [F1]) is recommended so you can easily identify the shortcut inside the on-screen menu.

4. Navigating Default Ventoy Key Conflicts

In the main Ventoy browser menu, several function keys are reserved for native features:

  • F1: Memdisk mode toggle
  • F2: Power menu
  • F3: Tree view toggle
  • F4: Local boot
  • F5: Debug/Tools
  • F6: Extension Menu (Ventoy Grub Menu)

Because the main interface captures these default functions, custom hotkeys defined in ventoy_grub.cfg take effect inside Ventoy's Extension Menu. Press F6 from the main Ventoy screen to load your custom menu, where pressing any assigned key from F1 through F12 will instantly execute its mapped utility.
