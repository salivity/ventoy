Show File Size and Date in Ventoy Boot Menu

Ventoy is a popular utility for creating multi-boot USB drives by simply copying image files to the device. While it automatically detects bootable ISO, WIM, IMG, and VHD files, many users want to know if the boot screen can display metadata such as file sizes and last modified dates. This article explains Ventoy's native capabilities regarding file metadata display and the practical workarounds available to display this information on the boot screen.

Native Support for File Size and Date

Ventoy cannot automatically detect and display the file size or last modified date of image files on the boot screen. By default, the scanning mechanism reads only the file names and folder structures from the supported partitions. It does not query or parse filesystem metadata attributes—such as file size in bytes or timestamps—when populating the GRUB-based boot menu.

Because Ventoy executes in a lightweight pre-boot environment, keeping the menu generation fast and reliable across different filesystems (exFAT, NTFS, ext4, UDF) takes precedence over querying detailed file properties. As a result, there is no built-in toggle to dynamically print file sizes or timestamps alongside listed images.

Workarounds to Display Size and Date

Although automatic metadata rendering is not supported, you can manually display file sizes and dates using built-in Ventoy features.

1. Rename the Image Files

The most straightforward method is including the size and release or modification date directly in the file name on your USB drive.

  • Example: ubuntu-24.04-desktop-amd64-[5.8GB-2024-04].iso

Ventoy displays the full file name by default, making this information visible immediately without requiring any configuration.

2. Use the Menu Alias Plugin

If you prefer to keep standard file names on your storage partition, you can use Ventoy's menu_alias plugin to override how titles appear on the screen.

  1. Navigate to the ventoy directory on your USB drive (create one if it does not exist).
  2. Create or edit the ventoy.json configuration file.
  3. Define aliases that include your desired file details:
{
    "menu_alias": [
        {
            "image": "/ISO/Win11_English_x64.iso",
            "alias": "Windows 11 64-bit [Size: 5.4 GB | Date: 2023-10-15]"
        },
        {
            "image": "/ISO/archlinux-x86_64.iso",
            "alias": "Arch Linux [Size: 1.1 GB | Date: 2024-05-01]"
        }
    ]
}

3. Use the Menu Tip Plugin

Ventoy also provides a menu_tip plugin that displays descriptive text at the bottom of the screen whenever a specific menu entry is highlighted. This keeps the main menu list uncluttered while still providing file details.

Add a menu_tip section to your ventoy.json file:

{
    "menu_tip": {
        "tips": [
            {
                "image": "/ISO/Win11_English_x64.iso",
                "tip": "File Size: 5.4 GB | Last Modified: October 2023"
            }
        ]
    }
}

Summary

Ventoy does not natively fetch and display image file sizes or modification dates automatically. However, users who require this information on screen can achieve the desired result by incorporating the details into the file names directly or by configuring the menu_alias and menu_tip options in the ventoy.json file.
