Customize Ventoy Boot Menu With Theme Plugin

The Ventoy theme plugin allows users to customize the visual appearance of their multiboot USB drive's bootloader interface. This guide covers what the theme plugin is, how GRUB themes function within Ventoy, and the exact steps required to configure custom backgrounds, fonts, icons, and screen resolutions using the ventoy.json configuration file.

What Is the Ventoy Theme Plugin?

Ventoy relies on GRUB2 as its primary boot manager. By default, Ventoy presents a simple, functional interface listing the ISO and image files stored on the drive. The Ventoy Theme Plugin is an integrated feature that enables users to override this standard interface with custom GRUB2 themes. Through this plugin, you can modify the background image, menu box position, text colors, fonts, boot menu icons, and display resolution without modifying the core Ventoy bootloader files.

Preparing a GRUB2 Theme

Ventoy supports standard GRUB2 themes. You can download ready-made GRUB2 themes from community repositories like GNOME-Look, or create your own.

A standard theme directory typically contains:

  • theme.txt: The core configuration file defining positions, colors, and fonts.
  • Background image (.png or .jpg).
  • Font files (.pf2).
  • Icon sets for different operating systems.

Step-by-Step Setup Guide

1. Create the Ventoy Configuration Directory

Plug in your Ventoy USB drive and open the main data partition (where you store ISO files). In the root directory, create a new folder named exactly:

ventoy

2. Add Your Theme Files

Inside the ventoy directory, create a subfolder named theme. Copy your extracted theme folder into this directory. For example, if your theme is named dark-matter, the path should look like:

/ventoy/theme/dark-matter/theme.txt

3. Create the ventoy.json Configuration File

Inside the /ventoy folder, create a new text file named ventoy.json. Ventoy reads this JSON file to load plugins and apply settings.

4. Configure the Theme in ventoy.json

Open ventoy.json in a text editor and add the configuration block. Below is an example configuration:

{
    "theme": {
        "file": "/ventoy/theme/dark-matter/theme.txt",
        "gfxmode": "1920x1080",
        "display_mode": "GUI",
        "ventoy_color": "#ffffff"
    }
}

Key Configuration Parameters:

  • file: The absolute path from the root of the USB drive to the theme.txt file. Forward slashes (/) must be used.
  • gfxmode: Sets the screen resolution of the boot menu (e.g., 1920x1080, 1024x768, or auto).
  • display_mode: Can be set to GUI for graphical interface or CLI for text mode.
  • ventoy_color: Defines the text color used for Ventoy-specific UI elements such as version and hotkey prompts.

Setting Up Multiple Random Themes

Ventoy also allows you to define multiple themes that rotate randomly upon boot. To use this feature, specify an array of paths in the file field instead of a single string:

{
    "theme": {
        "file": [
            "/ventoy/theme/theme1/theme.txt",
            "/ventoy/theme/theme2/theme.txt"
        ],
        "gfxmode": "1920x1080"
    }
}

Testing Your Configuration

Once the ventoy.json file is saved, restart your computer and boot into your USB drive via UEFI or BIOS to view your customized bootloader. Ensure that the resolution defined in gfxmode is supported by your display to prevent rendering issues.
