How to Use Ventoy with Internal Hard Drive ISOs

Ventoy is widely recognized for its ability to boot multiple ISO files directly from a single USB flash drive without requiring reformatting. While Ventoy searches its own USB partition by default to generate its boot menu, it can also access and boot ISO files stored on internal hard drives. This guide covers how Ventoy interacts with local storage, how to use the built-in file browser to launch images from internal drives, and how to configure persistent custom entries to streamline the process.

Default Behavior and Limitations

By default, Ventoy restricts its automatic filesystem scan to the partition located on the Ventoy USB drive itself. It does not automatically index every internal hard drive during the initial boot sequence. This design choice prevents slow boot times that would otherwise occur if Ventoy had to scan large multi-terabyte internal drives, network storage, or complex partition tables upon startup.

Despite not automatically populating the main menu with internal ISOs, Ventoy contains full driver support to read internal SATA, NVMe, and external secondary drives formatted with file systems such as NTFS, FAT32, exFAT, ext2, ext3, and ext4.

Method 1: The F2 File Browser Mode

The quickest and most direct way to access an ISO file on an internal drive is through Ventoy's native file browser.

  1. Boot your computer from the Ventoy USB drive as you normally would.
  2. At the main Ventoy boot menu, press the F2 key to enter Browse Mode.
  3. Ventoy will display a list of all detected disks and partitions, including internal hard drives (often labeled by disk index, partition number, and filesystem).
  4. Navigate through the directory tree of your internal drive to the folder containing your ISO files.
  5. Select the target ISO and press Enter to boot it just as you would from the USB drive.

This method requires no prior configuration and works immediately with any supported filesystem.

Method 2: Custom Boot Menu (ventoy_grub.cfg)

If you regularly boot specific ISO files located on an internal hard drive, you can configure Ventoy to present a persistent menu option using a custom GRUB configuration script.

  1. On the ventoy partition of your USB drive, open the ventoy folder (create one if it does not exist).
  2. Create a file named ventoy_grub.cfg.
  3. Add a custom GRUB menu entry targeting your internal drive. For example:
menuentry "Boot Ubuntu from Internal Drive" {
    set root=(hd1,2)
    set iso_path="/ISOs/ubuntu-desktop.iso"
    ventoy_chain $iso_path
}

Note: Replace (hd1,2) with the correct disk and partition identifier of your internal drive, and adjust the file path to match your layout.

When you boot Ventoy, press F6 to access the custom menu, where your defined internal ISO entries will be ready to launch directly without manual directory navigation.

Key Considerations

  • Drive Encryption: Ventoy cannot read partitions encrypted with technologies such as BitLocker, LUKS, or VeraCrypt. Internal ISOs must reside on an unencrypted partition.
  • Boot Mode Compatibility: The ISO file on the internal disk must support the architecture and boot mode (UEFI or Legacy BIOS) that your system used to boot the Ventoy USB.
  • File Fragmentation: While modern versions of Ventoy handle fragmented images well, keeping internal ISO files contiguous ensures maximum compatibility across different hardware environments.
