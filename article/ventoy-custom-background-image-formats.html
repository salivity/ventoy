Ventoy Custom Background Image Formats

Customizing the boot interface in Ventoy allows users to replace the default screen with personalized artwork, logos, or system information. This guide outlines the specific image file formats supported by Ventoy for custom themes and backgrounds, along with key technical specifications and configuration requirements to ensure your custom background displays properly.

Supported File Formats

Ventoy relies on GRUB2 graphics drivers to render its user interface. As a result, it supports the standard image formats compatible with the GRUB2 graphics subsystem:

  • PNG (.png): Highly recommended. PNG supports lossless compression and transparency (alpha channels), making it the most reliable format for both backgrounds and interface icons.
  • JPG / JPEG (.jpg, .jpeg): Fully supported. Best suited for high-resolution photographic backgrounds where smaller file size is desired. Note that progressive JPEGs may occasionally fail to render; baseline standard JPEGs are required.
  • BMP (.bmp): Supported. Uncompressed bitmap images render reliably, though they result in larger file sizes.
  • TGA (.tga): Supported. Truevision TGA files (uncompressed or RLE-compressed) work within the GRUB environment, though they are less commonly used than PNG.

Resolution and Color Recommendations

To avoid stretching, letterboxing, or distortion, tailor your background image to match your display settings:

  • Aspect Ratio and Resolution: Standard 16:9 resolutions (1920x1080 or 1280x720) or 4:3 resolutions (1024x768) are standard. Setting the image to 1920x1080 covers the majority of modern displays.
  • Color Depth: 24-bit RGB or 32-bit RGBA color formats should be used. Indexed color palettes or CMYK color spaces are not supported and will fail to display.

Implementing the Custom Background

Ventoy handles custom backgrounds primarily through its theme plugin:

  1. Place your chosen image file into the ventoy directory on the USB drive (for example, /ventoy/background.png).
  2. Alternatively, integrate the image into a complete GRUB theme by placing it inside /ventoy/theme/<theme_name>/ and referencing it in the accompanying theme.txt file using the desktop-image: "filename.png" attribute.
  3. Configure your /ventoy/ventoy.json configuration file to point to the theme or background path. If the specified image format or path is invalid, Ventoy will fall back to its default blue graphical interface.
