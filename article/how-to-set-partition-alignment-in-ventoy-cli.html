How to Set Partition Alignment in Ventoy CLI

This guide explains how partition alignment functions in the Ventoy command-line interface, addressing the availability of explicit alignment parameters, Ventoy's default sector layout, and alternative methods for implementing custom partition alignment.

Ventoy CLI Alignment Support

The standard Ventoy command-line tool (Ventoy2Disk.sh on Linux or Ventoy2Disk.exe with CLI flags on Windows) does not provide a dedicated command-line flag (such as --align or -a) to explicitly define custom partition boundaries.

By design, Ventoy automatically enforces standard partition alignment:

  • Default Offset: The first partition (the exFAT/data partition VTOY) begins at sector 2048.
  • Standard Alignment: A start sector of 2048 corresponds to a 1 MiB boundary, which naturally guarantees 4K (4096-byte) alignment for Advanced Format drives, SSDs, and standard USB flash media.
  • Secondary Partition: The second partition (VTOYBOOT, containing bootloaders) is sized and placed immediately following the first partition, maintaining block integrity.

Because 1 MiB alignment is the universal standard for modern storage media and UEFI compatibility, explicit alignment parameters were omitted from the official utility.

Workarounds for Custom Partition Alignment

If you require non-standard partition alignment (such as aligning to specific erase-block sizes or custom cylinder offsets), you must use one of the following approaches.

Method 1: Modify the Ventoy Installation Script (Linux)

You can alter the hardcoded sector values inside the Linux installation script:

  1. Extract the Ventoy installation archive: 
    tar -xvf ventoy-x.x.xx-linux.tar.gz
cd ventoy-x.x.xx
  2. Open Ventoy2Disk.sh in a text editor.
  3. Locate the disk partitioning routine. In legacy and modern versions, Ventoy uses parted or fdisk to construct the layout:
    • Look for the command invoking parted -s "$TARGET_DEV" mklabel ... or fdisk.
    • Locate the start sector value assigned to the primary partition (default is 2048).
  4. Replace 2048 with your desired starting sector (e.g., 4096 or 8192), ensuring that the sector value remains divisible by 8 for 4K alignment.
  5. Run the modified script to install Ventoy: 
    sudo ./Ventoy2Disk.sh -i /dev/sdX

Method 2: Manual Pre-Partitioning (Non-Destructive Method)

If you must define strict partition geometry using external utilities like parted or gdisk:

  1. Align and format your disk manually using parted: 
    sudo parted -a optimal /dev/sdX mklabel msdos
sudo parted -a optimal /dev/sdX mkpart primary exfat 2048s 90%
sudo parted -a optimal /dev/sdX mkpart primary fat16 90% 100%
  2. Label the partitions according to Ventoy’s standard (VTOY for the data partition, VTOYBOOT for the boot partition).
  3. Use Ventoy's non-destructive installation routine or copy the Ventoy boot code directly to the boot partition using the core Ventoy payload tools.
