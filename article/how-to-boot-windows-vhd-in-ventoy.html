How to Boot Windows VHD in Ventoy

Booting a Windows Virtual Hard Disk (VHD or VHDX) directly from a Ventoy USB drive requires a dedicated extension called the ventoy_vhdboot.img plugin. By default, Ventoy supports ISO and standard image files natively, but Windows VHD/VHDX files require this helper image to bridge the virtual disk directly into the Windows boot loader. This guide explains which plugin is required, where to install it on your USB drive, and how to prepare your files for seamless booting.

The Required Plugin: ventoy_vhdboot.img

To boot Windows VHD and VHDX files, you must use the ventoy_vhdboot.img file. This plugin acts as a virtual disk driver and hook loader. When you select a Windows .vhd or .vhdx file from the Ventoy boot menu, Ventoy uses this image to load the disk into memory and pass control to the Windows boot manager (bootmgr) without requiring the image to be fully unpacked or pre-installed onto the physical host drive.

How to Install the Plugin

  1. Download the Plugin: Download the latest ventoy_vhdboot.img file directly from the official Ventoy GitHub releases or Ventoy website under the VHD boot section.
  2. Locate the Ventoy Partition: Insert your Ventoy USB drive into your computer and open the primary partition where you store your ISO files.
  3. Create the Ventoy Folder: In the root directory of the drive, create a folder named ventoy (in all lowercase) if it does not already exist.
  4. Place the Image: Copy the downloaded ventoy_vhdboot.img file directly into this ventoy folder. The final path must be /ventoy/ventoy_vhdboot.img.

Preparing and Booting Windows VHD Files

Once the plugin is in place, you can place your Windows .vhd or .vhdx files anywhere on the USB drive alongside your normal ISO files.

For the boot process to succeed, ensure the following conditions are met:

  • Internal Boot Files: The VHD must contain an installed, bootable Windows operating system (Windows 7, 8, 8.1, 10, 11, or Windows Server) with proper internal boot configurations.
  • File Extensions: Ensure the file extensions are strictly .vhd or .vhdx.
  • Fixed vs. Dynamic: While dynamic disks work, fixed-size VHDs generally provide better read/write performance when running directly from USB storage.
  • File Fragmentation: Ensure the VHD file is not heavily fragmented on the USB file system, as excessive fragmentation can cause read errors during initialization.

When you boot your system from the Ventoy USB drive, select the Windows VHD file from the list. Ventoy will automatically call the ventoy_vhdboot.img plugin and initialize the operating system.
