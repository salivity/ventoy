Can Ventoy Boot ISO Files with Spaces in Filenames?

Ventoy can technically detect and display ISO files with spaces in their filenames, but you should avoid them because they frequently cause boot failures. While Ventoy's own menu engine can parse these names, the operating system kernels and bootloaders inside the ISO often cannot handle path spaces during runtime. To ensure reliable booting, Ventoy officially recommends keeping filenames free of spaces and non-ASCII characters.

The Official Recommendation

According to the official Ventoy documentation, ISO, WIM, IMG, and VHD files—as well as the directories containing them—must not contain spaces or non-ASCII characters. The system is designed to read standard ASCII paths to maximize compatibility across hundreds of different operating systems.

What Happens When You Use Spaces

If you copy an ISO containing spaces (for example, Ubuntu 22.04 Live.iso) to your Ventoy USB drive:

  1. The Menu Works: Ventoy will scan the drive, locate the file, and list it in the boot selection menu without an issue.
  2. The Boot Loader Launches: When selected, Ventoy mounts the ISO virtually and passes the boot parameters to the image's internal bootloader (such as GRUB, Syslinux, or Windows Boot Manager).
  3. The Kernel Fails to Mount: The failure typically occurs during the second stage of booting. As the operating system kernel and its initial RAM disk (initramfs) load, they parse command-line arguments to find and mount the ISO file. Many Linux distributions and recovery utilities do not properly escape spaces in these scripts, leading to errors like "Unable to find a medium containing a live file system" or dropping to a basic shell prompt.

Best Practices for Naming ISO Files

To prevent boot crashes and ensure maximum compatibility across all operating systems:

  • Use Underscores or Hyphens: Replace every space with an underscore (_) or a hyphen (-). For example, rename Windows 11 23H2.iso to Windows_11_23H2.iso.
  • Stick to Standard ASCII: Avoid special characters, symbols (such as parentheses, brackets, or ampersands), and accented letters.
  • Keep Directory Paths Clean: If you organize your images into folders on the Ventoy partition, ensure that the folder names also follow the same rules (e.g., /Linux_ISOs/ instead of /Linux ISOs/).
