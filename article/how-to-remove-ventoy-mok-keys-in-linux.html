How to Remove Ventoy MOK Keys in Linux

When you boot Ventoy on a host machine with Secure Boot enabled, you are prompted to enroll Ventoy’s Machine Owner Key (MOK) to authenticate its bootloader. Once testing is complete, leaving this third-party certificate in your system's NVRAM poses an unnecessary security risk. This guide provides the exact steps to locate, target, and delete the Ventoy MOK certificate from your Linux system using the mokutil utility and MokManager.

Step 1: Identify the Ventoy Certificate

Before deleting anything, verify which keys are currently enrolled in your system’s MOK list. Open a terminal and run:

mokutil --list-enrolled

Scroll through the output to find the entry associated with Ventoy. The certificate details will typically display Ventoy or Ventoy OS under the Issuer or Subject lines.

Step 2: Export the Enrolled Keys

To safely delete only the Ventoy key without disrupting other enrolled keys (such as proprietary drivers), export all active keys to your current directory:

mokutil --export

This command extracts the enrolled certificates as DER-encoded files named MOK-0001.der, MOK-0002.der, and so forth.

Find which specific file belongs to Ventoy by inspecting each exported key with OpenSSL:

for cert in MOK-*.der; do
    echo "=== $cert ==="
    openssl x509 -in "$cert" -inform DER -noout -subject -issuer
done

Identify the filename (e.g., MOK-0002.der) corresponding to the Ventoy certificate.

Step 3: Issue the Deletion Request

Once you have identified the Ventoy certificate file, mark it for removal using mokutil:

sudo mokutil --delete MOK-XXXX.der

(Replace MOK-XXXX.der with the actual file name associated with Ventoy.)

The terminal will prompt you to enter and confirm a temporary password. Choose a simple password that you can remember during the next system reboot.

(Alternative: If you do not have other custom keys and want to purge all custom MOKs entirely, you can run sudo mokutil --reset instead.)

Step 4: Confirm Removal in MokManager

The key is not fully removed until authorized within the UEFI environment:

  1. Restart your computer: 
    sudo reboot
  2. During boot, before the OS loads, the blue MokManager screen ("Perform MOK management") will appear.
  3. Press any key to enter the configuration menu.
  4. Select Enroll MOK or Delete MOK (depending on whether you initiated a single deletion or a reset).
  5. Select View key to verify it is the Ventoy certificate, then choose Continue.
  6. When prompted, select Yes to confirm the deletion and enter the password you created in Step 3.
  7. Select Reboot to boot back into your operating system.

Step 5: Verify Deletion

After booting back into Linux, confirm that the Ventoy key has been successfully removed from NVRAM:

mokutil --list-enrolled | grep -i ventoy

If the command returns no output, the Ventoy MOK certificate has been permanently cleared. You can now safely delete the exported .der files from your working directory.
