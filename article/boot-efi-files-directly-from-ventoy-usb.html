Boot EFI Files Directly From Ventoy USB

Ventoy is widely recognized for booting standard ISO and image files, but it also natively supports launching standalone UEFI executable files (.efi) directly from the boot menu. This guide provides a straightforward walkthrough on how to prepare your drive, place your EFI binaries, configure necessary settings, and boot them directly on any UEFI-compatible machine without packaging them into an ISO container.

Prerequisites

  • A USB drive with Ventoy already installed.
  • A target computer booted in UEFI mode (Ventoy cannot execute .efi files in Legacy BIOS mode).
  • The EFI executable file you intend to run (e.g., shell.efi, grubx64.efi, or custom bootloaders).

Step 1: Place the EFI File on the Ventoy Partition

  1. Insert your Ventoy USB drive into your computer.
  2. Open the main file storage partition (the large partition named Ventoy where you typically drop ISO files).
  3. Copy your .efi file directly into this partition. You can place it in the root directory or organize it inside a subfolder.
  4. Ensure the file has the .efi extension in lowercase or uppercase (e.g., bootx64.efi).

Step 2: Configure UEFI and Secure Boot Settings

Because many third-party or open-source .efi files are not signed by Microsoft, Secure Boot may block them from executing:

  1. Restart your target computer and enter the BIOS/UEFI firmware settings (typically by pressing F2, F12, Del, or Esc during startup).
  2. Verify that the boot mode is set to UEFI.
  3. Temporarily disable Secure Boot if your .efi binary is unsigned or self-signed.
  4. Save the settings and exit the BIOS.

Step 3: Boot and Launch the File

  1. Boot your computer from the Ventoy USB drive using your system's one-time boot menu.
  2. Once the Ventoy main menu appears, your .efi file will be listed alongside any ISO images on the drive.
  3. Use the arrow keys to highlight the .efi file.
  4. Press Enter to launch the executable directly.

Additional Notes

  • List Mode: If you have numerous files on your drive, press F2 in the Ventoy menu to switch to Browser Mode, which lets you navigate folders specifically to find your .efi file.
  • Ventoy UEFI Utilities: If you need a UEFI interactive shell and do not have an executable on hand, Ventoy includes built-in EFI tools. Press F6 or check the bottom menu options to load an embedded UEFI Shell directly if supported by your Ventoy version.
