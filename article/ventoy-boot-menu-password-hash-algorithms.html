Ventoy Boot Menu Password Hash Algorithms

Ventoy allows users to protect boot menus and specific image files using password authentication defined in its configuration files. To prevent storing credentials in plain text, Ventoy supports several cryptographic hashing algorithms to verify user identity securely at boot time, ranging from iterative key-derivation functions like PBKDF2 with SHA-512 to direct cryptographic hash digests like SHA-256.

GRUB2 PBKDF2 with HMAC-SHA512

The primary and most secure mechanism supported by Ventoy relies on GRUB2's native key-derivation implementation: PBKDF2 using HMAC-SHA-512.

Because Ventoy's underlying bootloader environment is built on modified GRUB2 code, it natively understands hashes generated by the standard grub-mkpasswd-pbkdf2 utility. This format typically follows the identifier:

grub.pbkdf2.sha512.<iterations>.<salt>.<hash>

  • Underlying Primitive: SHA-512 (Secure Hash Algorithm 512-bit).
  • Function: Password-Based Key Derivation Function 2 (PBKDF2).
  • Security Attributes: Uses a pseudo-random salt and a configurable iteration count (typically thousands of rounds), providing strong resistance against dictionary attacks, precomputed rainbow tables, and hardware-accelerated brute-force attempts.

SHA-2 Family (SHA-256 and SHA-512)

Ventoy's integrated hash generator (VentoyHash.exe / VentoyHash.sh) and configuration parser directly support standard cryptographic hash digests from the SHA-2 family:

  • SHA-256: Produces a 256-bit (32-byte) message digest represented as a 64-character hexadecimal string.
  • SHA-512: Produces a 512-bit (64-byte) message digest represented as a 128-character hexadecimal string.

When configured via hexadecimal strings in ventoy.json, Ventoy compares the hash of the entered password against the stored digest. While computationally secure against preimage and collision attacks, standard unsalted SHA-2 digests are more susceptible to high-speed offline dictionary attacks compared to PBKDF2 if weak passwords are used.

Legacy and Compatibility Algorithms

The Ventoy hash utility also includes generation options for legacy message digest algorithms:

  • SHA-1: Produces a 160-bit digest.
  • MD5: Produces a 128-bit digest.

These options exist primarily for compatibility and quick integrity checks rather than robust access control. Because both MD5 and SHA-1 have known cryptographic collision vulnerabilities, their use for boot menu protection is discouraged.

Implementation in Configuration

Password protection in Ventoy is configured within the ventoy.json file under the control or menu_alias sections. Administrators can supply the password value as:

  1. A raw grub.pbkdf2.sha512 string generated via GRUB utilities.
  2. A hex digest corresponding to SHA-256 or SHA-512 generated via VentoyHash.
  3. Plain text (evaluated directly without a hashing function).

For environments requiring high security, PBKDF2 with HMAC-SHA-512 is the recommended cryptographic standard for all Ventoy deployments.
