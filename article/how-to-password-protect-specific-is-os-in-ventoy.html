How to Password Protect Specific ISOs in Ventoy

Ventoy allows users to configure granular security controls using a JSON configuration file, enabling you to password-protect sensitive administrative ISOs while leaving general-purpose tools publicly accessible. By defining image-specific rules rather than a global lock, you can secure proprietary recovery disks, domain imaging tools, or administrative installers on a shared multiboot drive without inconveniencing users accessing standard operating system installers.

Step 1: Create the Configuration Folder

Ventoy reads custom configurations from a dedicated directory located on the root of your primary USB partition (where your ISO files reside):

  1. Plug in your Ventoy USB drive.
  2. Open the main file storage partition (labeled Ventoy).
  3. Check for a folder named ventoy (all lowercase). If it does not exist, create it in the root directory.

Step 2: Generate a Secure Password Hash

While Ventoy supports plaintext passwords, using SHA-256 hashes is significantly more secure.

  • On Linux/macOS: Run the following command in your terminal, replacing YourPassword with your chosen password: 
    echo -n "YourPassword" | sha256sum
  • On Windows: Ventoy includes a tool named VentoyHash.exe inside the downloaded installation archive. Run this tool, enter your desired password, and copy the generated SHA-256 string. Alternatively, run PowerShell: 
    [BitConverter]::ToString((New-Object Security.Cryptography.SHA256Managed).ComputeHash([Text.Encoding]::UTF8.GetBytes("YourPassword"))).Replace("-","").ToLower()

Step 3: Configure the ventoy.json File

Inside the ventoy folder, create a new text file and name it ventoy.json. If it already exists, open it in a code or text editor.

Add the password plugin configuration to specify which ISOs require authentication.

{
    "password": {
        "image": [
            {
                "image": "/admin/winpe_admin.iso",
                "hash": "ef92b778bafe771e89245b89ecbc08a44a4e166c06659911881f383d4473e94f"
            },
            {
                "image": "/isos/sensitive-tool.iso",
                "pwd": "PlaintextPasswordExample"
            }
        ]
    }
}

Key Rules for Configuration:

  • image path: The path must match the exact location of the file relative to the root of the USB drive. Use forward slashes (/) even on Windows.
  • hash: Used to supply a SHA-256 hash.
  • pwd: Used if you prefer a plaintext password instead of a hash.
  • Any ISO file stored on the drive that is not explicitly listed in the image array will remain completely unlocked and bootable without prompting for credentials.

Step 4: Validate and Test

  1. Ensure the JSON syntax is valid (ensure all braces, commas, and quotes are correctly closed).
  2. Safely eject the USB drive.
  3. Boot a machine using the USB drive.
  4. Verify that public ISOs boot immediately upon selection, while the configured administrative ISOs display a password prompt before loading into memory.
