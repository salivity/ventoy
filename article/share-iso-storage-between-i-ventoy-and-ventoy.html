Share ISO Storage Between iVentoy and Ventoy

Yes, iVentoy can share the exact same ISO storage repository as a standard Ventoy drive. Because both systems read unmodified ISO images directly from standard filesystems, you can configure iVentoy to point directly to the partition or directory where your Ventoy files reside. This article explains how this shared setup works, how to configure it, and key considerations regarding file systems and system performance.

How Repository Sharing Works

Standard Ventoy formats a flash drive into two partitions: a hidden EFI system partition for the bootloader and a primary partition formatted as exFAT, NTFS, or ext4 to hold your raw ISO files.

iVentoy does not require a proprietary directory structure or special container format. It functions as a PXE network boot server that simply scans a designated folder on the host computer for bootable image files. As a result, iVentoy can read the primary data partition of a Ventoy drive directly without altering the files.

Configuration Methods

There are two primary ways to share an ISO repository between the two platforms:

1. Pointing iVentoy to a Physical Ventoy USB Drive

If you already maintain a Ventoy USB flash drive or portable SSD:

  1. Connect the Ventoy drive to the computer running the iVentoy software.
  2. Identify the drive letter (Windows) or mount point (Linux) assigned to the Ventoy primary data partition.
  3. In the iVentoy web management console, set the image directory path to the root or subfolder of that mounted partition.
  4. Refresh the image list in the iVentoy console to load the detected ISOs.

2. Using a Shared Local or Network Folder

If you build a local ISO library on a PC or Network-Attached Storage (NAS):

  1. Store all your operating system ISO files in a single local directory.
  2. Configure iVentoy's image location to point to this directory for PXE booting.
  3. When updating your physical Ventoy drive, use file synchronization tools (such as rsync, FreeFileSync, or Robocopy) to mirror the exact same folder directly to the Ventoy drive's data partition.

Key Considerations

  • Filesystem Compatibility: If running iVentoy on a Linux host, ensure the host system has the necessary drivers installed (such as exfat-fuse or built-in kernel exFAT support) if your Ventoy drive uses the default exFAT format.
  • Drive Letter and Mount Stability: If using a removable Ventoy drive as the iVentoy source, assign a persistent drive letter in Windows Disk Management or create an entry in /etc/fstab on Linux to prevent broken directory paths upon reconnection.
  • USB Read Speeds: Running a multi-client network boot environment via iVentoy off a slow USB flash drive can cause severe throughput bottlenecks. If multiple machines will boot over the network simultaneously, use a high-speed USB 3.2 SSD or host the repository on internal NVMe/SATA storage.
  • Partition Selection: Always point iVentoy to the larger data partition (Partition 1) of the Ventoy drive, never the small VTOYEFI system partition (Partition 2).
