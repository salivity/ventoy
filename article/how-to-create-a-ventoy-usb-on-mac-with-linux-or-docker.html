How to Create a Ventoy USB on Mac with Linux or Docker

Ventoy does not natively support macOS, making it challenging for Mac users to create multi-boot USB drives directly from their operating system. However, by using a Linux virtual machine with direct USB passthrough or running a specialized Docker container environment, you can bypass macOS limitations and install Ventoy seamlessly. This guide outlines the exact, step-by-step methods to prepare, configure, and install Ventoy onto a USB flash drive on both Intel and Apple Silicon Macs.

Method 1: Using a Linux Virtual Machine

A Linux virtual machine provides the most reliable way to grant Ventoy the direct hardware-level access it requires to partition and format your drive.

1. Prepare Your Hypervisor and Linux ISO

  • Apple Silicon (M1/M2/M3): Download and install UTM. Download an ARM64 Linux ISO, such as Ubuntu Server or Debian.
  • Intel Macs: Download and install VirtualBox or VMware Fusion. Download a standard x86_64 Linux ISO.

2. Configure USB Passthrough

  1. Insert your USB drive into your Mac.
  2. Launch your hypervisor and boot up the Linux virtual machine.
  3. Redirect the physical USB drive from macOS to the Linux VM:
    • In UTM, click the USB icon in the top toolbar and select your USB flash drive.
    • In VirtualBox, open the VM settings, navigate to Ports > USB, add a USB device filter for your drive, or capture it from the Devices > USB menu in the live window.

3. Run the Ventoy Installation Script

  1. Open a terminal inside your Linux VM.
  2. Identify your drive name using the block devices command: 
    lsblk
    Locate your flash drive (commonly /dev/sdb or /dev/sdc). Ensure you do not select the virtual machine's primary disk (/dev/sda).
  3. Download the latest Ventoy Linux release: 
    wget https://github.com/ventoy/Ventoy/releases/download/v1.0.99/ventoy-1.0.99-linux.tar.gz
    (Replace the version number with the current release if newer).
  4. Extract the archive and navigate to the directory: 
    tar -xzvf ventoy-*-linux.tar.gz
cd ventoy-*
  5. Install Ventoy to your target drive (replace /dev/sdX with your verified drive letter): 
    sudo ./Ventoy2Disk.sh -i /dev/sdX
  6. Confirm the prompts twice to format the drive and complete the installation.

Method 2: Using Docker Containers

Because Docker Desktop for Mac runs inside a virtualized lightweight Alpine Linux environment, standard containers cannot automatically see raw USB block devices plugged into the host Mac without bridge utilities or a Linux VM hosting Docker.

1. Forward the USB Device via USBIP (or Docker in a VM)

Docker Desktop on macOS cannot access /dev/disk* block devices directly due to the hypervisor boundary. To use Docker effectively:

  1. Use an lightweight Linux virtual environment (such as a minimal Alpine VM in UTM) that has Docker installed.
  2. Pass the USB device into that VM.

2. Run the Ventoy Container

Once your Docker host has direct access to the block device:

  1. Verify the drive is recognized: 
    lsblk
  2. Run a community-maintained Ventoy image in privileged mode to write directly to the storage medium: 
    docker run --rm -it --privileged \
  -v /dev:/dev \
  ventoy/ventoy:latest /Ventoy2Disk.sh -i /dev/sdX
  3. Type y and press Enter when prompted to verify that you want to format the target disk.

Finalizing and Using the Drive on macOS

  1. Disconnect or unmount the USB drive from your Linux VM or Docker environment.
  2. Unplug and replug the drive into your Mac.
  3. macOS will now recognize the partition named Ventoy.
  4. Drag and drop any bootable .iso, .img, or .vhd files directly into the Ventoy partition using Finder.
