Supported Hashing Algorithms in Ventoy Checksum

This article provides a direct overview of the cryptographic hashing algorithms supported by Ventoy's checksum verification feature. You will learn which specific hash algorithms can be used to verify the integrity of bootable image files, how Ventoy performs verification, and how to configure automatic checksum matching using Ventoy's configuration files.

Supported Hashing Algorithms

Ventoy's image verification feature supports four major cryptographic hash functions:

  • MD5: A widely used, 128-bit legacy hashing algorithm. While no longer recommended for cryptographic security due to collision vulnerabilities, it remains supported in Ventoy for verifying file integrity against accidental corruption.
  • SHA-1: A 160-bit hash function commonly provided by legacy distribution mirrors. Like MD5, it is suitable for detecting download errors, though phased out for strict security applications.
  • SHA-256: Part of the SHA-2 family, producing a 256-bit digest. It is currently the industry standard for verifying Linux distributions, Windows installation media, and system rescue tools.
  • SHA-512: A high-security 512-bit algorithm from the SHA-2 family, offering the highest level of integrity verification available in Ventoy.

Methods for Using Checksums in Ventoy

Ventoy provides two methods to verify image files: on-demand calculation via the boot menu and automated matching via configuration files.

1. On-Demand Menu Verification

At the boot screen, you can navigate to any bootable file (such as an .iso, .wim, .img, or .vhd) and enter the Checksum Menu (typically by pressing c or selecting the secondary options menu, depending on the theme). Ventoy will read the storage blocks of the selected file and compute the hash values on the fly, allowing you to manually compare the output against the publisher's published digest.

2. Automated Matching with ventoy.json

You can define expected hashes in the ventoy.json configuration file located in the ventoy folder of your USB drive. When configured, Ventoy automatically calculates the file's hash and compares it against your predefined value, alerting you if there is a mismatch.

Below is an example of how each supported algorithm is defined within the checksum plugin:

{
    "checksum": [
        {
            "image": "/ISO/ubuntu-22.04-desktop-amd64.iso",
            "sha256": "10c7a1023d6a0663673982e56994781ec7d1889950fa71a9386bc770e060ea26"
        },
        {
            "image": "/ISO/debian-11.0.0-amd64-netinst.iso",
            "sha512": "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855..."
        },
        {
            "image": "/ISO/legacy-rescue-disk.iso",
            "sha1": "2aae6c35c94fcfb415dbe95f408b9ce91ee846ed"
        },
        {
            "image": "/ISO/old-tool.iso",
            "md5": "098f6bcd4621d373cade4e832627b4f6"
        }
    ]
}

Ventoy evaluates hashes in a case-insensitive manner, meaning uppercase and lowercase hexadecimal strings are treated identically.
