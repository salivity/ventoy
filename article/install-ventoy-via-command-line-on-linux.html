Install Ventoy via Command Line on Linux

This guide provides a straightforward walkthrough on installing Ventoy onto a USB drive using the Linux command-line interface. You will learn how to download the official archive, extract the files, identify the correct storage device, and execute the installation script to create a bootable drive capable of holding multiple ISO files without reformatting.

Step 1: Download and Extract the Ventoy Package

Open your terminal and download the latest release of Ventoy for Linux. You can retrieve it using wget or curl, replacing the version number with the latest release:

wget https://github.com/ventoy/Ventoy/releases/download/v1.0.99/ventoy-1.0.99-linux.tar.gz

Once the download is complete, extract the tarball:

tar -xf ventoy-*-linux.tar.gz

Navigate into the extracted directory:

cd ventoy-*/

Step 2: Identify Your USB Drive

Insert your USB flash drive into your computer. Before proceeding, you must identify its exact device node. Run the lsblk command:

lsblk

Locate your USB drive based on its size and model (e.g., /dev/sdb or /dev/sdc).

Warning: Be certain of the device name. Installing Ventoy will completely erase the selected disk. Do not target partition names (like /dev/sdb1), target the entire device (like /dev/sdb).

Step 3: Run the Installation Script

Ventoy provides a shell script named Ventoy2Disk.sh to manage installation directly from the terminal.

To install Ventoy onto the target drive using standard MBR partition style, run:

sudo ./Ventoy2Disk.sh -i /dev/sdX

(Replace /dev/sdX with your actual USB device node, such as /dev/sdb)

If you prefer to use the GPT partition scheme (recommended for modern UEFI systems), include the -g flag:

sudo ./Ventoy2Disk.sh -i -g /dev/sdX

Script Options and Prompts

  • -i: Installs Ventoy onto the disk (erases all data).
  • -I: Forces the installation without additional confirmation prompts.
  • -u: Updates an existing Ventoy installation without formatting or deleting stored ISOs.
  • -g: Sets the partition scheme to GPT instead of MBR.

The script will prompt you twice to confirm that you want to format the drive. Type y and press Enter at both prompts. The script will format the disk into two partitions: a large exFAT partition for ISO storage and a hidden VTOYEFI boot partition.

Step 4: Add ISO Files

Once the script outputs that the installation completed successfully, unplug and re-insert the USB drive. Your operating system will automatically mount the main exFAT partition labeled Ventoy.

Simply copy or move any bootable .iso, .img, or .vhd files directly onto this partition. When you boot your computer from this USB drive, Ventoy will present a menu allowing you to select and boot any image stored on it.
