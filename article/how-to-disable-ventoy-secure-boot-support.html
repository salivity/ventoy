How to Disable Ventoy Secure Boot Support

Ventoy includes native support for UEFI Secure Boot, but this feature can be disabled through Ventoy's setup options. While it cannot be toggled using the runtime ventoy.json configuration file due to UEFI security constraints, it can easily be disabled using the Ventoy installer utility without formatting or losing existing data on your USB drive.

Why Secure Boot Cannot Be Disabled in ventoy.json

The ventoy.json file is a runtime configuration file loaded by the Ventoy bootloader after the initial boot stage. Because Secure Boot validation occurs at the UEFI firmware level before any configuration files are read, the UEFI environment must verify Ventoy’s signed EFI binaries (BOOTX64.EFI) first. Consequently, there is no option in ventoy.json to enable or disable Secure Boot support. The setting must be configured at the binary and partition level using the Ventoy installer.

Disabling Secure Boot Using Ventoy2Disk on Windows

To disable Secure Boot support using the graphical interface:

  1. Insert your Ventoy USB drive into your computer.
  2. Launch the Ventoy2Disk.exe application.
  3. Click on the Option menu in the top toolbar.
  4. Locate Secure Boot Support and click it to uncheck the option.
  5. Click the Update button (do not click "Install", as "Install" will reformat the drive).

The update process takes only a few seconds and replaces the bootloader files with unsigned/standard versions while keeping all of your ISO files intact.

Disabling Secure Boot on Linux

If you manage your Ventoy drive via the Linux command-line interface:

  1. Identify your USB drive's device path (e.g., /dev/sdb).
  2. Run the update command without the -s (secure boot) flag: 
    sudo sh Ventoy2Disk.sh -u /dev/sdX
    (Replace /dev/sdX with your target drive).

By default, omitting the -s flag during an update or installation disables Secure Boot support on the disk.

When Should You Disable Secure Boot?

Disabling Secure Boot support in Ventoy is recommended if:

  • Your machine displays errors such as Verification failed: (0x1A) Security Violation or issues related to the Linpus/MOK (Machine Owner Key) manager.
  • You already have Secure Boot disabled in your computer's motherboard BIOS/UEFI settings, making Ventoy's internal Secure Boot shim unnecessary.
  • You are experiencing boot freezes or incompatibilities with specific custom Linux distributions or older hardware.
