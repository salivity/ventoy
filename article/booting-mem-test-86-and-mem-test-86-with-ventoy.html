Booting MemTest86 and MemTest86+ with Ventoy

Ventoy fully supports launching memory diagnostic utilities, including PassMark MemTest86 and open-source MemTest86+, directly from your multiboot USB drive. This guide explains how Ventoy handles these diagnostic tools, the file formats required, important BIOS and UEFI compatibility details, and the straightforward process of adding them to your existing Ventoy configuration.

Compatibility and Supported Formats

Ventoy operates by loading disk images directly from the USB drive's filesystem into memory without requiring you to extract or reformat the drive for each tool. Both MemTest86 and MemTest86+ work reliably with Ventoy when provided in compatible formats:

  • ISO Files: Most standard bootable ISO images of MemTest86+ can be placed directly on the Ventoy partition and booted via standard ISO emulation.
  • IMG and ZIP Files: Official releases of PassMark MemTest86 often distribute as a USB image (.img) inside a zip archive. Ventoy natively supports uncompressed .img files. Extracting the raw .img file and placing it on your Ventoy drive allows it to boot seamlessly.

UEFI vs. Legacy BIOS Considerations

When using diagnostic tools with Ventoy, the mode in which you boot your computer determines which diagnostic utilities can run:

  • PassMark MemTest86 (Version 5 and later): Requires native UEFI mode. If you boot Ventoy in Legacy BIOS mode, modern releases of MemTest86 will not launch. Ensure your target machine is set to boot the Ventoy USB via UEFI.
  • MemTest86+: Historically designed for Legacy BIOS, recent versions (version 6.0 and later) support both 32-bit and 64-bit UEFI as well as Legacy BIOS. This makes MemTest86+ versatile across older and newer hardware architectures through Ventoy.

How to Add and Run the Utilities

Setting up these memory testing tools on Ventoy requires only a few steps:

  1. Obtain the Image: Download the bootable image file for either MemTest86 (extract the .img file from the downloaded archive) or MemTest86+ (download the bootable .iso or .img package).
  2. Copy to Ventoy: Connect your prepared Ventoy USB drive to your computer and copy the downloaded image file into the main storage partition. You can place it in the root directory or organize it inside a subfolder, such as /Diagnostics/.
  3. Boot the System: Insert the USB drive into the system you want to test and boot from the USB device using your system's boot menu key (such as F12, F11, or Esc).
  4. Select and Execute: In the Ventoy graphical menu, navigate to the diagnostic image using your arrow keys and press Enter. Ventoy will map the image and start the memory test environment immediately.

Additional Diagnostic Utilities

Beyond MemTest86 and MemTest86+, Ventoy handles a wide variety of complete diagnostic and rescue suites. Live environments such as Hiren's BootCD PE, Ultimate Boot CD, and system rescue distributions can be placed alongside your standalone memory test images on the same drive, functioning as a comprehensive hardware troubleshooting toolkit.
