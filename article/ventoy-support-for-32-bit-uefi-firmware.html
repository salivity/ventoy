Ventoy Support for 32-Bit UEFI Firmware

Ventoy natively accommodates computers equipped with 32-bit UEFI firmware by providing dedicated boot binaries, enabling users to launch compatible operating systems on niche hardware like older Intel Atom tablets and netbooks. While Ventoy itself initializes seamlessly on these systems, successful deployment depends on how the software handles the underlying architecture and whether the target operating system ISO supports 32-bit UEFI handoffs.

Dedicated IA32 Bootloader Support

When Ventoy formats a USB drive, it creates a hidden EFI System Partition (VTOYEFI) containing bootloaders for multiple platform architectures, including x86_64, ARM64, and IA32 (32-bit UEFI).

On a 32-bit UEFI machine, the motherboard's firmware scans the storage drive specifically for the \EFI\BOOT\BOOTIA32.EFI file. Ventoy includes this binary out of the box. The system firmware executes this 32-bit EFI loader, which immediately initializes a 32-bit GRUB2 environment. As a result, the Ventoy selection menu renders natively on the screen without requiring configuration changes or legacy BIOS emulation.

The Payload Handoff and Mixed-Mode Limitations

Once Ventoy boots and displays the list of ISO files, the interaction becomes dependent on the payload's architecture:

  • Native 32-bit UEFI Payloads: If you select an ISO that natively includes a 32-bit EFI bootloader (such as 32-bit Windows installation media or specific 32-bit Linux distributions), Ventoy chains directly to the payload. The operating system boots normally because the bitness of the firmware, Ventoy, and the OS loader align.
  • 64-bit Payloads on 32-bit Firmware: Many Intel Bay Trail and Cherry Trail devices feature a 64-bit processor paired with a 32-bit UEFI implementation. Standard 64-bit OS images generally supply only a 64-bit EFI loader (BOOTX64.EFI). Because the motherboard firmware cannot execute 64-bit EFI binaries, Ventoy cannot boot a standard 64-bit image on these machines unless the ISO itself has been modified or multi-streamed to include a functional bootia32.efi loader.

Workarounds within Ventoy

To boot modern 64-bit Linux distributions on 32-bit UEFI machines using Ventoy, users must rely on ISO images that explicitly provide mixed-mode EFI support (such as Fedora, Debian multi-arch, or modern Ubuntu derivatives that bundle 32-bit GRUB packages). Alternatively, users can inject custom GRUB configurations or replacement EFI boot files into their ISO workflows to allow the 32-bit Ventoy core to transition control to a 64-bit kernel.
