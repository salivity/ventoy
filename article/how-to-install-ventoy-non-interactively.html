How to Install Ventoy Non-Interactively

Ventoy can be installed in a non-interactive, automated environment, though it does not provide a native --silent flag or dedicated environment variables for headless deployment. Instead, automation is achieved on Linux by executing the official installation script alongside standard parameter flags and piping standard confirmation inputs to bypass interactive prompts. This guide explains how to leverage existing flags and command chaining to automate Ventoy installations safely in CI/CD pipelines, container configurations, or provisioning scripts.

Core Installation Flags

The standard Linux installer is executed via the Ventoy2Disk.sh shell script. While the script normally halts execution to request user confirmation, it accepts several core operational flags:

  • -i: Installs Ventoy to the target drive (prompts twice for confirmation).
  • -I: Force installs Ventoy to the target drive, overwriting any existing Ventoy installation (still prompts for user confirmation).
  • -u: Updates an existing Ventoy installation without formatting the data partition.
  • -g: Applies GPT partition style instead of the default MBR.
  • -s: Enables Secure Boot support during installation.

Automating the Installation on Linux

The confirmation steps in Ventoy2Disk.sh rely on standard read commands that expect a y input to verify data destruction. To bypass these interactive pauses, pipe standard affirmative responses into the script.

Basic Automated Installation

To execute an unattended installation on a target drive (such as /dev/sdb), use the yes command or printf:

echo -e "y\ny\n" | sudo ./Ventoy2Disk.sh -i /dev/sdb

Alternatively, use the force installation flag:

yes y | sudo ./Ventoy2Disk.sh -I /dev/sdb

Automated Installation with Custom Flags

To configure Ventoy with GPT partition layout and Secure Boot support non-interactively, chain the flags together:

printf "y\ny\n" | sudo ./Ventoy2Disk.sh -I -g -s /dev/sdb

Automated Updates

Updating an existing Ventoy installation requires only a single confirmation. Automate updates non-interactively using:

echo "y" | sudo ./Ventoy2Disk.sh -u /dev/sdb

Automating on Windows

The Windows distribution provides Ventoy2Disk.exe, which primarily functions as a graphical interface. To automate the installation on Windows without user intervention, use the command-line interface executable included in modern Ventoy packages:

Ventoy2Disk.exe VTOYCLI /I /Drive:E:

Replace E: with the appropriate drive letter. If using standard deployment scripts, ensure the target volume letter is strictly resolved prior to execution.

Safety Precautions for Unattended Setups

Because non-interactive installations bypass manual safety checks, hardcoded drive paths can lead to unintended data loss if drive assignments change (e.g., /dev/sdb shifting to /dev/sdc). Always resolve target drives dynamically using disk labels, serial numbers, or persistent identifiers found under /dev/disk/by-id/ before piping confirmations to the installer.
