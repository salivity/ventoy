Ventoy Salted Password Hashes in ventoy.json

This article explains how to secure a Ventoy bootable drive by using salted password hashes in the ventoy.json configuration file rather than exposing passwords in plain text. It covers the compatibility of Ventoy with modern hashing standards, demonstrates how to generate standard salted SHA-256 and SHA-512 hashes, and provides the exact syntax required to implement them for global or image-specific boot protection.

Does Ventoy Support Salted Password Hashes?

Yes, Ventoy natively supports salted password hashes. You do not need to store your administrative or boot passwords in plain text within the ventoy.json file.

Ventoy evaluates password strings using standard Unix crypt() formats compatible with GRUB 2. If a password string begins with a recognized hash identifier (such as $5$ for SHA-256 or $6$ for SHA-512), Ventoy will treat the value as a salted hash and verify input against it at boot time.

Supported Hashing Formats

Ventoy supports the following hash formats:

  • SHA-512 (Recommended): Prefixed with $6$. This provides the strongest standard security for passwords in Ventoy.
  • SHA-256: Prefixed with $5$. A secure, widely supported alternative.
  • MD5: Prefixed with $1$. Supported for backward compatibility, but not recommended due to cryptographic weaknesses.

How to Generate a Salted Password Hash

You can generate a salted hash on most Linux distributions using standard terminal utilities.

Method 1: Using mkpasswd

The mkpasswd utility (often included in the whois package) is the simplest method:

mkpasswd -m sha-512

When prompted, type your password. The output will look similar to:

$6$qZ7d...$examplehashstring...

Method 2: Using openssl

Most systems have openssl installed by default:

openssl passwd -6

This command prompts for the password, verifies it, and outputs a salted SHA-512 string starting with $6$.

Configuring ventoy.json

To apply the salted hash, open or create ventoy/ventoy.json on the root of your Ventoy USB drive's primary data partition.

Global Password Protection

To require a password before the main Ventoy boot menu appears:

{
    "control": [
        {
            "password": "$6$salt$YourGeneratedHashStringGoesHere"
        }
    ]
}

Image-Specific Password Protection

To protect individual ISO or WIM files while leaving the main menu accessible:

{
    "control": [
        {
            "image": "/ubuntu-22.04-desktop-amd64.iso",
            "password": "$6$salt$YourGeneratedHashStringGoesHere"
        }
    ]
}

Security Considerations

Using a salted hash prevents shoulder-surfing and protects your password if someone browses the files on the USB drive. However, keep the following in mind:

  1. Local Access Risks: If a third party has unrestricted physical access to the USB drive, they can edit or delete the ventoy.json file to bypass the password prompt entirely.
  2. BIOS/UEFI Protection: Password protection in Ventoy should be paired with secure firmware passwords and restricted boot device settings on the host machine for end-to-end access control.
