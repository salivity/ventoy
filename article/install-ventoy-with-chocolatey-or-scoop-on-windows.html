Install Ventoy with Chocolatey or Scoop on Windows

Ventoy can be installed and managed on Windows using third-party package managers such as Chocolatey and Scoop, as well as the native Windows Package Manager (winget). Using these tools automates downloading, extracting, and updating the Ventoy management utility on your local system. However, the package manager only handles the host application (Ventoy2Disk.exe), meaning you must still run the utility to write or upgrade the Ventoy bootloader files on your actual USB flash drive.

Installing Ventoy with Chocolatey

Ventoy is actively maintained in the Chocolatey community repository.

To install Ventoy via Chocolatey:

  1. Open PowerShell or Command Prompt as an Administrator.
  2. Run the installation command: 
    choco install ventoy
  3. To update Ventoy to the latest version in the future, run: 
    choco upgrade ventoy

Chocolatey downloads the Ventoy archive, unpacks the utility files, and creates necessary system shims or shortcuts to launch the tool directly.

Installing Ventoy with Scoop

Ventoy is available through Scoop's extras bucket, which contains standard Windows desktop GUI and CLI software.

To install Ventoy via Scoop:

  1. Open PowerShell (Administrator rights are not required for standard Scoop setups).
  2. Ensure the extras bucket is enabled: 
    scoop bucket add extras
  3. Install Ventoy: 
    scoop install ventoy
  4. To update the package later, run: 
    scoop update ventoy

Scoop isolates the binaries in your user directory and adds them to your environment path, allowing you to launch Ventoy2Disk directly from the command line.

Alternative: Windows Package Manager (winget)

If you prefer not to use third-party package managers, Microsoft's native winget tool also hosts Ventoy.

To install:

winget install Ventoy.Ventoy

To update:

winget upgrade Ventoy.Ventoy

Managing the USB Drive

Package managers automate maintenance for the host tool, but they do not automatically flash connected hardware.

After updating Ventoy via Chocolatey, Scoop, or winget:

  1. Launch Ventoy2Disk.exe.
  2. Select your USB drive from the device dropdown list.
  3. Click Update (not Install) to refresh the Ventoy bootloader code on the USB drive without formatting or deleting your existing ISO files.
