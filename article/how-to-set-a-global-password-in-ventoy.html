How to Set a Global Password in Ventoy

Setting a global boot password on your Ventoy USB drive prevents unauthorized users from booting into your ISO files and utilities. This guide walks you through configuring a universal boot password using the native ventoy.json configuration file as well as the official VentoyPlugson graphical interface, ensuring authentication is required before the main boot menu loads.

Method 1: Using the ventoy.json Configuration File

Ventoy reads plugin parameters directly from a JSON file located on the storage partition of your USB drive.

  1. Access the USB Drive: Plug your Ventoy USB drive into your computer and open its main partition (the one where you store ISO files).
  2. Create the Ventoy Folder: In the root directory of the partition, check for a folder named ventoy (all lowercase). If it does not exist, create it.
  3. Create or Open ventoy.json: Inside the ventoy folder, create a new text file named ventoy.json.
  4. Define the Password: Open ventoy.json in a text editor and add the following structure:
{
    "control": [
        {
            "password": "YourPasswordHere"
        }
    ]
}

Replace YourPasswordHere with your desired password.

Enhancing Security with Password Hashes (Optional)

To avoid storing the password in plain text, you can use a PBKDF2 hash generated by grub-mkpasswd-pbkdf2:

{
    "control": [
        {
            "password_hash": "grub.pbkdf2.sha512.10000.YOUR_GENERATED_HASH..."
        }
    ]
}
  1. Save the File: Save and close ventoy.json.

Method 2: Using the VentoyPlugson Graphical Tool

If you prefer a graphical setup, you can configure the global password using Ventoy’s built-in web configurator, VentoyPlugson.

  1. Launch VentoyPlugson:
    • Windows: Open the extracted Ventoy installation directory and run VentoyPlugson.exe. Select your USB drive and click Start.
    • Linux: Open a terminal in the Ventoy directory and run sudo bash VentoyPlugson.sh /dev/sdX (replacing sdX with your USB drive identifier).
  2. Open the Web Interface: Your default browser should open to http://127.0.0.1:24681. If it does not open automatically, paste the link manually.
  3. Navigate to Global Control: Click on the Control Plugin tab on the left-side menu.
  4. Set the Password: Locate the password field, type your desired access key, and save your changes. VentoyPlugson will generate or update the ventoy.json file automatically.
  5. Stop the Service: Close the web browser and terminate the VentoyPlugson program.

Testing the Configuration

Reboot your computer and boot from the Ventoy USB drive (or launch it in a virtual machine). Ventoy will prompt you for the password immediately upon loading. Entering the correct credentials will unlock the main interface and allow you to select and boot your ISO images.
