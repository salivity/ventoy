How to Load Custom Storage Drivers in Ventoy

Ventoy allows you to load custom mass storage controller drivers dynamically during boot without modifying your base ISO files. By leveraging Ventoy's native Injection Plugin, you can automatically inject storage drivers—such as Intel VMD, RAID, or VirtIO controllers—directly into the operating system's installer environment at runtime, ensuring drives are recognized during setup.

How Dynamic Driver Injection Works

When booting an installer (such as Windows Setup or a Linux distribution), the installer's RAM-based environment (WinPE or initramfs) may lack the proprietary or modern controller drivers needed to detect your target storage drives.

Ventoy solves this using its Injection Plugin. This feature instructs Ventoy to overlay a user-defined archive (such as a .zip or .cpio file) into the boot filesystem in memory before handing execution over to the target OS kernel. Because this occurs entirely in memory, your original ISO image remains untouched.

Loading Drivers for Windows Installers

For Windows installations, Windows Setup automatically scans for drivers placed in specific locations, primarily the $WinPEDriver$ folder.

  1. Prepare the Driver Files: Download the extracted driver files (.inf, .sys, .cat) for your mass storage controller. Do not use an .exe installer; raw driver files are required.

  2. Create the Driver Archive: Create a folder structure named $WinPEDriver$\Storage and place your driver files inside it. Compress the $WinPEDriver$ folder into a standard .zip file (for example, drivers.zip).

  3. Configure ventoy.json: Navigate to the ventoy directory on your USB drive (create it if it does not exist) and create or edit ventoy.json. Add the injection configuration mapping your ISO to the driver zip archive:

{
    "injection": [
        {
            "image": "/ISO/Windows_11.iso",
            "archive": "/ventoy/drivers.zip"
        }
    ]
}

When you boot Windows_11.iso, Ventoy extracts the archive into the root of the virtual installation environment. Windows Setup automatically detects the drivers inside $WinPEDriver$ and initializes the storage controller.

Loading Drivers for Linux Distributions

Linux installers typically support dynamic driver loading via Driver Update Disks (DUD) or supplementary initrd overlays:

  1. Obtain the driver update image or package (typically a .iso, .img, or .cpio provided by the hardware manufacturer).
  2. Configure the injection plugin in ventoy.json to point your Linux ISO to the driver package.
  3. For distributions using native driver injection parameters (such as Red Hat or SUSE inst.dd), supply the appropriate boot parameter, or allow Ventoy to inject the kernel modules directly into the root filesystem if using an initramfs overlay.

Using Ventoy's injection framework keeps your setup clean, modular, and eliminates the need to maintain multiple customized installation media for different hardware configurations.
