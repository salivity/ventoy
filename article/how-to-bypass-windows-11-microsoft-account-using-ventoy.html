How to Bypass Windows 11 Microsoft Account Using Ventoy

Installing Windows 11 typically forces users to connect to the internet and sign in with a Microsoft account during the Out-of-Box Experience (OOBE). Ventoy, a popular open-source tool for creating bootable USB drives, provides a native mechanism to bypass this mandatory requirement without altering the official Windows 11 ISO. By leveraging Ventoy's global control plugin, users can automatically inject a registry tweak that restores the option to set up a standard offline local account.

How the Bypass Works

Starting with version 1.0.86, Ventoy introduced the VTOY_WIN11_BYPASS_NRO configuration option. During the Windows 11 boot and setup phase, Ventoy intercepts the installation environment and automatically applies the BypassNRO registry modification (reg add HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\OOBE /v BypassNRO /t REG_DWORD /d 1 /f). This tweak removes the strict internet requirement screen and brings back the "I don't have internet" option, allowing you to proceed with an offline, local account.

Step-by-Step Configuration

To enable the bypass on your Ventoy USB drive, follow these steps:

  1. Prepare the USB Directory: Plug your Ventoy USB drive into your computer. In the root directory of the drive, create a folder named ventoy (all lowercase).
  2. Create the Configuration File: Inside the ventoy folder, create a new text file named ventoy.json.
  3. Add the Bypass Parameter: Open ventoy.json in any text editor and insert the following configuration:
{
    "control": [
        { "VTOY_WIN11_BYPASS_NRO": "1" }
    ]
}

If you also wish to bypass hardware checks (such as TPM 2.0, Secure Boot, and minimum RAM checks), you can combine the parameters like this:

{
    "control": [
        { "VTOY_WIN11_BYPASS_CHECK": "1" },
        { "VTOY_WIN11_BYPASS_NRO": "1" }
    ]
}
  1. Save and Close: Save the file and ensure its extension remains .json rather than .json.txt.

Installing Windows 11 with a Local Account

Once configured, boot your target computer from the Ventoy USB drive and select your official Windows 11 ISO.

When the installation progresses to the "Let's connect you to a network" screen, you will now see an active option labeled "I don't have internet." Click this option, followed by "Continue with limited setup." Windows setup will immediately skip the mandatory Microsoft account login and prompt you to create a traditional offline local username and password.
