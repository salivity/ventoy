Boot a VDI File Directly From Ventoy

Ventoy allows you to boot Linux VirtualBox disk images (.vdi) directly on physical hardware without converting them into standard ISO files. This guide details the preparation process using the official vtoyboot script, how to format the image file name so Ventoy recognizes it, and the final steps to launch your virtual environment from a USB drive.

Prerequisites

  • A USB drive with the latest version of Ventoy installed.
  • A VirtualBox virtual machine running a Linux distribution.
  • The vtoyboot tool, which injects the necessary kernel modules and scripts into the virtual machine to allow it to interface with physical hardware.

Step 1: Prepare the Virtual Machine with vtoyboot

Before Ventoy can boot a .vdi image, the guest operating system must be patched to load the proper storage and filesystem drivers at boot time.

  1. Start your Linux virtual machine inside VirtualBox.
  2. Download the latest vtoyboot release archive inside the guest OS.
  3. Extract the downloaded archive.
  4. Open a terminal, navigate to the extracted directory, and run the installation script with root privileges: 
    sudo bash vtoyboot.sh
  5. Once the script finishes successfully, shut down the virtual machine completely. Do not power it back on inside VirtualBox, as doing so may undo the changes made by vtoyboot.

Step 2: Rename the .vdi File

Ventoy relies on specific file extensions to identify how to process virtual disk images.

  1. Locate the .vdi file on your host computer (typically found in your VirtualBox VMs directory).
  2. Append .vtoy to the end of the file name. For example, rename ubuntu.vdi to: 
    ubuntu.vdi.vtoy

Step 3: Copy to Ventoy and Boot

  1. Copy the renamed .vdi.vtoy file onto your Ventoy USB partition just like a normal ISO.
  2. Safely eject the USB drive and insert it into the target physical computer.
  3. Boot the computer from the USB drive to enter the Ventoy menu.
  4. Select your .vdi.vtoy file from the list to boot the operating system.

Key Considerations

  • OS Support: Currently, the vtoyboot hook primarily supports Linux-based operating systems. Windows .vdi files are not supported natively through this method (Windows requires VHD/VHDX formats).
  • Hardware Drivers: Because the guest OS boots on physical hardware, ensure the Linux kernel installed in the image contains standard open-source drivers (such as graphics and network drivers) for the target machine.
