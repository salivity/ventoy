How to Boot Ventoy from Existing GRUB Menu

This guide explains how to add a custom menu entry to an existing GRUB installation to directly launch Ventoy without needing to change your computer's BIOS/UEFI boot order. By identifying the partition UUID of the Ventoy installation and adding a chainloader entry into your GRUB configuration files, you can seamlessly integrate your multiboot Ventoy drive into your primary system's boot menu.

1. Identify the Ventoy Partition UUID

Ventoy drives contain two partitions: a large data partition for ISO files and a smaller FAT partition (labeled VTOYEFI) that holds the bootloader. You need the UUID of the VTOYEFI partition.

Plug in your Ventoy drive and open a terminal, then run:

lsblk -f

Look for the partition labeled VTOYEFI (typically the second partition, such as sdb2). Note the filesystem type (usually vfat) and copy its UUID string (e.g., 1234-ABCD).

2. Edit the Custom GRUB Configuration

Custom GRUB entries should be added to /etc/grub.d/40_custom so they are not overwritten during kernel or system updates.

Open the file in a text editor with root privileges:

sudo nano /etc/grub.d/40_custom

3. Add the Ventoy Menu Entry

Scroll to the bottom of the file and add one of the following entries depending on your system's boot mode.

For UEFI Systems (Standard Modern Setup)

Replace YOUR-UUID-HERE with the actual UUID obtained from the VTOYEFI partition:

menuentry "Boot Ventoy (UEFI)" {
    insmod part_gpt
    insmod part_msdos
    insmod fat
    search --no-floppy --fs-uuid --set=root YOUR-UUID-HERE
    chainloader /EFI/BOOT/bootx64.efi
}

Note: If your system uses a 32-bit UEFI architecture, replace /EFI/BOOT/bootx64.efi with /EFI/BOOT/bootia32.efi.

For Legacy BIOS / MBR Systems

If you are running in legacy BIOS mode, use the following structure:

menuentry "Boot Ventoy (BIOS)" {
    insmod part_msdos
    insmod fat
    search --no-floppy --fs-uuid --set=root YOUR-UUID-HERE
    chainloader +1
}

Save the file and exit the text editor (in nano, press Ctrl+O, Enter, then Ctrl+X).

4. Update the GRUB Configuration

Apply the changes to regenerate your active grub.cfg file.

On Debian, Ubuntu, Linux Mint, and derivatives:

sudo update-grub

On Fedora, RHEL, Arch Linux, and derivatives:

sudo grub-mkconfig -o /boot/grub/grub.cfg

(Note: On some UEFI Fedora systems, the path may be /boot/efi/EFI/fedora/grub.cfg.)

5. Test the Entry

Reboot your system. When the GRUB menu appears, select your new "Boot Ventoy" entry. GRUB will locate the partition using the specified UUID, hand off control to Ventoy's bootloader, and display your standard Ventoy ISO selection screen.
