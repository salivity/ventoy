How to Customize Ventoy Background and Fonts

Ventoy allows users to completely personalize the appearance of its boot menu by leveraging standard GRUB2 theming capabilities through a central configuration file. By creating a dedicated configuration directory and adding a ventoy.json file, you can specify custom high-resolution background wallpapers and load custom .pf2 fonts to replace the default aesthetic. This guide provides a straightforward walkthrough for configuring both elements correctly on your Ventoy USB drive.

Step 1: Create the Required Directory Structure

Ventoy reads custom configurations from a specific folder located on the main partition where your ISO files reside.

  1. Open your Ventoy USB drive in your file manager.
  2. In the root directory, create a new folder named ventoy (lowercase).
  3. Inside the ventoy folder, create a subfolder named theme.
  4. Inside theme, create a folder for your custom assets, such as mytheme.

The resulting directory structure will look like this:

USB_ROOT/
└── ventoy/
    ├── ventoy.json
    └── theme/
        └── mytheme/
            ├── theme.txt
            ├── background.png
            └── custom-font.pf2

Step 2: Prepare the Background Image

Ventoy supports standard image formats, primarily PNG and JPG. For the best visual quality and to avoid scaling artifacts:

  1. Choose or resize an image to match your target display resolution (e.g., 1920x1080).
  2. Save the image in PNG format (recommended for reliability) inside /ventoy/theme/mytheme/ as background.png.

Step 3: Prepare and Add Custom Fonts

GRUB2 cannot render raw TTF or OTF fonts directly; it requires fonts in the .pf2 format.

  1. Obtain a PF2 Font:
    • You can download pre-compiled .pf2 fonts from existing GRUB themes.
    • Alternatively, convert a TTF/OTF font on a Linux system using the grub-mkfont utility: 
      grub-mkfont -s 16 -o custom-font.pf2 /path/to/font.ttf
      (The -s parameter defines the font size in points).
  2. Copy the generated .pf2 file into your /ventoy/theme/mytheme/ directory.

Step 4: Create the theme.txt File

GRUB uses a file named theme.txt to apply visual elements. Create a plain text file named theme.txt inside /ventoy/theme/mytheme/ with the following basic configuration:

# Global properties
title-text: ""
desktop-image: "background.png"
desktop-color: "#000000"

# Custom Font Declaration
terminal-font: "Custom Font Regular 16"

# Boot Menu Configuration
+ boot_menu {
    left = 20%
    top = 25%
    width = 60%
    height = 50%
    item_font = "Custom Font Regular 16"
    item_color = "#cccccc"
    selected_item_color = "#ffffff"
    item_height = 28
    item_spacing = 4
}

Note: Ensure the font name used in item_font matches the internal font name embedded inside the .pf2 file, not just the file name.

Step 5: Enable the Theme in ventoy.json

To instruct Ventoy to load your theme instead of the default layout, define it in the configuration file.

  1. Inside the /ventoy/ directory, create a text file named ventoy.json.
  2. Insert the following JSON block:
{
    "theme": {
        "file": "/ventoy/theme/mytheme/theme.txt",
        "gfxmode": "1920x1080"
    }
}
  • The "file" key specifies the absolute path from the USB root to your theme.txt.
  • The "gfxmode" key sets the display resolution. You can set it to match your background image resolution or use "1920x1080,1366x768,auto" to allow fallback options.

Once saved, safely eject your USB drive. Upon booting, Ventoy will automatically initialize the specified resolution, render your custom background, and display the boot menu using your chosen font.
