Ventoy Auto Installation Plugin Explained

The Ventoy auto-installation plugin is a configuration tool that enables unattended operating system deployments directly from a Ventoy-prepared USB drive. By linking automated response scripts—such as Windows answer files or Linux kickstart configurations—directly to original ISO images, the plugin automates the setup process without requiring users to modify or rebuild the ISO files. This overview details the primary functions, configuration mechanisms, and benefits of using this plugin for mass deployment and testing.

Core Functionality

The primary purpose of the auto-installation plugin is to eliminate the need for manual user intervention during operating system setups. When deploying an OS, installers typically halt to prompt for user credentials, disk partitioning preferences, language and keyboard layouts, and network configurations.

The Ventoy auto-installation plugin injects predefined installation scripts into the boot process dynamically. Once the installer starts, it reads these instructions and completes the entire installation silently and automatically.

How the Plugin Works

The plugin operates via the ventoy.json configuration file, which resides in the ventoy folder at the root of the USB drive. Within this JSON file, administrators define an auto_install array that maps specific ISO paths to corresponding configuration scripts stored on the drive.

When an ISO configured in this block is selected from the Ventoy boot menu:

  1. Ventoy reads the assigned script.
  2. It constructs a virtual environment or modifies boot parameters dynamically in memory.
  3. The original ISO boots, recognizes the automated answer file, and proceeds through installation without prompting the user.

If multiple answer scripts are mapped to a single ISO, Ventoy presents a sub-menu upon selection, allowing the administrator to choose the appropriate deployment profile (such as a minimal server setup versus a full workstation setup).

Supported Formats and Systems

The auto-installation plugin supports standard configuration formats across major operating system families:

  • Windows: Uses unattend.xml or autounattend.xml to configure regional settings, create user accounts, skip license agreements, and automate disk layout.
  • Red Hat / CentOS / Rocky Linux / Fedora: Uses Kickstart files (.cfg) to define packages, networking, and system parameters.
  • Debian / Ubuntu: Uses Preseed configuration files to automatically answer debconf questions.
  • SUSE / openSUSE: Uses AutoYaST XML profiles to control the installation framework.

Key Benefits

  • Preserves Original Images: Traditional automated installations require extracting an ISO, injecting the answer file, and repacking the image. Ventoy leaves the original ISO completely unmodified.
  • Centralized Configuration: All deployment scripts and mappings are maintained in standard text files on the USB drive, making version control and updates straightforward.
  • Flexibility: A single USB stick can deploy multiple distinct configurations of the same operating system by mapping different answer scripts to the same ISO file.
