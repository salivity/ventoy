How to Set Ventoy Boot Menu to Text Mode

This guide explains how to switch the Ventoy boot loader interface from its default graphical user interface (GUI) to text mode. While the graphical theme provides a modern visual look, text mode is often preferred for troubleshooting display resolution problems, ensuring maximum compatibility with older hardware, or providing a clean, distraction-free interface. You can switch to text mode either permanently by modifying a configuration file or temporarily using a keyboard shortcut.

Method 1: Permanent Switch via ventoy.json

To make text mode the default display every time you boot:

  1. Insert your Ventoy USB drive into your computer.
  2. Open the primary partition of the USB drive (the partition where you store your ISO files).
  3. Check for a folder named ventoy in the root directory. If it does not exist, create a new folder named ventoy (ensure the name is entirely lowercase).
  4. Inside the ventoy folder, create a new plain text file and name it ventoy.json. If you already have a ventoy.json file, open it with a text editor like Notepad, VS Code, or Nano.
  5. Add the following JSON configuration to the file:
{
    "theme": {
        "display_mode": "text"
    }
}

Note: If your ventoy.json already contains other configuration blocks, simply insert the "display_mode": "text" key-value pair inside your existing "theme" object.

  1. Save the file and safely eject the USB drive. When you next boot from the drive, Ventoy will load directly into text mode.

Method 2: Temporary Switch Using the Hotkey

If you only need text mode for a single session, you do not need to edit configuration files:

  1. Boot your computer from the Ventoy USB drive into the standard graphical menu.
  2. Once the menu appears, press the F7 key on your keyboard.
  3. The display will immediately switch from GUI mode to text mode. Pressing F7 again will return the menu to GUI mode.
