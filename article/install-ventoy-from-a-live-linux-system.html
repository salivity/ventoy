Install Ventoy from a Live Linux System

Yes, you can install Ventoy directly from within a running live Linux system. Because live distributions run primarily in memory (RAM) and provide root access via sudo, they have all the required tools to download, extract, and execute Ventoy’s installation scripts onto a secondary USB flash drive or storage device. This guide provides a straightforward walkthrough on how to prepare the environment, identify target drives, and execute the installation using either the command-line interface or the web-based graphical installer.

Prerequisites

Before beginning, ensure you have the following:

  • A live Linux session (such as Ubuntu Live, Fedora Live, or SystemRescue) booted and running.
  • An active internet connection to download the Ventoy archive.
  • The target USB drive where Ventoy will be installed.
  • Administrative privileges (sudo access, typically enabled by default in live sessions).

Step 1: Download and Extract Ventoy

  1. Open your terminal in the live desktop environment.
  2. Download the latest Linux release package from the official Ventoy repository (or use your browser). Via terminal, you can fetch it with curl or wget: 
    wget https://github.com/ventoy/Ventoy/releases/download/v1.0.99/ventoy-1.0.99-linux.tar.gz
    (Note: Replace the version number with the current release if newer.)
  3. Extract the downloaded archive: 
    tar -xzvf ventoy-*-linux.tar.gz
  4. Navigate into the extracted directory: 
    cd ventoy-*

Step 2: Identify the Target Drive

It is critical to distinguish between the drive hosting your live Linux image and the destination drive for Ventoy.

Run the block device list command:

lsblk

Locate your target USB drive by its storage size and model name (for example, /dev/sdb or /dev/sdc). Do not select the drive running the live system (often /dev/sda or a partition mounted at /cdrom or /rofs), as overwriting it will crash your active session.

Step 3: Install Ventoy

You can complete the installation using either the command-line script or the browser-based graphical user interface.

Method A: Command-Line Installation (Fastest)

Run the installation script pointing to the whole device node (not a partition number):

sudo sh Ventoy2Disk.sh -i /dev/sdX

(Replace /dev/sdX with your verified target drive letter, such as /dev/sdb.)

  • The script will prompt you twice to confirm that all data on the target drive will be wiped. Type y and press Enter for both prompts.
  • Once completed, Ventoy will partition and format the drive into an exFAT data partition and an EFI system partition.

Method B: Web GUI Installation

If you prefer a graphical interface:

  1. In the terminal, start the local web service: 
    sudo sh VentoyWeb.sh
  2. Open the web browser in your live session and navigate to: 
    http://127.0.0.1:2460
  3. Select your target USB drive from the drop-down menu.
  4. Click Install and confirm the formatting prompts.
  5. Once the installation status reaches 100%, return to the terminal and press Ctrl + C to stop the web server.

Post-Installation

Once the process finishes, safely unplug and reconnect the USB drive. Your live Linux system will mount the new partition (labeled Ventoy). You can immediately begin copying ISO files directly onto this partition without needing to reboot your computer.
