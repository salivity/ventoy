How to Use ventoy_grub.cfg for Custom GRUB Entries

The ventoy_grub.cfg configuration file allows Ventoy users to define custom GRUB2 boot entries, chainload other bootloaders, and execute custom scripts without altering the underlying Ventoy installation. This guide explains what the file does, where to place it on your drive, how to write standard GRUB2 menu entries for it, and how to access your custom menu options directly from the Ventoy interface.

What is ventoy_grub.cfg?

Ventoy is an open-source tool used to create bootable USB drives simply by copying ISO, WIM, IMG, and VHD(x) files directly onto the storage media. While Ventoy automatically generates its own dynamic menu based on the image files found on the partition, advanced users often require custom boot logic.

The ventoy_grub.cfg file is a user-defined GRUB2 script file. When present, Ventoy reads this file and integrates its definitions into a dedicated submenu, allowing users to:

  • Boot operating systems installed on internal hard drives.
  • Chainload specific .efi binaries or specialized boot files.
  • Pass custom kernel parameters to distributions.
  • Add administrative entries like hardware reboots, shutdowns, or UEFI firmware access.

File Location and Setup

To make Ventoy recognize your custom configuration, create a text file named ventoy_grub.cfg in the proper location on your drive:

  1. Open your Ventoy USB drive's primary storage partition (the partition where your ISO files reside, formatted as exFAT, NTFS, or FAT32).
  2. Create a folder named ventoy in the root of that partition (if it does not already exist).
  3. Place ventoy_grub.cfg inside this folder.

The absolute path should be:

/ventoy/ventoy_grub.cfg

Syntax and Structure

The file uses standard GRUB2 configuration syntax. Each custom entry is enclosed within a menuentry block.

Example Configuration

Below is a functional sample ventoy_grub.cfg demonstrating common entries:

# Return to Ventoy Main Menu
menuentry "<- Return to Previous Menu [Esc]" --class=vtoyret {
    VTOY_RET
}

# Boot Windows Boot Manager from the primary internal disk (UEFI)
menuentry "Boot Local Windows Boot Manager" --class=windows {
    insmod chain
    insmod ntfs
    search --no-floppy --file --set=root /EFI/Microsoft/Boot/bootmgfw.efi
    chainloader /EFI/Microsoft/Boot/bootmgfw.efi
}

# Reboot into UEFI Firmware Settings
menuentry "UEFI Firmware Settings" --class=efi {
    fwsetup
}

# Restart Computer
menuentry "Reboot System" --class=reboot {
    reboot
}

# Halt System
menuentry "Power Off" --class=halt {
    halt
}

Accessing Custom Entries in Ventoy

  1. Boot your computer from the Ventoy USB drive.
  2. At the main Ventoy boot menu, press the F6 key on your keyboard.
  3. Ventoy will parse /ventoy/ventoy_grub.cfg and display your custom GRUB menu.
  4. Select the desired entry and press Enter to execute it.

To return to the standard ISO file list, select the entry containing the VTOY_RET command or press Esc.
