How to Remove Ventoy and Restore USB Drive

Ventoy is a popular open-source utility that allows users to boot multiple operating systems from a single USB drive. Because Ventoy creates hidden, multi-partition structures (including an EFI system partition and an exFAT storage partition), standard right-click formatting in an operating system often fails to completely erase it. This guide outlines the most effective methods to completely remove Ventoy and restore your USB drive to a single, fully functional partition using native operating system tools and the Ventoy utility itself.

Method 1: Use the Ventoy2Disk Application

The fastest and safest method to revert your drive is to use the official Ventoy application itself, which includes a built-in uninstallation routine.

  1. Connect your USB flash drive to your computer.
  2. Launch the Ventoy2Disk.exe utility.
  3. Select your USB drive from the Device drop-down menu.
  4. Click on the Option menu at the top of the window.
  5. Select Uninstall.
  6. A confirmation prompt will appear warning that all data will be destroyed. Click Yes to confirm.

Ventoy will delete its custom partition table and reformat the flash drive back to a standard, single-partition storage device.

Method 2: Use Windows Diskpart (Complete Clean)

If you no longer have the Ventoy installer, or if the drive is not responding properly, the Windows command-line tool diskpart will forcefully wipe the hidden partitions and the Master Boot Record (MBR) or GUID Partition Table (GPT).

  1. Press Win + R, type cmd, and press Ctrl + Shift + Enter to run Command Prompt as Administrator.
  2. Type diskpart and press Enter.
  3. Type list disk and press Enter. Identify the disk number corresponding to your USB flash drive by looking at the storage capacity.
  4. Type select disk X (replace X with your actual USB drive number) and press Enter.
  5. Type clean and press Enter. This erases all partition data, hidden system files, and the bootloader.
  6. Type create partition primary and press Enter.
  7. Type format fs=exfat quick (or format fs=ntfs quick) and press Enter.
  8. Type assign and press Enter to give the drive a drive letter.
  9. Type exit to close Diskpart.

Method 3: Use Windows Disk Management

If you prefer a graphical interface on Windows:

  1. Right-click the Start button and select Disk Management.
  2. Scroll through the bottom pane to locate your USB drive. You will see two partitions: the main storage partition and the hidden VTOYEFI partition.
  3. Right-click the primary data partition and choose Delete Volume. Confirm when prompted.
  4. Right-click the VTOYEFI partition and choose Delete Volume.
  5. Once both partitions are deleted, the entire drive space will display as Unallocated.
  6. Right-click the unallocated space and select New Simple Volume.
  7. Follow the on-screen wizard, leave the volume size at maximum, select your preferred file system (exFAT, NTFS, or FAT32), and click Finish.

Method 4: Use macOS Disk Utility

If you are on a Mac, you can wipe the drive using the native Disk Utility application.

  1. Plug the USB drive into your Mac.
  2. Open Disk Utility (found via Spotlight or inside /Applications/Utilities/).
  3. Click the View dropdown menu in the upper-left corner and select Show All Devices.
  4. In the left sidebar, select the top-level name of your USB drive (the physical hardware drive, not the volume name indented beneath it).
  5. Click the Erase button in the top toolbar.
  6. Enter a name for the drive.
  7. Set the Format to ExFAT (compatible with both Windows and Mac) or MS-DOS (FAT).
  8. Set the Scheme to Master Boot Record or GUID Partition Map.
  9. Click Erase to wipe the drive and restore it to factory status.
