How to Reboot Directly from the Ventoy Interface

Ventoy is widely recognized as a versatile multiboot USB solution, yet users often need to restart their system directly from the bootloader screen without cutting power or loading an operating system. This article provides a clear, step-by-step guide on how to trigger a hardware reboot directly from the Ventoy interface using built-in keyboard shortcuts and command-line instructions.

Method 1: The Universal Reboot Keystroke

The quickest and most direct way to initiate a hardware reboot from the main Ventoy boot menu is using the standard pre-boot keyboard combination:

  1. Ensure the Ventoy interface is currently displayed on your monitor.
  2. Press Ctrl + Alt + Delete simultaneously on your keyboard.

Because Ventoy operates within a pre-boot UEFI or legacy BIOS environment, this key combination immediately signals the motherboard firmware to perform a warm hardware restart.

Method 2: The GRUB Command Console

If the key combination is intercepted or disabled by your specific firmware, you can reboot the machine using Ventoy's underlying GRUB2 command shell:

  1. From the main Ventoy file selection menu, press the c key to open the command-line interface.
  2. In the terminal prompt, type: 
    reboot
  3. Press Enter.

The system will instantly reset and initiate standard POST (Power-On Self-Test) routines, safely restarting your computer without touching the physical power switch.
