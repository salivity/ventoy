Sign Ventoy with Custom Secure Boot Keys

Users can sign Ventoy binaries using their own personal custom Secure Boot keys, allowing the bootable USB drive to run in strict UEFI environments where standard third-party keys are disabled or custom keys are enforced. This approach provides complete control over the system's chain of trust, bypassing the default Ventoy MOK (Machine Owner Key) enrollment while maintaining full Secure Boot integrity.

Feasibility and Requirements

Ventoy inherently supports Secure Boot through a signed shim loader and MOK manager, but it also allows manual signing of its core EFI executables. If your UEFI firmware runs in "User Mode" with custom Platform Keys (PK), Key Exchange Keys (KEK), and authorized Signature Databases (db), you can replace Ventoy's signatures with your private cryptographic keys.

To complete this process, you need:

  • A working installation of Ventoy on a USB flash drive.
  • Your custom Secure Boot certificate (e.g., db.crt) and private key (e.g., db.key).
  • A signing utility, such as sbsigntool on Linux or SignTool on Windows.

Accessing the Ventoy EFI Binaries

Ventoy partitions the USB flash drive into two sections: an exFAT/NTFS partition for storing ISO files and a hidden FAT16/FAT32 EFI System Partition (ESP) labeled VTOYEFI.

  1. Mount the VTOYEFI partition to access the boot files.
  2. Navigate to the EFI/BOOT/ directory inside the partition.
  3. Identify the primary boot files that require signing, primarily BOOTX64.EFI (for x86_64 systems) or the architecture-specific loader you intend to boot.

Signing the Binaries

Using Linux and sbsigntool, you can remove the existing vendor signature (optional) and sign the binary with your custom key:

sbsign --key db.key --cert db.crt --output /path/to/VTOYEFI/EFI/BOOT/BOOTX64.EFI /path/to/VTOYEFI/EFI/BOOT/BOOTX64.EFI

If you plan to use Ventoy's internal GRUB loader directly, you must also inspect the grub directories on the ESP and sign any secondary .efi binaries that the primary loader chainloads.

Maintenance and Updates

Custom signatures are written directly to the binaries on the VTOYEFI partition. Whenever you upgrade Ventoy to a newer release using the official updater, the installer rewrites the EFI partition, replacing your signed binaries with standard Ventoy executables. Consequently, you must re-sign the binaries after every Ventoy version upgrade.
