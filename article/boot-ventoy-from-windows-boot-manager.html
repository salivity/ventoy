Boot Ventoy from Windows Boot Manager

This article explores whether and how Ventoy can be integrated into a multi-boot system driven by the Windows Boot Manager. While the Windows Boot Configuration Data (BCD) engine is primarily tailored to boot Windows-based operating systems, it is entirely possible to add Ventoy to the menu on modern UEFI systems. Below is an explanation of how this integration works, the primary configuration methods, and the technical limitations to keep in mind.

Can Ventoy Be Integrated?

Yes. Ventoy can be added to the Windows Boot Manager menu. Because modern systems use UEFI, the Windows Boot Manager can chainload third-party .efi binaries or invoke external partitions. By creating a custom entry in the Windows Boot Configuration Data (BCD) store, you can instruct the Windows Boot Manager to execute Ventoy's EFI loader directly from an internal drive or USB partition.

Methods for Integration

There are two primary approaches to booting Ventoy from the Windows Boot Manager: direct BCD chainloading and booting via a Virtual Hard Disk (VHD).

1. Direct UEFI BCD Entry (Recommended)

This method creates an entry directly in your existing Windows BCD pointing to Ventoy's EFI executable file located on its dedicated boot partition.

  1. Locate the Ventoy EFI File: Ventoy creates two partitions upon installation. The small partition (usually FAT formatted, labelled VTOYEFI) contains the EFI bootloaders, typically at \EFI\BOOT\BOOTX64.EFI.
  2. Assign a Drive Letter: Use Windows Disk Management or diskpart to assign a temporary drive letter to the VTOYEFI partition if it is not already visible.
  3. Configure the BCD: You can use either the command line or a GUI tool like BOOTICE or EasyBCD (note: UEFI BCD management may require commercial EasyBCD or third-party tools like EasyUEFI).

Using Windows Command Prompt (Administrator):

bcdedit /copy {bootmgr} /d "Ventoy Multi-Boot"

This command outputs a GUID for the new entry, such as {xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx}.

Next, set the path to the Ventoy executable and the target partition:

bcdedit /set {your-guid-here} device partition=X:
bcdedit /set {your-guid-here} path \EFI\BOOT\BOOTX64.EFI

(Replace X: with the drive letter of the Ventoy EFI partition, and {your-guid-here} with the generated GUID.)

Once saved, remove the temporary drive letter using diskpart.

2. Booting Ventoy via VHD

If you prefer not to repartition physical disks to house Ventoy permanently, you can install Ventoy inside a raw Virtual Hard Disk (VHD) file.

  1. Create a fixed-size VHD using Windows Disk Management.
  2. Initialize and install Ventoy onto the mounted VHD.
  3. Place your ISO images inside the VHD's storage partition.
  4. Add the VHD to the Windows Boot Manager via standard BCD commands or utility software.

When selected at boot, the Windows Boot Manager mounts the virtual disk and handshakes execution over to the Ventoy environment contained within it.

Important Considerations

  • Secure Boot: Ventoy supports Secure Boot, but you must enroll the Ventoy MOK (Machine Owner Key) certificate during the first launch if Secure Boot is enabled in your UEFI firmware.
  • Legacy BIOS Limitations: If your system runs in Legacy BIOS/MBR mode instead of UEFI, chainloading Ventoy through the standard Windows BCD is significantly more complex and often unreliable. In MBR environments, it is typically better to install GRUB4DOS or use the native BIOS boot selection menu.
  • Windows Updates: Major Windows feature updates occasionally rebuild or prioritize the default Windows EFI entry. You may need to verify or restore the custom BCD entry after large system updates.
