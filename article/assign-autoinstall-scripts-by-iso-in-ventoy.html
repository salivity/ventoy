Assign Autoinstall Scripts by ISO in Ventoy

Ventoy allows you to automatically assign specific unattended installation scripts to individual ISO files based on their storage paths. By configuring the native Auto Install Plugin via a JSON file, you can map answer files—such as Windows unattend.xml, Debian/Ubuntu Preseed, Red Hat Kickstart, or AutoYaST scripts—directly to specific image paths or entire directories. This setup eliminates the need to manually browse for or inject configuration files during system deployment.

How the Auto Install Plugin Works

Ventoy identifies which script to inject by referencing a configuration file located on your USB drive at /ventoy/ventoy.json. Inside this file, the auto_install object contains an array of mappings between ISO paths and script paths.

When you boot an ISO, Ventoy checks ventoy.json for a match. If a match is found, Ventoy prompts you to select either an automated installation or a standard manual installation.

Configuring ventoy.json

To set up path-based autoinstall scripts, create a folder named ventoy in the root of your Ventoy partition (if it does not already exist), and create a text file named ventoy.json inside it.

Here is an example configuration demonstrating path-based script assignment:

{
    "auto_install": [
        {
            "image": "/ISO/Windows/Win11_Pro.iso",
            "template": "/ventoy/script/win11_unattend.xml"
        },
        {
            "image": "/ISO/Linux/ubuntu-22.04-live-server.iso",
            "template": "/ventoy/script/ubuntu_autoinstall.yaml"
        },
        {
            "image": "/ISO/RedHat/",
            "template": "/ventoy/script/rhel_ks.cfg"
        }
    ]
}

Path Matching Rules

  • Exact File Match: Defining a full path to an ISO (e.g., /ISO/Windows/Win11_Pro.iso) binds the specified template exclusively to that single image.
  • Directory Match: Specifying a directory ending with a forward slash (e.g., /ISO/RedHat/) applies the defined template to every ISO located within that directory.
  • Case Sensitivity: Paths in ventoy.json are case-sensitive. Ensure that the capitalization in the JSON configuration matches the file and directory names on the USB drive exactly.
  • Template Storage: While the template files can technically reside anywhere on the USB drive, storing them inside /ventoy/script/ or a dedicated configuration folder is standard practice for easy maintenance.

Multiple Template Selection

If you have multiple configurations for a single ISO (such as one script for a desktop setup and another for a server setup), you can assign an array of templates to a single image path:

{
    "auto_install": [
        {
            "image": "/ISO/Windows/Win10.iso",
            "template": [
                "/ventoy/script/win10_workstation.xml",
                "/ventoy/script/win10_kiosk.xml"
            ]
        }
    ]
}

When booting this image, Ventoy will present a menu allowing you to select which unattended script you want to load.
