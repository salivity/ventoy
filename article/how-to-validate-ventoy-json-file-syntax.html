How to Validate Ventoy JSON File Syntax

The ventoy.json configuration file allows users to customize the Ventoy boot menu, theme, auto-installation scripts, and plugin options. However, even a minor syntax mistake—such as a missing bracket or a trailing comma—will cause Ventoy to ignore the file entirely. This guide outlines the most effective methods to validate the syntax of your ventoy.json file, using official Ventoy utilities, command-line tools, text editors, and online linters to ensure proper functionality before booting.

1. Use the Official VentoyPlugson Tool

The most reliable way to avoid and check for syntax errors is by using VentoyPlugson, Ventoy's official web-based configuration utility.

  • Download the latest Ventoy package for Windows or Linux.
  • Run the VentoyPlugson executable (VentoyPlugson.exe on Windows, or sudo sh VentoyPlugson.sh /dev/sdX on Linux).
  • Click Start to launch the local web server and open the interface in your browser.
  • VentoyPlugson reads your existing ventoy.json file, validates its structure, and alerts you if there are parsing errors. Modifying settings through this GUI guarantees valid JSON formatting upon saving.

2. Validate via Command-Line Tools

If you prefer using a terminal or need a quick automated check, standard JSON parsing tools can detect syntax errors instantly.

Using Python

Python comes pre-installed on most Linux and macOS systems and is widely available on Windows. Run the following command in the directory containing your file:

python -m json.tool ventoy.json
  • Valid: The command outputs the formatted JSON content without errors.
  • Invalid: The terminal outputs an error pointing directly to the line and column number where the syntax error occurred.

Using jq

If you have jq installed on Linux or macOS, run:

jq . ventoy.json > /dev/null

If the syntax is correct, the command returns no output and exits with code 0. If invalid, jq prints the exact parsing error and line number.

3. Use Code Editors with Built-in JSON Validation

Modern source code editors have integrated syntax highlighters and JSON linters:

  • Visual Studio Code: Open ventoy.json. If there is a syntax issue, the file name turns red, the minimap displays red markers, and the Problems tab (Ctrl+Shift+M or Cmd+Shift+M) lists the exact syntax error.
  • Notepad++: Install the JSTool or JSON Viewer plugin via the Plugin Admin. Use the format or validate option to locate invalid tokens.

4. Use Online JSON Linters

If you do not have command-line utilities or advanced editors installed, you can use any standard online JSON validator (such as JSONLint):

  1. Open your ventoy.json file in a plain text editor.
  2. Copy the entire contents of the file.
  3. Paste the code into the online validator and click Validate JSON.
  4. The tool will verify whether standard JSON rules are met and flag any errors.

Important Guidelines for ventoy.json

When correcting syntax errors, keep the following Ventoy-specific rules in mind:

  • No Trailing Commas: JSON does not allow a comma after the last item in an array or object. This is the most common reason a ventoy.json fails.
  • Proper Quotation: All keys and string values must be enclosed in standard double quotes ("), not single quotes (') or typographic "smart" quotes.
  • Correct File Location: The file must strictly be named ventoy.json (all lowercase) and placed inside a folder named ventoy located at the root of the Ventoy partition (/ventoy/ventoy.json).
