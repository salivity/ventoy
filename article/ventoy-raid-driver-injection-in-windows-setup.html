Ventoy RAID Driver Injection in Windows Setup

Ventoy allows administrators to dynamically inject mass storage and hardware RAID drivers during an enterprise Windows installation without modifying the original ISO image. By leveraging Ventoy’s native Windows Injection Plugin, you can automatically load vendor-specific storage controller drivers—such as Broadcom MegaRAID, Dell PERC, or HPE Smart Array—directly into the Windows Preinstallation Environment (WinPE). This ensures that target storage arrays are detected immediately during the drive selection phase of the setup process.

The Mechanism: Windows Injection Plugin

Enterprise Windows installations frequently stall at the "Select the driver to be installed" or disk selection screen when the operating system media lacks native drivers for hardware RAID controllers. Ventoy resolves this using its injection plugin architecture.

During the boot phase, Ventoy hooks into the WinPE startup process. It mounts a specified archive containing your raw driver files into memory and executes a script to stage these drivers using pnputil.exe or drvload.exe before the main Windows Setup interface initializes.

Preparing the RAID Drivers

Ventoy requires raw, unpacked driver files. Executable installer files (.exe) are not supported.

  1. Obtain the driver package from the hardware vendor (e.g., Dell, HP, Lenovo).
  2. Extract the driver contents until you have the raw .inf, .sys, and .cat files for the target architecture (typically x64).
  3. Place these files inside a structured directory, for example: RAID_Drivers/.
  4. Compress the folder into a standard archive, such as raid_drivers.7z or raid_drivers.zip.

Configuring ventoy.json

To bind the driver archive to your enterprise Windows ISO, configure the ventoy.json file inside the ventoy directory on the root of your USB drive:

  1. Create a folder named ventoy on the root of the Ventoy partition if it does not exist.
  2. Place the compressed driver archive inside the ventoy folder (e.g., ventoy/raid_drivers.zip).
  3. Create or edit ventoy/ventoy.json.
  4. Add the injection configuration structure linking your Windows ISO to the driver archive:
{
    "injection": [
        {
            "image": "/ISO/Windows_Server_2022.iso",
            "archive": "/ventoy/raid_drivers.zip"
        }
    ]
}

Execution During Setup

When you select the enterprise Windows ISO from the Ventoy boot menu:

  1. Ventoy loads the WinPE environment from the ISO into memory.
  2. The injection hook automatically unpacks the archive into the temporary WinPE file system (X:\ventoy\).
  3. Ventoy's embedded initialization script scans the extracted path and injects every .inf file using standard Windows driver loading utilities.
  4. Windows Setup opens, queries the storage controller, and displays the provisioned RAID virtual disks without requiring manual driver browsing via USB.

Technical Requirements and Caveats

  • Driver Architecture: Ensure the injected storage drivers match the kernel architecture of the Windows PE environment (e.g., 64-bit drivers for 64-bit installation media).
  • Driver Signing: Enterprise Windows installations with Secure Boot enabled will reject unsigned or improperly signed drivers loaded through WinPE. Use official WHQL-certified vendor drivers.
  • Storage Pathing: Paths inside ventoy.json are case-sensitive and must start with a forward slash relative to the root of the Ventoy partition.
