Generate SHA-512 or PBKDF2 Password Hash for Ventoy

Ventoy allows you to secure your bootable USB drive by password-protecting the main menu or individual ISO files. To prevent exposing credentials in plaintext, Ventoy supports cryptographically secure password hashes, including SHA-512 and PBKDF2. This guide explains how to generate these compatible hashes using standard terminal utilities and how to apply them directly to your Ventoy configuration.

Generating a PBKDF2 Hash

PBKDF2 is the most secure option supported by Ventoy and utilizes standard GRUB2 hashing mechanisms. You can generate a compatible hash using Linux terminal utilities.

  1. Open a terminal on any Linux system.
  2. Run the GRUB password generation command: 
    grub-mkpasswd-pbkdf2
  3. Enter your desired password and confirm it when prompted.
  4. The output will look similar to this: 
    Your PBKDF2 is grub.pbkdf2.sha512.10000.C8E...D4A
  5. Copy the entire string starting with grub.pbkdf2.sha512.

Generating a SHA-512 Hash

If you prefer SHA-512 over PBKDF2, you can generate a compatible hash using the standard OpenSSL utility available on Linux, macOS, and Windows via Git Bash or WSL.

  1. Run the following command in your terminal: 
    openssl passwd -6
  2. Type your password and press Enter. Verify it when prompted.
  3. The terminal will output a string starting with $6$, which designates a SHA-512 hash with a cryptographic salt: 
    $6$saltstring$hashedpasswordstring...
  4. Copy the entire output string.

Alternative: Using VentoyPlugson GUI

If you prefer not to use the command line, Ventoy provides a built-in browser-based configuration tool that generates hashes automatically.

  1. Connect your Ventoy USB drive to your computer.
  2. Run VentoyPlugson.exe on Windows or execute sudo ./VentoyPlugson.sh /dev/sdX on Linux (replace /dev/sdX with your USB drive's identifier).
  3. Open the provided local URL in your web browser.
  4. Navigate to the Password Plugin tab.
  5. Enter your password in the provided field, select either SHA-512 or PBKDF2, and the tool will automatically write the hash to your configuration.

Applying the Hash in ventoy.json

To manually apply the hash, open or create the /ventoy/ventoy.json file on the root partition of your Ventoy drive. Use the generated string in the password parameter under the control section:

{
    "control": [
        {
            "VTOY_DEFAULT_SEARCH_ROOT": "/ISO",
            "VTOY_MENU_TIMEOUT": "10"
        }
    ],
    "password": {
        "vtoy_password": "YOUR_GENERATED_HASH_STRING_HERE"
    }
}

Replace YOUR_GENERATED_HASH_STRING_HERE with your copied PBKDF2 or SHA-512 string. Save the file and safely eject the drive. Ventoy will now require your password upon booting.
