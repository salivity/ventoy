Automate Windows Server Setup Using Ventoy Answer Files

Ventoy fully supports automated answer files for unattended Windows Server setups through its native Auto Install Plugin. This article explains how Ventoy enables unattended deployments, how to configure the ventoy.json file to pair an autounattend.xml answer file with your Windows Server ISO, and the key benefits of using this method for rapid system rollouts.

How Ventoy Handles Unattended Windows Server Setups

Ventoy does not modify the original Windows Server ISO to achieve an automated installation. Instead, it uses an internal hook via its Auto Install Plugin to inject an XML answer file (autounattend.xml) into the Windows PE installer runtime during the boot process. This means you can keep your original, untouched Microsoft ISOs on the flash drive while dynamically attaching configuration scripts at boot time.

Step-by-Step Configuration

To set up an automated Windows Server installation using Ventoy, follow these steps:

1. Create Your Windows Server Answer File

Generate an autounattend.xml file tailored to your Windows Server edition (such as Windows Server 2019, 2022, or 2025). The file should automate your desired setup options, including disk partitioning, regional settings, the local administrator password, and product key insertion. You can create this file manually or by using the Windows System Image Manager (SIM).

2. Set Up the Directory Structure

Inside the root directory of your Ventoy USB drive, create a folder named ventoy (all lowercase) if it does not already exist. Place your answer file in this folder or a dedicated subfolder.

For example:

  • /ventoy/ventoy.json
  • /ventoy/script/win_server_2022.xml
  • /iso/Windows_Server_2022.iso

3. Configure ventoy.json

Create or edit the ventoy.json file inside the /ventoy folder. Use the auto_install configuration array to map your specific Windows Server ISO to your answer file:

{
    "auto_install": [
        {
            "image": "/iso/Windows_Server_2022.iso",
            "template": "/ventoy/script/win_server_2022.xml"
        }
    ]
}

You can specify exact paths, or you can map an answer file to multiple ISOs using parent directory matching.

4. Boot and Deploy

When you boot from the Ventoy drive and select your Windows Server ISO, Ventoy prompts you to choose whether to run the installation in automated mode or normal mode. Selecting the automated option injects the mapped autounattend.xml, allowing the Windows Server setup to run to completion without user intervention.
