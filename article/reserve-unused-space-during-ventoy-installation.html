Reserve Unused Space During Ventoy Installation

Ventoy is a popular open-source tool that allows users to create bootable USB drives simply by copying ISO files onto the device. By default, Ventoy formats and claims the entire capacity of the storage medium. However, you can configure the installer to leave a specified amount of unallocated space at the end of the drive, which can later be partitioned for regular file storage, encrypted volumes, or alternative operating system partitions.

Reserving Space Using the Ventoy GUI (Windows & Linux)

  1. Connect your target USB drive to your computer.
  2. Launch the Ventoy2Disk application.
  3. Select your USB drive from the Device drop-down menu.
  4. Click on the Option menu located in the top navigation bar.
  5. Select Partition Configuration from the menu.
  6. Check the box labeled Preserve some space at the bottom of the disk.
  7. Enter the amount of storage you wish to leave unallocated at the end of the drive, and select the appropriate unit (MB or GB).
  8. Click OK to save the partition layout preferences.
  9. Click Install on the main window. A prompt will warn you that all existing data will be erased. Confirm the prompt to proceed.

Reserving Space Using the Linux Command Line

If you are using the Linux terminal script (Ventoy2Disk.sh), use the -r flag to specify reserved space in megabytes.

  1. Identify your target USB device path (for example, /dev/sdb) using lsblk or fdisk -l.
  2. Open a terminal and navigate to the extracted Ventoy directory.
  3. Run the installation script with root privileges, appending the -r option followed by the number of megabytes to preserve: 
    sudo sh Ventoy2Disk.sh -i -r 10240 /dev/sdX
    (Replace 10240 with your desired reserved size in MB and /dev/sdX with your actual USB drive identifier).
  4. Confirm the prompt by typing y to execute the formatting and installation.

Formatting the Reserved Space

Once the installation finishes, the reserved capacity will remain as raw, unallocated space:

  • On Windows: Open Disk Management (diskmgmt.msc), locate your USB drive, right-click the unallocated section at the far right, and select New Simple Volume to format it as NTFS, FAT32, or exFAT.
  • On Linux: Use partition managers like GParted or terminal utilities such as fdisk or parted to create and format a third partition on the unallocated space using your preferred file system.
