Does Ventoy Have an Integrated Checksum Utility?

Ventoy includes a built-in checksum utility that allows users to verify the integrity of ISO and image files directly from the boot menu. This feature supports several industry-standard hashing algorithms, enabling you to detect file corruption or incomplete downloads without needing to reboot into a secondary operating system to run external verification tools.

On-the-Fly Boot Menu Verification

Ventoy provides a native calculation tool built straight into its bootloader interface:

  1. Boot into Ventoy: Insert your Ventoy USB drive and boot your computer from it.
  2. Select the Image: Use the arrow keys to highlight the ISO, IMG, or WIM file you want to check.
  3. Trigger the Checksum Menu: Press the c key on your keyboard.
  4. Select an Algorithm: Ventoy will prompt you to choose a hashing algorithm. It supports:
    • MD5
    • SHA-1
    • SHA-256
    • SHA-512
  5. View the Hash: Ventoy reads the storage block by block, calculates the hash, and displays the result on screen. You can compare this string against the official checksum provided by the operating system vendor.

Automated Verification via the Checksum Plugin

For users who want automated pass/fail verification rather than manually reading hash strings, Ventoy supports a Checksum Plugin configured through a ventoy.json file.

  • Configuration: Create or edit ventoy/ventoy.json on the USB drive.
  • Adding Hashes: Add an entry containing the ISO file path and its official checksum value (along with the algorithm used).
  • Automatic Validation: When you select that ISO in the boot menu, Ventoy automatically calculates the file hash, compares it with the value in ventoy.json, and displays whether the verification passed or failed before launching the installer.

Why This Matters

Storage drives, especially high-capacity USB flash drives, are susceptible to bad sectors, transfer timeouts, and write errors. Utilizing Ventoy's integrated verification guarantees that the installation media is intact, preventing unexpected crashes, missing driver errors, and broken installations during system setup.
