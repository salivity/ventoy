Ventoy GRUB2 Mode Explained

Ventoy is a popular open-source tool used to create bootable USB drives simply by copying ISO files onto the storage device. While Ventoy relies on its proprietary "Normal Mode" by default, it includes an essential fallback mechanism known as GRUB2 mode. This article explains what Ventoy's GRUB2 mode is, how it operates behind the scenes, when you should use it, and its current limitations.

What Is Normal Mode vs. GRUB2 Mode?

To understand GRUB2 mode, you must first understand how Ventoy boots files by default:

  • Normal Mode (Default): Ventoy intercepts the boot process using custom runtime hooks. It creates a virtual disk in system memory to map the ISO file, allowing the operating system installer to see the virtual drive as if it were a physical CD/DVD or raw USB drive.
  • GRUB2 Mode (Secondary Boot): Instead of using Ventoy's custom virtualization hooks, GRUB2 mode utilizes the standard GNU GRUB2 bootloader’s native loopback capabilities. It passes control directly to the boot configuration files pre-packaged inside the ISO itself (such as loopback.cfg or grub.cfg).

Why Does GRUB2 Mode Exist?

Although Ventoy's default hooking mechanism works for thousands of images, it can occasionally fail due to:

  • Unusual kernel configurations or custom initramfs scripts inside the ISO.
  • Strict hardware or firmware quirks in specific UEFI implementations.
  • New or experimental Linux distribution releases that conflict with Ventoy's memory-hooking code.

When Normal Mode results in a black screen, a boot loop, or an error stating that the installation media cannot be found, GRUB2 mode acts as an alternative execution path to launch the file without altering the USB drive.

How GRUB2 Mode Works

When you launch an ISO in GRUB2 mode, the process follows these steps:

  1. Ventoy mounts the target ISO image as a standard loopback device using GRUB2 syntax.
  2. It inspects the ISO for standard GRUB configuration scripts, typically located at /boot/grub/loopback.cfg or /boot/grub/grub.cfg.
  3. Ventoy loads that native configuration file into the active GRUB environment.
  4. Control is handed entirely over to the operating system's internal bootloader menu, bypassing Ventoy's custom initialization scripts.

Because this method relies on standard boot standards created by Linux distribution maintainers, it frequently succeeds where third-party hooks fail.

Limitations of GRUB2 Mode

While highly effective as a recovery option, GRUB2 mode has distinct boundaries:

  • Linux-Centric: It primarily works with Linux distributions that include built-in loopback support (such as Ubuntu, Debian, Fedora, Arch Linux, and Linux Mint).
  • No Windows Support: Standard Windows installation ISOs and WinPE environments do not use GRUB2 configurations and cannot be booted via this mode.
  • Dependency on Upstream Support: If an ISO creator did not include a valid GRUB2 configuration file inside their image, GRUB2 mode will fail to initialize.

How to Boot into GRUB2 Mode

You can launch GRUB2 mode on demand directly from the main Ventoy interface:

  1. Plug in your Ventoy USB drive and boot your computer.
  2. Navigate to the ISO file you want to start.
  3. Press Ctrl + r on your keyboard (or press Enter to open the secondary action menu, depending on your Ventoy theme and version).
  4. Select Boot in GRUB2 mode from the list of options.
