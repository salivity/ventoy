How to Search ISOs in the Ventoy Menu

Managing a large multi-boot drive with dozens of image files can make scrolling through the boot list slow and cumbersome. This article covers the built-in search functionality available directly within the Ventoy boot interface, explaining the dedicated shortcut key, how the query matching works, and how to rapidly filter and launch your desired ISO, WIM, or IMG files.

The Built-in Search Mode (F3)

Ventoy includes a dedicated search utility accessible right from the main boot screen via the F3 hotkey. Instead of manually paging through multiple screens of operating systems and utility images, you can activate this mode to query your drive's contents instantly.

How to Use the Search Function

  1. Boot into Ventoy: Start your computer and boot into your Ventoy USB drive as usual to reach the main menu.
  2. Press F3: Press the F3 key on your keyboard. A text input prompt labeled Search will appear at the bottom of the screen.
  3. Enter Your Query: Type the name—or any part of the name—of the ISO file you wish to locate. The search is case-insensitive, meaning typing "ubuntu", "Ubuntu", or "UBUNTU" will yield the same results.
  4. Execute the Search: Press Enter. Ventoy will immediately filter the list, displaying only the files that contain your search keyword anywhere in the filename.
  5. Boot the Image: Use the arrow keys to highlight your desired image from the filtered results and press Enter to launch it.

Useful Tips for Fast Searching

  • Partial Matching: You do not need to enter full filenames. Entering short strings like win, arch, rescue, or version numbers like 22.04 is enough to narrow down large directories.
  • Return to the Full List: If you want to clear your search and restore the complete list of available images, press Esc or press F3 again with an empty prompt.
  • Combine with Tree View: For users organizing images in complex folder structures, pressing F4 switches between list view and tree view, which can be used in tandem with the search function to locate files across different directories.
