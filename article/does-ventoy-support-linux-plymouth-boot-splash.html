Does Ventoy Support Linux Plymouth Boot Splash?

Ventoy fully supports booting into Linux distributions configured with the Plymouth boot splash screen. Because Ventoy operates primarily as an ISO loader that hands execution over to the distribution's native kernel and initial ramdisk (initramfs), Plymouth functions as intended in most modern distributions, including Ubuntu, Fedora, Debian, and Linux Mint.

How Ventoy Interacts with Plymouth

Ventoy functions at the pre-boot and early-boot environment stages. When you select an ISO from the Ventoy menu, the utility prepares the virtual environment, loads the target distribution’s kernel and initramfs into memory, and initiates execution.

Plymouth is an early-boot multiplexer that takes over display duties once the Linux kernel and initramfs stage begin. Because Ventoy’s primary task is completed once the distribution’s kernel initializes hardware and mounts the root filesystem, it does not interfere with Plymouth’s operation. Plymouth draws its graphical splash screen using the Direct Rendering Manager (DRM) and Kernel Mode Setting (KMS) supplied by the distribution itself.

Common Behaviors and Variations

While Plymouth is natively supported, user experiences can vary depending on hardware configuration, firmware settings, and distribution defaults:

  • UEFI vs. Legacy BIOS: Under modern UEFI configurations, the transition from Ventoy to Plymouth is generally seamless because UEFI retains standard framebuffer resolutions across the boot sequence. On older Legacy BIOS systems, resolution changes between the Ventoy GRUB interface and kernel mode setting may cause a brief black screen or screen flicker before Plymouth appears.
  • Initramfs Integration: Some live distributions disable or truncate the graphical Plymouth splash screen by default on live media to allow users to see early diagnostic output. In these cases, the absence of a splash screen is an intentional design choice of the distribution's live image, not a limitation imposed by Ventoy.
  • Safe Graphics Modes: Selecting "Safe Graphics" or passing the nomodeset boot parameter from the distribution's sub-menu will disable graphical KMS drivers. When this occurs, Plymouth will automatically fall back to its text-based mode, displaying simple progress indicators instead of the graphical logo.

In standard scenarios using mainstream Linux ISOs, booting via Ventoy retains the complete visual boot sequence, including the native Plymouth splash animations and shutdown screens.
