Load Intel VMD Drivers with Ventoy

You can successfully load Intel Volume Management Device (VMD) storage drivers during a Windows installation booted from a Ventoy USB drive. Modern Intel systems—primarily 11th Gen and newer—often enable Intel VMD by default, which causes the Windows setup utility to report that no drives were found. Ventoy allows you to resolve this by either manually loading the extracted drivers from the USB drive during setup or automatically injecting them at boot using Ventoy's native injection plugin.

Method 1: Manual Loading During Setup

This is the simplest method and does not require complex configuration files.

  1. Download the latest Intel Rapid Storage Technology (RST) / VMD driver package (often labeled as "F6 Floppy" drivers) from your motherboard or laptop manufacturer's support page.
  2. Extract the driver contents (specifically looking for the .inf, .sys, and .cat files, including iaStorVD.sys).
  3. Copy the extracted driver folder onto the root or inside a dedicated folder on your Ventoy USB drive. The Windows installer can read files stored on the standard partition of the Ventoy drive alongside your ISOs.
  4. Boot into Ventoy and launch your Windows installation ISO.
  5. Proceed through the setup until you reach the screen asking, "Where do you want to install Windows?"
  6. Click Load driver, then select Browse.
  7. Locate your Ventoy USB drive in the folder list, navigate to your extracted VMD driver folder, and select it.
  8. Choose the detected Intel RST VMD Controller driver and proceed. Your NVMe storage drives will immediately become visible, allowing you to continue the installation.

Method 2: Ventoy Windows Injection Plugin

If you want an automated deployment without clicking "Load driver" each time, use Ventoy's injection plugin.

  1. Create a .7z or .zip archive containing your extracted Intel VMD driver files.
  2. Place the archive in a folder on your Ventoy drive (for example, /ventoy/drivers.7z).
  3. Open or create the ventoy.json configuration file located in the /ventoy/ directory of your USB drive.
  4. Add an injection entry that targets your Windows ISO and points to the driver archive:
{
    "injection": [
        {
            "image": "/Windows_11.iso",
            "archive": "/ventoy/drivers.7z"
        }
    ]
}

When you boot the specified Windows ISO, Ventoy injects the archive into the Windows PE environment before setup loads, allowing Windows to recognize the storage controllers automatically.

Alternative Workaround: Disable VMD in BIOS

If you cannot access the required drivers, you can enter your system's UEFI/BIOS settings and disable Intel VMD Controller (often found under System Configuration, Storage, or VMD Setup Menu). Disabling VMD reverts the storage interface to standard AHCI/NVMe mode, enabling Windows to detect the drives using its built-in generic storage drivers without third-party files.
