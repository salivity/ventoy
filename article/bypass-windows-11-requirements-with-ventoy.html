Bypass Windows 11 Requirements with Ventoy

Ventoy includes a built-in feature that allows users to bypass Windows 11 system requirements, including restrictions for CPU, RAM, TPM 2.0, Secure Boot, and minimum disk space. This article explains how Ventoy handles these hardware checks, what requirements it can bypass, and how to configure the feature to install Windows 11 on unsupported PC hardware without altering the original ISO file.

Does Ventoy Support Bypassing Windows 11 Checks?

Yes. Starting from version 1.0.55, Ventoy introduced native support to bypass Windows 11 installation checks. Instead of requiring you to modify the official Microsoft ISO or execute manual registry commands during installation, Ventoy automatically injects the necessary registry parameters into the Windows setup environment during boot.

What Requirements Does Ventoy Bypass?

When enabled, Ventoy automatically overrides the following Windows 11 pre-installation checks:

  • Processor (CPU): Bypasses the generation and model whitelist enforced by Microsoft.
  • Memory (RAM): Bypasses the minimum requirement of 4 GB of RAM.
  • TPM (Trusted Platform Module): Disables the requirement for TPM 2.0.
  • Secure Boot: Removes the prerequisite for active Secure Boot support.
  • Storage Space: Overrides the minimum 64 GB storage disk requirement.
  • Online Account Requirement: Recent versions also offer options to bypass the mandatory Microsoft account requirement during initial setup (OOBE).

How Ventoy Implements the Bypass

Ventoy modifies the Windows PE (Preinstallation Environment) setup memory table on the fly. It sets specific bypass keys under HKEY_LOCAL_MACHINE\SYSTEM\Setup\LabConfig, including:

  • BypassCPUCheck = 1
  • BypassRAMCheck = 1
  • BypassTPMCheck = 1
  • BypassSecureBootCheck = 1
  • BypassStorageCheck = 1

Because this is done at runtime in memory, the original Windows 11 ISO stored on your USB drive remains completely untouched and verified.

How to Enable the Windows 11 Bypass in Ventoy

In many modern releases of Ventoy, the Windows 11 bypass is enabled globally by default. If you need to manually configure or ensure it is active, you can do so through the ventoy.json configuration file.

Method 1: Using ventoy.json

  1. Open your Ventoy USB drive.
  2. Create a folder named ventoy in the root directory (if it does not already exist).
  3. Inside the ventoy folder, create a text file named ventoy.json.
  4. Add the following JSON structure to bypass the hardware checks:
{
  "control": [
    {
      "VTOY_WIN11_BYPASS_CHECK": "1"
    }
  ]
}

Setting "VTOY_WIN11_BYPASS_CHECK": "1" forces Ventoy to apply the hardware bypass registry keys to any Windows 11 ISO booted from the drive. Setting it to "0" turns the feature off.

Method 2: Using VentoyPlugson (GUI)

  1. Connect your Ventoy drive to your PC.
  2. Run the VentoyPlugson.exe utility provided in the Ventoy download package.
  3. Select your USB drive and click Start.
  4. The tool opens a local browser configuration page.
  5. Navigate to Global Control Plugin and locate the VTOY_WIN11_BYPASS_CHECK setting.
  6. Set the value to 1 and save your changes.

Once configured, simply boot your computer from the Ventoy USB drive, select your standard Windows 11 ISO, and proceed through the installation process on systems that lack supported CPUs, sufficient RAM, or TPM 2.0 chips.
