How the Ventoy Menu Alias Plugin Works

The Ventoy menu alias plugin allows users to replace default, often cryptic image filenames on a multiboot USB drive with clean, human-readable display names in the boot selection menu. By mapping the full path or filename of an ISO, WIM, or IMG file to a custom text string within a configuration file, the plugin creates a polished user interface without requiring users to rename the actual underlying files. This article explains how the plugin operates, the syntax required for configuration, and how to set it up on your Ventoy drive.

The Problem the Plugin Solves

By default, Ventoy lists files in its boot menu using their literal filesystem names (for example, ubuntu-22.04.3-desktop-amd64.iso or Win11_23H2_English_x64v2.iso). Renaming these files directly on disk can break verification scripts, make version tracking difficult, or cause confusion when updating image files. The menu alias plugin acts as a display abstraction layer: the original files stay intact on the storage partition, but the boot interface shows whatever custom text string you define.

The Configuration File: ventoy.json

Ventoy processes plugin configurations through a single JSON file located on the Ventoy data partition (the partition where your ISO files are stored).

To enable aliases:

  1. Navigate to the root directory of your Ventoy USB drive.
  2. Open or create a folder named ventoy.
  3. Inside this folder, create or edit a file named ventoy.json.

All alias mappings are placed within a top-level "menu_alias" JSON array.

JSON Syntax and Structure

The "menu_alias" structure uses key-value pairs where "image" represents the targeted file and "alias" defines the custom label to display.

Here is a standard example:

{
    "menu_alias": [
        {
            "image": "/ISO/ubuntu-22.04.3-desktop-amd64.iso",
            "alias": "Ubuntu 22.04.3 LTS (Desktop)"
        },
        {
            "image": "/ISO/Win11_23H2_English_x64v2.iso",
            "alias": "Windows 11 Pro 64-Bit (Installation)"
        },
        {
            "image": "/WinPE_x64.iso",
            "alias": "Emergency Rescue Environment"
        }
    ]
}

Path Matching Mechanics

The plugin matches files based on the path specified in the "image" field:

  • Full Paths: Specifying a full path starting from the partition root (such as /ISO/Linux/archlinux.iso) ensures that the alias applies strictly to that specific file in that specific location.
  • Relative Paths and Direct Filenames: The path defined must match the file's absolute path relative to the root of the USB drive. Paths are case-sensitive depending on the underlying filesystem, so matching the exact letter case of your folders and filenames is required.
  • Separators: Forward slashes (/) must always be used as directory separators, even when configuring the JSON file on a Windows system.

Advanced Features

  • Multi-Language and Special Characters: The alias string fully supports UTF-8 encoding. You can include spaces, brackets, special characters, and non-English scripts (such as Chinese, Japanese, or Cyrillic characters) in your display names.
  • Display Only: The alias plugin solely affects how items appear in the visual menu. It does not alter the boot arguments, kernel parameters, or how Ventoy mounts and executes the selected file.
  • Fallback Behavior: If an ISO file on the drive is not declared in the ventoy.json alias list, Ventoy simply falls back to displaying its standard filename. If a path declared in the JSON does not exist on the drive, Ventoy ignores that rule without throwing a fatal error.
