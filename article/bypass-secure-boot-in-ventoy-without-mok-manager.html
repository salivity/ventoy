Bypass Secure Boot in Ventoy Without MokManager

This guide explains how to configure a Ventoy USB drive to bypass the Secure Boot MokManager prompt without manually enrolling MOK (Machine Owner Key) certificates. By replacing Ventoy's default shim on the hidden EFI system partition with an alternative, pre-signed Linux bootloader shim, you can boot Ventoy seamlessly on UEFI systems where Secure Boot is enforced.

Why Ventoy Prompts for MokManager

Ventoy uses an open-source shim signed by a standard third-party certificate to comply with UEFI Secure Boot requirements. Because this key is not integrated into your motherboard's factory UEFI database, the system halts at boot and launches MokManager, asking you to enroll the key stored in ENROLL_KEY.DER. Bypassing this step requires replacing the default shim with one that does not enforce custom key enrollment.

Step 1: Reveal the Hidden Ventoy EFI Partition

Ventoy creates two partitions on your USB drive: a large partition for ISO storage (ExFAT/NTFS) and a small, hidden FAT16 partition named VTOYEFI that holds the bootloaders.

On Windows:

  1. Open Command Prompt as Administrator.
  2. Run diskpart.
  3. Type list disk and identify your USB drive number.
  4. Type select disk X (replace X with your USB drive number).
  5. Type list partition.
  6. Identify the small partition (typically around 32MB, labeled System or EFI).
  7. Type select partition 2 (or the corresponding number).
  8. Assign a drive letter by typing: assign letter=Z
  9. Type exit.

On Linux:

  1. Plug in the USB drive and run lsblk to identify the EFI partition (usually /dev/sdX2).
  2. Mount the partition to a temporary directory: 
    sudo mount /dev/sdX2 /mnt

Step 2: Acquire an Unrestricted Signed Shim

To boot directly into Ventoy's GRUB environment without the MOK prompt, you need a signed bootx64.efi file from a Linux distribution (such as Debian or Ubuntu) that chains directly into standard bootloaders without triggering external MOK enrollment screens, or an older signed shim that ignores SBAT restrictions.

  1. Download a pre-compiled, signed EFI shim binary from an official distribution repository (such as the Ubuntu shim-signed package).
  2. Extract the shimx64.efi.signed file.

Step 3: Replace the Ventoy Bootloader

  1. Navigate to the mounted VTOYEFI partition.
  2. Open the EFI/BOOT/ directory.
  3. Locate the original BOOTX64.EFI file and rename it to BOOTX64.EFI.BAK to preserve a backup.
  4. Copy your alternative shimx64.efi.signed file into the EFI/BOOT/ directory and rename it to BOOTX64.EFI.
  5. Ensure grubx64.efi remains in the same directory, as the new shim will automatically load this file upon system startup.

Step 4: Unmount and Test

On Windows:

  1. Open Command Prompt as Administrator and run diskpart.
  2. Type select volume Z (or the letter assigned previously).
  3. Type remove letter=Z.
  4. Type exit.

On Linux:

  1. Unmount the partition: 
    sudo umount /mnt

Reboot your computer and select the Ventoy USB drive from the UEFI boot menu. The drive will execute the signed shim and load directly into the Ventoy ISO selection interface without opening the MokManager key enrollment utility.
