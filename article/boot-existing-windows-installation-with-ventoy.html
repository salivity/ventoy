Boot Existing Windows Installation with Ventoy

Booting an existing physical Windows installation directly from a USB drive using Ventoy requires two key utilities: Microsoft's Disk2vhd to capture the operating system into a virtual disk, and Ventoy's official ventoy_vhdboot script to make the image bootable via Ventoy. Because standard Windows installations lack native drivers to map and boot from a virtual drive stored on a third-party USB filesystem, ventoy_vhdboot injects the necessary driver hooks into the captured VHD/VHDX file, enabling seamless booting through the Ventoy bootloader.

Step 1: Image the Installation with Disk2vhd

Before Ventoy can boot your current Windows environment, you must convert the physical drive into a single virtual hard disk file.

  1. Download and run Disk2vhd from Microsoft Sysinternals.
  2. Select a destination drive that is not the drive being copied (an external drive or secondary internal drive).
  3. Check Use Vhdx if you want faster performance and larger disk capacities, or leave it unchecked for standard .vhd format.
  4. Select the system partition (usually C:) and the required boot/EFI partitions.
  5. Click Create and wait for the image creation process to finish.

Step 2: Prepare the VHD Using ventoy_vhdboot

A raw VHD cloned from a physical machine will typically encounter a blue screen (BSOD) when loaded through Ventoy. The ventoy_vhdboot utility solves this by installing the required boot drivers directly into the offline image.

  1. Download the latest ventoy_vhdboot.zip archive from the official Ventoy release page.
  2. Extract the archive onto your computer.
  3. In Windows Disk Management (diskmgmt.msc), click Action > Attach VHD, locate the .vhd or .vhdx file created by Disk2vhd, and mount it.
  4. Open the extracted ventoy_vhdboot folder, right-click ventoy_vhdboot.bat, and select Run as administrator.
  5. The script automatically detects the mounted VHD volume and installs the required Ventoy hook drivers into its Windows registry and driver store.
  6. Once the script confirms completion, return to Disk Management, right-click the mounted virtual disk, and select Detach VHD.

Step 3: Copy and Boot

  1. Copy the patched .vhd or .vhdx file directly onto your Ventoy-formatted USB drive.
  2. Reboot your computer and access your BIOS/UEFI boot menu.
  3. Select your Ventoy USB drive as the boot device.
  4. Choose the Windows VHD file from the Ventoy menu to launch your Windows installation.
