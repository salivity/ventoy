Resize Ventoy Data Partition Non-Destructively

This article explains how to safely resize the primary data partition on a Ventoy USB drive without losing existing ISO files or breaking boot functionality. While standard operating system utilities often fail due to Ventoy’s specific partition scheme and filesystem formats, dedicated partitioning utilities can alter partition sizes non-destructively. Below, you will discover the best tools for the job, why default tools struggle, and the exact steps to resize your drive safely.

The Best Tool: GParted

The most reliable, open-source tool for non-destructively resizing the main Ventoy data partition is GParted (GNOME Partition Editor). Available natively on Linux distributions or as a standalone bootable live environment, GParted fully supports resizing exFAT, NTFS, and ext4 filesystems—the formats most commonly used by Ventoy—without corrupting stored data.

For users restricted to a Windows environment, third-party software such as DiskGenius or MiniTool Partition Wizard serves as an effective alternative. Windows' built-in Disk Management tool cannot be used because it natively lacks the capability to shrink or expand exFAT filesystems, which Ventoy uses by default.

Understanding the Ventoy Layout

A standard Ventoy drive is divided into two distinct partitions:

  • Partition 1 (Ventoy): Formatted as exFAT by default (or NTFS/ext4). This is the larger partition where bootable ISOs, images, and regular files reside.
  • Partition 2 (VTOYEFI): A small, hidden FAT16 partition (typically around 32MB) located at the very end of the disk that contains the core bootloader files.

To maintain boot integrity, you must never modify, move, or resize Partition 2. Only modify Partition 1.

How to Resize Using GParted

  1. Launch GParted: Open GParted on a Linux system or boot your computer into a GParted Live USB environment.
  2. Select the Device: In the top-right drop-down menu, locate and select your Ventoy USB drive (e.g., /dev/sdb).
  3. Unmount the Partition: Right-click the primary partition (labeled Ventoy or Partition 1) and select Unmount if it is currently mounted.
  4. Resize the Partition:
    • Right-click Partition 1 and select Resize/Move.
    • Drag the right edge of the partition to reduce or enlarge the volume, or enter a specific value in the New size field.
    • If shrinking to create empty space for another partition, ensure the free space is placed after Partition 1 but before Partition 2.
  5. Apply Operations: Click the green checkmark icon in the toolbar (Apply All Operations) to commit the changes.

Resizing on Windows with DiskGenius

If you prefer to stay in Windows:

  1. Download and run DiskGenius.
  2. Select Partition 1 on the Ventoy drive in the left panel.
  3. Right-click the partition and choose Resize Partition.
  4. Adjust the slider to allocate your desired size and click Start.
  5. Allow the program to verify the filesystem and complete the operation without disconnecting the drive.

Once the operation completes, Partition 1 will reflect the new capacity, all preexisting ISO files will remain intact, and Ventoy will boot normally.
