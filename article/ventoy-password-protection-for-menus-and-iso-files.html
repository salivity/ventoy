Ventoy Password Protection for Menus and ISO Files

Ventoy fully supports password protection for both the entire boot menu and individual ISO files. By using the tool's plugin system via a simple JSON configuration file, you can lock down your multiboot USB drive to prevent unauthorized booting. Whether you need a global lock on the bootloader or selective restrictions on sensitive rescue discs and operating system images, Ventoy allows you to enforce access controls using either plain text or encrypted SHA-256 password hashes.

Global Password Protection (Entire Boot Menu)

To lock the entire boot interface, Ventoy uses a global password parameter. When configured, the boot menu will not display any boot options until the user enters the correct password.

To set this up, create a folder named ventoy in the root directory of your USB drive (the main partition where you store ISOs) and create a file inside it named ventoy.json. Use the control configuration section to define the password:

{
    "control": [
        { "password": "YourGlobalPassword" }
    ]
}

When you boot the drive, Ventoy will immediately prompt you for the password before granting access to any menus or features.

Individual ISO Password Protection

If you want the main menu to be publicly accessible while restricting specific images—such as administrative tools, proprietary installers, or enterprise Windows images—you can assign passwords to individual files.

This is done using the image_password array in the same ventoy.json file. You define the exact relative path to the ISO file and assign a dedicated password to it:

{
    "image_password": [
        {
            "image": "/ISO/admin-rescue-tool.iso",
            "password": "RescuePassword123"
        },
        {
            "image": "/Windows/win11_enterprise.iso",
            "password": "WinEnterprisePass"
        }
    ]
}

With this configuration, users can view all files in the Ventoy menu, but selecting a locked ISO will trigger an authentication prompt before it begins the boot sequence.

Enhancing Security with Hashed Passwords

Storing passwords in plain text inside ventoy.json is a security risk because anyone who plugs the USB into a running operating system can read the file. Ventoy mitigates this by supporting standard SHA-256 password hashes.

Instead of typing the plain password, you can generate a SHA-256 hash using a terminal or online utility and insert the hash directly into the configuration prefixed by the hash algorithm:

{
    "control": [
        { "password": "sha256:5e884898da28047151d0e56f8dc6292773603d0d6aabbdd62a11ef721d1542d8" }
    ]
}

The hash format works identically for both global menu protection and individual ISO file protection, ensuring that even if the configuration file is viewed, the actual password remains protected.
