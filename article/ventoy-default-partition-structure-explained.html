Ventoy Default Partition Structure Explained

When installing Ventoy to a target storage drive, it automatically configures a specialized two-partition layout using the Master Boot Record (MBR) partition scheme by default. This article details the structure, file systems, and functions of these default partitions, explaining how they enable direct booting of ISO, WIM, and IMG files while maintaining standard USB storage functionality.

The Default Two-Partition Architecture

By default, Ventoy wipes the destination device and divides it into two distinct partitions regardless of the drive's total capacity:

Partition 1: The Main Data Partition

  • Label: Ventoy
  • File System: exFAT
  • Size: Spans almost the entire capacity of the storage device (total drive size minus 32 MB).
  • Visibility: Visible in all operating systems as a standard removable drive.
  • Purpose: This partition is where users place bootable images, including ISO, WIM, VHD, and EFI files. Because it is formatted with exFAT out of the box, it supports files larger than 4 GB, accommodating modern operating system installers. Users can safely store personal files and documents here alongside boot images without interfering with Ventoy's operation. If needed, this partition can be manually reformatted to NTFS, FAT32, ext4, or Btrfs without breaking Ventoy functionality.

Partition 2: The EFI System Partition

  • Label: VTOYEFI
  • File System: FAT16 (or FAT32 depending on specific configuration)
  • Size: Fixed at 32 MB located at the very end of the drive.
  • Visibility: Hidden by default in Windows to prevent accidental modification or deletion.
  • Purpose: This partition contains the core boot files, including GRUB bootloaders, EFI binaries, and drivers required to initialize the Ventoy environment. It supports both legacy BIOS and UEFI boot modes (including Secure Boot support).

Why Ventoy Uses This Specific Layout

  1. UEFI Compliance: UEFI firmware requires boot files to reside on a FAT-formatted partition. Because FAT partitions often impose file size limits (such as FAT32's 4 GB maximum), separating the boot environment into its own small FAT partition allows the main data partition to use exFAT or NTFS for large OS images.
  2. System Integrity: Isolating the bootloader in a protected, dedicated partition prevents users and automated cleanup tools from corrupting or accidentally deleting vital boot files when managing ISO images.
  3. Partition Scheme Flexibility: While MBR is applied by default to ensure maximum backward compatibility with older legacy BIOS systems, Ventoy also provides an option during installation to switch the underlying partition table to GPT (GUID Partition Table) while keeping the same two-partition structure.
