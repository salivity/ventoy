Where to Put GRUB Themes in Ventoy

Customizing the boot appearance in Ventoy requires placing your GRUB theme files within a dedicated folder structure on the drive's main partition and linking them via a configuration file. This guide outlines the exact directory hierarchy required by Ventoy, how to structure your theme files, and how to properly register them using ventoy.json so your custom bootloader interface loads correctly.

The Correct Partition

When you prepare a USB drive with Ventoy, it splits the drive into two partitions:

  1. Partition 1 (Ventoy): The large data partition formatted as exFAT, NTFS, or ext4, where you store ISO files.
  2. Partition 2 (VTOYEFI): A small, hidden FAT partition containing the core bootloader files.

All custom GRUB themes, configuration files, and assets must be placed on Partition 1 (the data partition), never on Partition 2.

Ventoy Directory Hierarchy

At the root level of Partition 1, create a folder named ventoy (all lowercase). Inside the ventoy directory, create a subfolder called themes or theme to store your extracted GRUB theme packages.

The directory tree should look like this:

[USB Root] (Partition 1)
│
└── ventoy/
    ├── ventoy.json
    └── themes/
        └── my-custom-theme/
            ├── theme.txt
            ├── background.png
            ├── icons/
            └── fonts/

Inside your specific theme directory (e.g., my-custom-theme), ensure the core theme.txt file and its accompanying assets (fonts, icons, and background images) are present.

Activating the Theme via ventoy.json

Ventoy does not automatically detect GRUB themes simply by placing them in the folder; you must specify the path in a configuration file named ventoy.json, located directly inside the /ventoy/ directory.

Create or edit /ventoy/ventoy.json with the following structure:

{
    "theme": {
        "file": "/ventoy/themes/my-custom-theme/theme.txt",
        "gfxmode": "1920x1080"
    }
}

Key configuration details:

  • file: Defines the absolute path to theme.txt relative to the root of Partition 1. Forward slashes (/) must be used.
  • gfxmode: Optional. Sets the screen resolution for the GRUB menu (e.g., 1920x1080, 1366x768, or 1024x768) to prevent scaling or distortion issues.

Case Sensitivity Warning

Ventoy's underlying environment is Linux-based and case-sensitive. Ensure that the folder names, file names, and the paths defined in ventoy.json match their real filesystem counterparts exactly. Using lowercase for directory names like ventoy and themes prevents common path-resolution errors during boot.
