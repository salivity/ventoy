Does Ventoy Support PXE Booting Raw ISO Images?

Ventoy does support booting raw ISO images over a local area network (LAN) using Preboot Execution Environment (PXE). While standard Ventoy is primarily recognized as a tool for creating bootable USB drives, its ecosystem provides direct network booting capabilities without requiring you to extract or modify the original ISO files. This is achieved either through the built-in PXE server functionality inside traditional Ventoy or via its dedicated network boot utility, iVentoy.

Native Ventoy PXE Mode

Standard Ventoy includes a local PXE feature. When you boot a machine using a Ventoy USB drive, you can press F5: Tools and select the PXE option to start an integrated PXE server directly from that computer.

Once activated:

  • The host machine serves as a temporary DHCP and TFTP server on your local network.
  • Target client machines configured to boot from LAN can connect directly to the host machine.
  • The target machines will load the Ventoy menu over the network and can boot from the raw ISO files stored on the host's Ventoy USB drive.

The Dedicated Network Tool: iVentoy

For dedicated network deployments without relying on a physical USB drive plugged into a client, the developer of Ventoy created iVentoy.

iVentoy functions as an enhanced PXE server software that runs on Windows or Linux:

  • Direct ISO Storage: You place raw ISO files into a single directory on the server machine.
  • No Extraction Required: Like standard Ventoy, iVentoy mounts and streams raw ISOs directly across the network using HTTP or NBD (Network Block Device).
  • Cross-Architecture Support: It supports both x86 Legacy BIOS and modern UEFI (IA32, x86_64, and ARM64) clients simultaneously.
  • Flexible DHCP Integration: It can run its own integrated DHCP server or operate as a DHCP proxy alongside an existing router or enterprise DHCP server.

How Network ISO Booting Works

When a client initiates a network boot:

  1. The client receives network boot instructions via PXE/TFTP.
  2. iVentoy transfers an iPXE kernel to the client machine.
  3. The client loads the familiar Ventoy graphical interface showing all ISO images available on the host machine.
  4. When an image is selected, the raw ISO is streamed over the local network into the client's memory or loaded via network block hooks, allowing the OS installer or live environment to run as if booted from physical media.

Requirements and Limitations

  • Network Bandwidth: Booting raw ISOs over the network requires substantial bandwidth. A wired Gigabit Ethernet (1000 Mbps) connection is strongly recommended for responsive boot times.
  • Installer Quirks: Most Linux live distributions, WinPE environments, and standard Windows installers boot seamlessly. However, certain specialized operating system installers may attempt to look for physical CD/USB media during the second phase of installation and may require driver injection or network repository paths to finish installing.
