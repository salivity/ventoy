Fix Windows XP 0x0000007B BSOD in Ventoy

Booting a Windows XP installation ISO through Ventoy frequently results in the infamous Blue Screen of Death (BSOD) with error code 0x0000007B (INACCESSIBLE_BOOT_DEVICE). This article breaks down the technical reasons behind this error—specifically the lack of modern storage drivers in Windows XP and the loss of virtual drive access during setup—and details the exact steps required to resolve the issue and complete installation.

1. Missing AHCI and SATA Drivers

The primary cause of error 0x0000007B is Windows XP's age. When Windows XP was released in 2001, Parallel ATA (IDE) was the industry standard. Consequently, the standard Windows XP installation media does not include native drivers for modern Serial ATA (SATA) controllers operating in AHCI (Advanced Host Controller Interface) or RAID modes.

When the text-mode phase of Windows XP setup initializes, it attempts to load drivers to communicate with the system's storage controllers. When it fails to find a compatible driver for the active SATA controller, it cannot access the drive and immediately triggers the 0x0000007B stop error.

2. Loss of the Virtual CD-ROM Emulation (Hook Loss)

Ventoy uses BIOS interrupt calls (such as INT 13h) to map the ISO file into system memory as a virtual CD-ROM drive. While this mechanism works seamlessly during the initial boot sequence in 16-bit Real Mode:

  • Windows XP Setup transitions from 16-bit Real Mode to 32-bit Protected Mode early in the installation process.
  • During this transition, setup stops using BIOS interrupts and switches exclusively to its internal 32-bit hardware drivers.
  • Because Windows XP does not natively understand Ventoy’s virtual drive mapping, the installation media disappears from the operating system's perspective.
  • Setup cannot locate the necessary source files to continue, which presents as an inaccessible boot device (0x0000007B).

How to Fix the Error

Switch SATA Mode to IDE in BIOS/UEFI

  1. Enter your computer's BIOS/UEFI firmware settings.
  2. Locate the SATA Configuration, SATA Mode, or Storage Configuration setting.
  3. Change the mode from AHCI or RAID to IDE, Compatible, or Legacy.
  4. Save changes and restart the setup via Ventoy.

Slipstream SATA/AHCI Drivers into the ISO

If your motherboard lacks an IDE compatibility mode:

  1. Obtain the specific SATA/AHCI drivers (F6 drivers) for your motherboard's chipset.
  2. Use an image customization tool such as nLite to slipstream these drivers directly into your Windows XP installation ISO.
  3. Replace the ISO on your Ventoy drive with the newly created, driver-integrated image.

Use DriverPacks and Virtual Disk Drivers

To address the loss of Ventoy's virtual ISO mount in Protected Mode:

  • Use a Windows XP image that includes Firadisk or WinVBlock drivers. These RAM-disk drivers preserve the ISO mapping throughout the Protected Mode transition.
  • Alternatively, integrate the DriverPacks Mass Storage pack into your installation ISO, which provides broad compatibility with various storage controllers and virtual drives out of the box.
