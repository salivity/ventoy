Boot Clonezilla with Automated Script via Ventoy

Automating Clonezilla workflows using Ventoy allows administrators to run unattended backup and restore operations without modifying the original Clonezilla ISO. By taking advantage of Ventoy's custom GRUB configuration capability and Clonezilla's native kernel boot parameters, you can mount storage partitions, execute custom deployment scripts, and bypass manual interactive prompts entirely.

1. Prepare the Automation Script

Create a shell script containing the Clonezilla commands you want to execute automatically.

  1. Create a script named custom-ocs.sh (or any preferred name).
  2. Add your automated imaging commands. For example, a basic restore command: 
    #!/bin/bash
# Mount the target image directory if not already mounted
ocs-sr -g auto -e1 auto -e2 -c -r -j2 -p poweroff restoredisk my-image sda
  3. Save the script onto the main Ventoy data partition (for example, in a folder named scripts/).

2. Identify the Required Clonezilla Boot Parameters

Clonezilla Live relies on specific kernel parameters passed at boot time to automate operations:

  • locales="en_US.UTF-8": Sets the language and suppresses the language selection prompt.
  • keyboard-layouts="NONE" or keyboard-layouts="en": Suppresses keyboard layout selection.
  • ocs_live_batch="yes": Runs Clonezilla in batch mode (suppresses interactive user prompts).
  • ocs_prerun: Runs arbitrary shell commands before the main Clonezilla task. Multiple prerun entries can be chained (ocs_prerun1, ocs_prerun2, etc.) to mount partitions or download network resources.
  • ocs_live_run: Defines the primary command or script path executed once the live environment loads.

3. Create a Custom Ventoy Boot Menu

Ventoy allows you to add custom GRUB menu entries via a ventoy_grub.cfg file. This prevents the need to unpack or repack the Clonezilla ISO.

  1. In the root of your Ventoy USB drive, create a folder named ventoy if it does not already exist.
  2. Inside the ventoy folder, create a file named ventoy_grub.cfg.
  3. Add a custom menu entry configured to loopback boot the Clonezilla ISO and inject your script parameters:
menuentry "Clonezilla Automated Restore" --class clonezilla {
    set isopath="/clonezilla-live.iso"
    
    # Search for the drive containing the ISO
    search --no-floppy --file --set=root $isopath
    
    # Mount the ISO via loopback
    loopback loop $isopath
    
    # Load kernel with automation arguments
    linux (loop)/live/vmlinuz boot=live union=overlay username=user config components quiet noswap edd=on nomodeset enforcing=0 locales=en_US.UTF-8 keyboard-layouts=NONE ocs_prerun="mount /dev/disk/by-label/Ventoy /mnt" ocs_live_run="/mnt/scripts/custom-ocs.sh" ocs_live_batch="yes" findiso=$isopath
    
    # Load the initial ramdisk
    initrd (loop)/live/initrd.img
}

Note: Replace /clonezilla-live.iso with the exact path and file name of the ISO on your Ventoy drive, and ensure /dev/disk/by-label/Ventoy matches the partition label of your USB drive.

4. Boot and Run the Automation

  1. Insert the Ventoy USB drive into the target computer and boot into Ventoy.
  2. At the main Ventoy boot menu, press F6 to switch to the custom menu defined by ventoy_grub.cfg.
  3. Select your automated entry (e.g., Clonezilla Automated Restore).
  4. The system will boot the live environment, mount the storage partition specified in ocs_prerun, execute your script via ocs_live_run, and perform the defined tasks automatically.
