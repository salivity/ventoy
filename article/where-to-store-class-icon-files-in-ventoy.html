Where to Store Class Icon Files in Ventoy

When customizing Ventoy's boot menu using the class plugin, icon graphic files are stored directly inside the active theme's icons directory on your USB drive's first partition. By default, Ventoy associates classes defined in the ventoy.json configuration file with corresponding PNG images placed in /ventoy/theme/<theme_name>/icons/. This guide explains the precise file paths, naming conventions, and setup requirements needed to ensure your custom icons display correctly.

The Icon Storage Path

Ventoy does not store class icons in an isolated plugin directory. Instead, it reads them directly from the active GRUB theme.

To store and use custom class icons:

  1. Navigate to the root of the first partition (the partition where your ISO files are stored).
  2. Open or create the ventoy folder: /ventoy/
  3. Locate your active theme directory inside the theme folder. The standard path is: /ventoy/theme/<your_theme_name>/icons/

Place your graphic files directly into this icons subfolder.

File Format and Naming Requirements

For Ventoy to properly link an icon to an operating system or ISO, the graphic file must strictly match the class defined in your configuration:

  • File Format: Files must be in .png format. Transparent backgrounds are recommended to blend seamlessly with the theme's menu style.
  • Dimensions: Standard icon dimensions are typically 32x32 pixels, though some themes support 48x48 or larger resolutions depending on the theme's theme.txt specification.
  • Naming Convention: The file name must match the class name assigned to the image: <class_name>.png.

For example, if your class is named ubuntu, the image file must be named ubuntu.png and placed at /ventoy/theme/<your_theme_name>/icons/ubuntu.png.

Configuring Classes in ventoy.json

To bind the icon to a specific ISO or WIM file, reference the matching class in /ventoy/ventoy.json under the menu_class plugin:

{
    "menu_class": [
        {
            "key": "ubuntu-22.04.iso",
            "class": "ubuntu"
        },
        {
            "key": "Win11_English_x64.iso",
            "class": "windows"
        }
    ]
}

In this setup:

  • Ventoy looks for /ventoy/theme/<your_theme_name>/icons/ubuntu.png for the Ubuntu entry.
  • Ventoy looks for /ventoy/theme/<your_theme_name>/icons/windows.png for the Windows entry.

If a custom theme is not defined, Ventoy relies on its internal default theme, which cannot be modified in place. To use custom class icons, you must define and load a custom theme path in ventoy.json using the theme plugin pointing to your custom theme directory containing the icons/ folder.
