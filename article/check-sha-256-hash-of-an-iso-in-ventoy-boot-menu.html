Check SHA-256 Hash of an ISO in Ventoy Boot Menu

Verifying the integrity of an operating system image ensures that the file is not corrupted or tampered with before installation. Ventoy includes a native checksum feature that allows you to calculate and verify the SHA-256 hash of any ISO file directly from the boot screen, eliminating the need to pre-check the file inside an operating system. This guide walks you through accessing the checksum tool and verifying your image directly from the Ventoy menu.

Prerequisites

Ensure your Ventoy USB drive is updated to version 1.0.86 or later, as direct checksum calculation from the boot menu was introduced in this release.

Steps to Check the SHA-256 Hash

  1. Boot into Ventoy
    Insert your Ventoy USB drive into your PC and boot into the main Ventoy interface via your system's boot menu.

  2. Select the ISO File
    Use the arrow keys to navigate the list and highlight the ISO file you want to verify.

  3. Open the Secondary Menu
    Press m or press Enter to bring up the file's secondary action menu. This menu displays launch options such as Normal mode, GRUB2 mode, and Checksum.

  4. Choose the Checksum Option
    Highlight Checksum from the list and press Enter.

  5. Select SHA-256
    Ventoy will display a list of supported hashing algorithms (such as MD5, SHA1, SHA256, and SHA512). Select SHA256 and press Enter.

  6. View the Calculated Hash
    Ventoy will read the ISO file from your storage media and display a progress indicator. Once reading is complete, the calculated SHA-256 string will appear on the screen. Compare this string to the official hash provided by the software distributor to confirm the integrity of the image.

Automatic Hash Verification (Optional)

If you place a matching .sha256 text file in the same directory as the ISO on your USB drive (using the exact same filename prefix, for example ubuntu.iso and ubuntu.iso.sha256), Ventoy will automatically compare the calculated value against the file's contents and display a green match confirmation directly on the screen.
