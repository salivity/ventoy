How to Chainload Custom GRUB Menu in Ventoy

This guide explains how to integrate and chainload a custom GRUB menu alongside your default Ventoy installation. By utilizing Ventoy’s native configuration injection features, you can launch custom GRUB configurations, chainload standalone EFI bootloaders, or define advanced boot parameters without overwriting the automated ISO detection mechanism of standard Ventoy.

Step 1: Access the Ventoy Data Partition

Insert your Ventoy USB drive into your computer and mount the primary data partition (usually labeled Ventoy, formatted as ExFAT, NTFS, or ext4). This is the partition where you normally store your ISO and image files, not the hidden VTOYEFI boot partition.

Step 2: Create the Ventoy Configuration Directory

Navigate to the root directory of the Ventoy partition. If it does not already exist, create a folder named ventoy (all lowercase):

mkdir -p /path/to/ventoy-drive/ventoy

Step 3: Create the Custom GRUB Configuration File

Ventoy looks for a specific file named ventoy_grub.cfg inside the ventoy directory. When this file is present, Ventoy automatically displays an F6 prompt at the bottom of the main menu to switch to your custom GRUB configuration.

Create a text file at /ventoy/ventoy_grub.cfg using a text editor.

Step 4: Configure the Chainload Entries

Inside /ventoy/ventoy_grub.cfg, you can either source another existing GRUB configuration file or chainload an external EFI binary.

Option A: Sourcing an External grub.cfg

To load a separate GRUB menu located on the same drive or another partition, use the configfile directive:

menuentry "Load Custom GRUB Menu" --class custom {
    # Set the root to the partition containing your custom grub.cfg
    # Example: partition 1 on the current drive
    search --no-floppy --set=root --file /boot/grub/grub.cfg
    configfile /boot/grub/grub.cfg
}

menuentry "Return to Ventoy Main Menu" --class vtoy {
    echo "Returning to Ventoy..."
    vtoy_return
}

Option B: Chainloading a Custom GRUB EFI Binary

If you compiled a custom GRUB EFI executable (such as grubx64.efi) and placed it on the partition, load it directly using chainloader:

menuentry "Chainload Custom GRUBx64.efi" --class efi {
    search --no-floppy --set=root --file /EFI/custom/grubx64.efi
    chainloader /EFI/custom/grubx64.efi
}

menuentry "Return to Ventoy Main Menu" --class vtoy {
    vtoy_return
}

Step 5: Test the Configuration

  1. Safely unmount and reboot your computer into the Ventoy USB drive.
  2. At the main Ventoy boot interface, observe the bottom menu bar where an F6 Custom Menu option will appear.
  3. Press F6 to exit the automated list and display your custom GRUB menu.
  4. Select your custom entry to chainload the secondary GRUB installation.
