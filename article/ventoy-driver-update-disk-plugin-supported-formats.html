Ventoy Driver Update Disk Plugin Supported Formats

The Ventoy Driver Update Disk (DUD) plugin allows users to supply custom hardware drivers to operating system installers directly during the boot process. This guide provides a straightforward breakdown of the specific file formats accepted by the Ventoy DUD plugin, explaining how these images are handled and how to configure them for seamless OS installations.

Accepted File Formats

The Ventoy DUD plugin primarily accepts standard raw image formats and compressed archives that Linux and other OS installation media recognize as driver sources. The supported formats are:

  • .iso (Optical Disc Images): Standard ISO-9660 image files containing the vendor-supplied driver structure. Installers recognize these as virtual CD/DVD media containing driver packages.
  • .img (Raw Disk Images): Uncompressed sector-by-sector disk or floppy images. These are commonly provided by hardware vendors (such as storage or network controller manufacturers) for legacy and modern installer environments.
  • .gz or .img.gz (Gzip Compressed Images): Compressed raw disk images. Ventoy can load .gz compressed images directly, reducing storage overhead on the USB drive while retaining compatibility with the installer's memory-decompression routines.

How the Plugin Uses These Formats

Operating system installers—most notably Linux distributions like Red Hat Enterprise Linux (RHEL), CentOS, Rocky Linux, SUSE Linux Enterprise Server (SLES), and openSUSE—require drivers to be presented in standardized block devices or filesystem layouts.

When you boot an installation medium through Ventoy, the DUD plugin injects the specified .iso, .img, or .img.gz file into memory. The OS installer then mounts this virtual device, identifies the OEM driver repository, and loads the required kernel modules before attempting to access hard disks, RAID arrays, or network interfaces.

Configuration Overview

Driver Update Disks are mapped using the ventoy.json configuration file located in the ventoy folder of your USB drive. Within the "dud" array, you define the path to your target installation ISO and link it to the driver update file format of your choice:

{
    "dud": [
        {
            "image": "/ISO/rhel-8.5-x86_64-dvd.iso",
            "dud": "/ISO/driver-update.img"
        },
        {
            "image": "/ISO/SLES-15-SP3-DVD-x86_64.iso",
            "dud": "/ISO/megaraid_driver.iso"
        }
    ]
}

Ensure the file extension matches the actual structure of the file (uncompressed .img or .iso, or gzip-compressed .gz) to allow Ventoy to correctly emulate the driver device during boot.
