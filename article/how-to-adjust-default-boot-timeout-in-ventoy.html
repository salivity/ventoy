How to Adjust Default Boot Timeout in Ventoy

Ventoy is a popular open-source utility used to create multiboot USB drives by simply dragging and dropping ISO files onto the storage device. By default, Ventoy's boot menu may wait indefinitely for user interaction or use a preset countdown before launching a selection. This guide explains how to change the countdown duration or disable the boot timeout entirely using Ventoy's built-in JSON configuration system.

Step 1: Create the Ventoy Directory

Ventoy stores all custom configurations in a dedicated folder on the USB drive.

  1. Connect your Ventoy USB drive to your computer.
  2. Open the main partition of the USB drive (the partition where your ISO files are stored).
  3. Check if a folder named ventoy exists in the root directory. If it does not exist, create a new folder and name it ventoy (use all lowercase letters).

Step 2: Create or Edit the ventoy.json File

Configuration settings are read from a file named ventoy.json.

  1. Open the ventoy folder.
  2. Look for a file named ventoy.json. If it does not exist, create a new text file and rename it to ventoy.json (ensure the file extension is .json and not .txt).
  3. Open ventoy.json in any text editor, such as Notepad, VS Code, or nano.

Step 3: Configure the Timeout Value

The boot menu timeout is defined using the timeout option inside the control section.

Add the following code to your ventoy.json file:

{
    "control": [
        {
            "timeout": 10
        }
    ]
}

Timeout Value Rules:

  • Any positive integer (e.g., 10): Sets the countdown in seconds. In the example above, Ventoy will wait 10 seconds before automatically booting the default or first menu item.
  • 0: Disables the countdown timer completely. Ventoy will pause indefinitely until you manually select an option and press Enter.

Step 4: Save and Test

  1. Save the changes to ventoy.json and close your text editor.
  2. Safely eject the USB drive from your computer.
  3. Reboot your system and boot from the Ventoy USB drive to verify that your new timeout setting is applied.
