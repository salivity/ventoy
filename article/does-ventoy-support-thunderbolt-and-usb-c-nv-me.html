Does Ventoy Support Thunderbolt and USB-C NVMe?

Ventoy fully supports booting from external USB-C and Thunderbolt NVMe enclosures, but your overall success depends primarily on your computer’s motherboard firmware rather than Ventoy itself. Because Ventoy operates as an OS-agnostic bootloader installed directly to the drive's partitions, it can run on any storage medium that the host system's UEFI or BIOS detects at startup. However, differences between USB and PCIe protocols introduce specific compatibility factors you must account for when attempting to boot.

How Ventoy Interacts with NVMe Enclosures

Ventoy formats external drives with a standard MBR or GPT layout containing an EFI system partition and an exFAT or NTFS data partition for your ISO files. To Ventoy, an external NVMe enclosure is simply another mass storage target. Once installed, it provides full read and write speeds to your NVMe drive, allowing operating system installers and live environments to load significantly faster than from traditional flash drives.

USB-C Enclosures (UASP / USB 3.x)

Standard USB-C enclosures that utilize bridge chips (such as Realtek, ASMedia, or JMicron) present the NVMe drive to the host computer as a standard USB mass storage device using the USB Attached SCSI Protocol (UASP).

  • Compatibility: Nearly universal on modern computers.
  • Firmware Support: Virtually all modern UEFI and legacy BIOS systems can enumerate USB mass storage devices during Power-On Self-Test (POST).
  • Behavior: The system recognizes the drive immediately, loads the Ventoy menu, and boots target ISOs without extra configuration.

Thunderbolt Enclosures (PCIe Tunneling)

True Thunderbolt 3 and Thunderbolt 4 enclosures tunnel PCIe lanes directly to the NVMe drive rather than translating the connection into USB mass storage. This introduces firmware-level hurdles:

  • Pre-Boot Enumeration: Many PC motherboards do not load Thunderbolt controllers during POST to speed up boot times or maintain hardware security. If the motherboard does not enumerate PCIe devices over Thunderbolt before loading the operating system, it cannot detect Ventoy.
  • Security Levels and DMA Protection: Thunderbolt security features, such as Kernel DMA Protection, can block external PCIe storage execution in pre-boot environments.
  • Dual-Protocol Enclosures: Newer enclosures using bridge controllers like the Intel JHL7440 or ASMedia ASM2464PD support both Thunderbolt and USB fallback. If a host system fails to boot via Thunderbolt, these enclosures fall back to standard USB protocol, allowing Ventoy to boot successfully.

Key BIOS Settings for Reliable Booting

To ensure your system boots Ventoy from an external NVMe enclosure:

  1. Disable Fast Boot: Allows the UEFI firmware enough time to detect and initialize external controllers and enclosures.
  2. Enable External Device Boot: Verify that external USB and Thunderbolt storage devices are allowed as valid boot targets in the boot priority list.
  3. Adjust Thunderbolt Security: If using a dedicated Thunderbolt enclosure, set the Thunderbolt security level in your BIOS to "No Security" or ensure external PCIe pre-boot authorization is enabled.
  4. Disable Secure Boot (If Required): While Ventoy supports Secure Boot, certain custom ISOs or modified enclosures may require Secure Boot to be temporarily disabled.
