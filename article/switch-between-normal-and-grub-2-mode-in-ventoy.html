Switch Between Normal and GRUB2 Mode in Ventoy

This guide explains how to switch between Normal Mode and GRUB2 Mode in Ventoy, a crucial troubleshooting step when an operating system ISO fails to boot properly. You will learn the keyboard shortcuts to toggle modes dynamically at boot time, how to select boot modes from the ISO action menu, and how to set a default mode permanently using the Ventoy configuration file.

Method 1: Using the ISO Action Menu

The most direct way to select a boot mode is through the interactive menu when launching an image.

  1. Boot your computer from the Ventoy USB drive.
  2. Use the arrow keys to navigate the list and highlight the ISO file you want to boot.
  3. Press Enter.
  4. A secondary options menu will appear on the screen.
  5. Select Boot in grub2 mode (or Boot in normal mode if it is already running in GRUB2) and press Enter.

Method 2: Using the Keyboard Shortcut (Hotkey)

Ventoy includes a hotkey to switch the global boot mode directly from the main list interface before selecting an image.

  1. On the main Ventoy boot screen, look at the bottom status bar for hotkey prompts.
  2. Press Ctrl + r on your keyboard.
  3. The interface will refresh, and a text indicator (such as [Grub2]) will appear in the lower-left or top section of the screen, confirming that GRUB2 mode is active.
  4. Select your ISO and press Enter to launch it directly in GRUB2 mode.
  5. To switch back, press Ctrl + r again to return to Normal Mode.

Method 3: Setting GRUB2 Mode Permanently via ventoy.json

If a specific ISO consistently requires GRUB2 mode, you can configure Ventoy to always launch that file in GRUB2 mode automatically.

  1. Plug the Ventoy USB drive into a running operating system.
  2. Open the primary partition of the USB drive (where your ISO files are stored).
  3. Create a folder named ventoy if it does not already exist.
  4. Inside the ventoy folder, create or edit a file named ventoy.json.
  5. Add the image_list configuration to specify the default boot mode:
{
    "control": [
        {
            "image": "/ISO/ubuntu-22.04.iso",
            "mode": "grub2"
        }
    ]
}

Replace /ISO/ubuntu-22.04.iso with the exact relative path to your ISO file. Save the file and restart your computer to apply the permanent configuration.
