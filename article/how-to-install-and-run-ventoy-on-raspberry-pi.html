How to Install and Run Ventoy on Raspberry Pi

Ventoy can be compiled and installed on a Raspberry Pi, provided the board is running a 64-bit operating system (ARM64/aarch64). While Ventoy is primarily known as a PC tool, official ARM64 support allows users to execute the installer on a Raspberry Pi to prepare multi-boot USB flash drives, or build the entire project from source using the appropriate compilation toolchains.

Running Precompiled Ventoy on Raspberry Pi

The fastest and most reliable way to use Ventoy on a Raspberry Pi is using the official Linux distribution, which includes precompiled ARM64 binaries.

Requirements

  • A Raspberry Pi 3, 4, 5, or Zero 2 W.
  • A 64-bit OS such as Raspberry Pi OS (64-bit) or Ubuntu Server/Desktop (aarch64).
  • A USB flash drive.

Installation Steps

  1. Download the latest ventoy-x.x.xx-linux.tar.gz archive from the official Ventoy release repository.
  2. Open a terminal and extract the archive: 
    tar -xvf ventoy-*-linux.tar.gz
cd ventoy-*
  3. Identify your target USB drive name using lsblk (e.g., /dev/sdb).
  4. Execute the installation script using root privileges: 
    sudo ./Ventoy2Disk.sh -i /dev/sdX
    (Replace /dev/sdX with the identifier of your target USB drive).
  5. Alternatively, launch the graphical web interface directly on your Pi: 
    sudo ./VentoyWeb.sh
    Open a browser and navigate to http://127.0.0.1:2460 to configure and format the drive.

Compiling Ventoy from Source on Raspberry Pi

Compiling Ventoy directly on a Raspberry Pi requires substantial system resources and a 64-bit environment.

Prerequisites

Install the core development packages and dependencies:

sudo apt update
sudo apt install -y git build-essential gcc-aarch64-linux-gnu bison flex libelf-dev libssl-dev bc

Build Process

  1. Clone the official repository and its submodules: 
    git clone --recurse-submodules https://github.com/ventoy/Ventoy.git
cd Ventoy
  2. Navigate to the build directory. Ventoy relies on several sub-components, including custom builds of GRUB, dynamic libraries, and tool binaries: 
    cd INSTALL
  3. Execute the build scripts corresponding to the Linux target architecture. Building all embedded components (such as GRUB2 and EDK2 packages) locally on a Raspberry Pi requires configuring swap memory (at least 4 GB) to prevent out-of-memory errors during linking.

Due to the complex interdependencies involving custom toolchains and x86 cross-compilation targets within the repository, official developers typically cross-compile Ventoy using Docker containers on x86_64 host machines. However, the Linux installer utilities (Ventoy2Disk, VentoyWeb) can be compiled natively on ARM64 without issues.

Important Distinction: Creating Drives vs. Booting the Pi

  • Creating Drives (Supported): Using a Raspberry Pi to install Ventoy onto a USB drive for booting other PCs and UEFI-compatible ARM devices works without issue.
  • Booting the Raspberry Pi via Ventoy (Limited): The Raspberry Pi does not natively use standard PC BIOS or standard UEFI firmware. By default, it cannot boot directly from a standard Ventoy partition scheme. Booting a Raspberry Pi via Ventoy requires loading an unofficial UEFI firmware runtime (such as the Raspberry Pi UEFI Community Firmware) prior to loading the Ventoy bootloader.
