Ventoy Auto Install Plugin JSON Configuration Syntax

This guide explains the exact syntax required to define auto-install scripts using the Ventoy auto_install plugin in the ventoy.json configuration file. By mapping installation scripts to specific ISO images, Ventoy can automatically deploy operating systems such as Windows, Red Hat, Debian, Ubuntu, and SUSE without manual intervention.

File Location and Format

All automated installation configurations must reside within a file named ventoy.json, located inside a directory named ventoy at the root of the primary partition of your Ventoy USB drive:

/ventoy/ventoy.json

The file must use standard JSON syntax and UTF-8 encoding. All paths specified inside the file are relative to the root of the drive and must start with a forward slash (/).

The auto_install Object Structure

The configuration relies on an auto_install array containing one or more mapping objects. Each mapping object contains two primary keys:

  • image: The full path to the ISO file or a parent directory containing multiple ISOs.
  • template: The full path to the answer file (script), or an array of paths if offering multiple templates.

Basic Single Script Mapping

To assign one unattended installation script to a specific ISO image, define image and template as single string paths:

{
    "auto_install": [
        {
            "image": "/ISO/Windows11.iso",
            "template": "/ventoy/script/win11_unattend.xml"
        },
        {
            "image": "/ISO/CentOS-Stream-9.iso",
            "template": "/ventoy/script/centos_ks.cfg"
        }
    ]
}

Multiple Templates for a Single Image

If you want Ventoy to display a menu prompting you to choose between different answer files before booting an ISO, provide an array of file paths for the template key:

{
    "auto_install": [
        {
            "image": "/ISO/ubuntu-22.04-live-server.iso",
            "template": [
                "/ventoy/script/ubuntu_desktop_ks.cfg",
                "/ventoy/script/ubuntu_server_ks.cfg",
                "/ventoy/script/ubuntu_minimal_ks.cfg"
            ]
        }
    ]
}

When you boot the ISO, Ventoy presents a selection menu displaying the names of these configuration files.

Directory-Level Mapping

Instead of mapping ISO files individually, you can define a directory path for image. Any ISO located within that directory will use the specified template or list of templates:

{
    "auto_install": [
        {
            "image": "/ISO/Debian",
            "template": "/ventoy/script/debian_preseed.cfg"
        }
    ]
}

Supported Script Types

The template key points to the platform-specific automated installation script required by the installer:

  • Windows: Unattend XML files (autounattend.xml or custom .xml files).
  • RHEL / CentOS / Fedora: Kickstart files (.cfg or .ks).
  • Debian / Ubuntu: Preseed configuration files (.cfg or .seed) or Subiquity cloud-init user-data files.
  • SUSE / openSUSE: AutoYaST XML profiles (.xml).

Ventoy automatically injects the assigned template into the boot environment at runtime based on the matching rules defined in the JSON array.
