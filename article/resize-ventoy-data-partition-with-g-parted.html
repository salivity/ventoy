Resize Ventoy Data Partition with GParted

Ventoy creates a dual-partition structure upon installation, consisting of a primary data partition and a hidden EFI boot partition. You can safely resize the main Ventoy data partition using GParted after installation without breaking the tool's boot functionality. This article explains how Ventoy’s partition scheme handles resizing, the safety precautions required, and the step-by-step process for modifying the partition size in GParted.

Understanding the Ventoy Disk Layout

When you install Ventoy onto a USB flash drive, it formats the storage medium into two distinct partitions:

  1. Partition 1 (Ventoy): Formatted by default as exFAT (though NTFS, FAT32, ext4, or XFS can be used). This is the larger partition where ISO files, images, and standard files are placed.
  2. Partition 2 (VTOYEFI): A small (typically 32MB), protected FAT partition located at the end of the drive. It contains the bootloader code and EFI files required to boot the drive.

Because the data partition (Partition 1) and the bootloader partition (Partition 2) are separated, Partition 1 can be shrunk or expanded without altering the bootloader files, provided Partition 2 is left completely intact.

Resizing Partition 1 with GParted

To resize the data partition using GParted on Linux:

  1. Back Up Data: Before modifying disk structures, back up your ISO files or custom configuration scripts stored on the drive.
  2. Launch GParted: Open GParted with administrative privileges and select your USB flash drive from the drive drop-down menu in the top-right corner.
  3. Unmount the Partition: Right-click Partition 1 and select Unmount if the system automatically mounted it.
  4. Resize: Right-click Partition 1 and choose Resize/Move. Drag the edge of the partition to reduce or enlarge its capacity, or enter your target size in the New size (MiB) field. If you are shrinking the partition to make space for a third, separate partition, ensure the unallocated space is placed between Partition 1 and Partition 2, or move the free space as needed without overwriting Partition 2.
  5. Apply Changes: Click the green checkmark icon in the toolbar to apply the pending operations.

Critical Precautions

  • Do Not Touch Partition 2 (VTOYEFI): Modifying, formatting, or deleting the second partition will corrupt the Ventoy boot sequence. GParted must only be used to modify Partition 1 or to create a third partition in the newly unallocated space.
  • Keep Partition Alignment: Ensure that 1 MiB alignment is maintained within GParted to prevent read/write performance degradation on flash memory.
  • Do Not Move Partition 2 to the Front: Ventoy expects its boot partition at the specific end location of the disk structure. Shifting Partition 2 may result in boot errors on UEFI firmware.
